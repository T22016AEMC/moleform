## 要做的事

**一、資料表（D22：每列有出處、SMARTS 有正反例、稽核狀態「待使用者審」）**

1. `Ym` 基團表（Table 6.14）、`Yd,1/2` 基團表（Table 21.2）、吸濕性基團表（Table 18.14）。每個數值逐一對照書中原表謄錄（含括號數值的標記），列的出處欄寫書名、表號、頁碼。**不憑記憶補任何數值；書中同一基團有「共軛／鄰接基團不同」的多個數值時，全部收錄並以 SMARTS 或條件欄區分，與既有 Yg 表處理共軛的方式一致；Appendix II 說明 Yg 與 Ym 重疊的基團，可沿用既有 Yg 切分結果，不重複發明。**
2. 資料表放 `src/data/`，沿用現有欄位格式與載入方式；若現有資料表驗證測試會掃描 `src/data/`，依其 schema 補齊，不得為此寫 TypeScript 計算。

**二、計算（Python 引擎端點，輸出沿用 `value/unit/source/status`）**

3. `POST /tm`：`Tm = ΣYm / M`（式 6.20、6.21，M＝重複單元分子量）。亞甲基鏈長度修正依式 (6.22)–(6.24)。輸入可帶 `crystallizable`（true／false／未提供）：false → 回報「不適用」（不是數值）；未提供 → 給數值並加警告「Tm 只在聚合物可結晶時有意義」。缺基團 → `missing` 並列出缺的基團。
4. `POST /td`：`Td,1/2 = ΣYd,1/2 / M`（式 21.4）。輸出 K 與 °C。備註寫明：這是書定義的「半分解溫度」Td,1/2，不是 5% 失重溫度，使用者若要 Td5 需另議。
5. `POST /moisture`：輸入相對濕度（只允許 Table 18.14 的 0.3、0.5、0.7、0.9、1.0）與可選的結晶度；依基團加總每結構單元的莫耳含水量，換算 `g 水／100 g 聚合物`（水 18 為分子量，單元 M 由現有分子量模組取得）；結晶度修正依書的式 (18.15)（先讀該式，照書寫）；括號數值標「書中括號值（不確定）」。表中沒有的基團視為無貢獻但要列出「未涵蓋基團」並警告，不可靜默忽略。狀態 `predicted`，備註「25 °C、非晶區、參考趨勢」。
6. `POST /modulus`：先讀 13.2.5、13.2.6。**只實作書中能用本專案已有或本卡收錄的基團表直接算出的方法**：式 (13.30)–(13.32) 各自需要的加成函數表若不在書裡、或需要本專案沒有的資料，該方法不做並在報告列出原因，不要自行找外部資料；有兩個以上方法可算時，依書的建議取平均並同時列出各方法的值。能算出體積模數 K 才輸出；彈性模數 E 只有在書中給出由結構（或由 Tg 等已有量）估算的明確路徑時才輸出，否則只輸出 K，並在報告寫明缺什麼。結果標「參考趨勢，與書的 20% 一致性」。

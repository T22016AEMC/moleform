## 要做的事

1. 先看圖，把 Bondi 對三類芳香碳的定義原文寫進報告，尤其：「取代」是否包含雜原子取代（–OH、–O–、–F）與環稠合的飽和環碳。**若定義文字與下面的規則不一致，停下來問我。**
2. 資料表：芳香族 C 一列改為三列（每列有出處、頁碼、稽核狀態「待使用者審」，缺欄位報錯）：
   - 芳香 C–H（有氫）：維持使用者的 8.11，備註「Bondi C–H 為 8.06，差 0.6%，保留使用者值」。
   - 取代芳香 C（無氫，連接環外任何原子或飽和環）：5.54，出處 Bondi Table XV。
   - 縮合芳香 C（同時屬於兩個以上芳香環，萘型）：4.74，出處 Bondi Table XV。
3. 配對規則（固定、可重現，寫進程式註解與報告）：芳香碳若屬兩個芳香環共用 → 縮合；否則有氫 → C–H；否則 → 取代。茚滿與茀的稠合碳（屬一個芳香環與一個飽和環或五員環）歸為取代，標「詮釋，待使用者審」。SMARTS 自行撰寫，每個基團至少一個正例與一個反例（苯、甲苯、苯酚、萘、聯苯、茚滿、茀、二苯醚）。
4. **依論文套用 Table XVII 的修正量**（使用者 2026-11-06 要求完全照論文算法）。先看圖讀取該表與腳註的全部項目與適用條件，寫進報告，再逐項實作：稠合在芳香環系統上的飽和（亞甲基）環，每個環扣 1.66（腳註 b：苯環或其他芳香環系統，例：四氫萘、茚滿）；茀的五員環算 1 個環、扣 1 次，並在報告列出「若算 2 次」的差（預期不到 1%）；共軛雙鍵間單鍵 0.25；羧基或醯胺旁的單鍵每個 0.22（計數方式寫出）；cis-稠合環 2.50、二氧環 1.70 等其餘項目，凡論文敘述清楚者都實作。**環己基與環戊基環的 1.14：使用者表的環脂肪族 C／CH／CH₂（3.8、5.6、8.45）可能已含此修正，為避免重複計算，這一項不套用**，報告並列環值與「鏈值減 1.14」的比較。論文敘述不清楚的項目列「不實作」並回報，不得猜。每項修正在輸出列出適用的次數與數值。

# 任務 034：成分 Tg（Fox–Flory）與混合配方未固化 Tg（Phase 6.7 的 Tg 部分）

編號：034
建立日期：2026-11-06
指派給：Claude Code

## 目標

1. 讓配方中每個 Solid 成分有一個 Tg：聚合物與寡聚物用 Fox–Flory（Tg = Tg∞ − K/Mn），Tg∞ 取自基團貢獻（任務 026、033）或文獻錨點；小分子用「Tg ≈ Tm 的約 2/3」。
2. 用 Fox（必要時 Gordon–Taylor）把成分 Tg 混成配方的**未固化 Tg**。
3. 做核心函式與批次輸出文件，不做畫面。

本卡只做 PLAN 6.7 的「混合 Tg」。混合密度、混合介電常數、共聚比例影響不在本卡。固化後 Tg（DiBenedetto）屬 Phase 7，不在本卡。

前提：任務 033 已完成（commit 9f7f637）。

## 要做的事

### A. 先讀懂公式（寫進報告，不要自行詮釋）

1. Fox–Flory 的形式、適用條件、K 的意義；書中與 Fox–Flory 原文的式號與頁碼。
2. 混合 Tg：書中與 Fox 1956／Gordon–Taylor 原文各給了什麼式、參數 k 是否能不靠實驗值決定（例如由書中的 Simha–Boyer 規則推）。**k 如果只能靠實驗值決定，就不得自行假設 k，Gordon–Taylor 只在 k 可由書中規則推得時才做**；Fox 式沒有可調參數，作為主要輸出。
3. 以上任何一點書中沒說清楚 → 停下來回報。

### B. 成分 Tg 的資料（全部看圖讀取，寫進報告附頁碼；數值只能來自看過的頁面）

1. **酚醛（苯酚酚醛）Tg 對 Mn**：優先用論文直接給的 DSC Tg 與 Mn 配對（Bian 2016）。Pilato Table 4.9 只有軟化點與 Mn（Mn 為聚苯乙烯換算的相對值，軟化點量法表中未註明）：依 D55，只能以 Bian 2016 同類酚醛的軟化點與 DSC Tg 差值換算，標「換算值，低可信度」。換算後的點只當檢驗用。
2. **DGEBA／環氧寡聚物**：
   - Mn 軸用 McAninch 2014 Table 4.1 的平均 n（見 `EPON_ECN_EPN_PGMA_樹脂資料與來源_更新版.pdf`）算出。
   - Tg 的文獻點：D.E.R. 332 論文（n = 0.03，若有給 Tg）、苯氧樹脂論文（Mn 1.5×10⁴ 為 96 °C）、Kuo 2003 圖 5（Mn 23,000，約 99 °C）。
   - `EPON固態_軟化點_EEW_AI整理截圖.png` 是 AI 整理的二手表，**不入擬合，不換算 Tg**，只用來檢查「1001F < 1004F < 1007F」的高低順序是否與算出的 Tg 順序一致（使用者 2026-11-06 決定）。
3. **ECN／EPN**：INDEX 第五節記為缺 Tg 資料；本卡不得用軟化點換算它們的 Tg 進入擬合。若沒有可用的 Tg，輸出「缺 Tg 資料」。
4. **小分子**：Tg ≈ Tm × 2/3，範圍用書中給的比值範圍（0.56–0.76，查頁碼）；Tm 用 Joback（D52）。SBI 二酚的文獻熔點（TCI 213–217 °C、Stueben 215.5–217 °C）只當比對，不當輸入。
5. 每個數值連同量測方法記錄（DSC 中點、TMA、環球法等，D55）。

### C. 計算方法

1. **Fox–Flory**：成分 Tg∞ 兩個來源並列輸出：(a) 基團貢獻值（含校準基團，標註）；(b) 文獻 Tg∞（僅有高分子量文獻點的類別）。K 由 B 的資料擬合，**按樹脂類別分開**（酚醛、DGEBA 類）。**不得自行假設 K，也不得把某一類的 K 套到另一類**；沒有資料的類別只輸出 Tg∞，標「缺 K，未做分子量修正」。
2. **擬合品質規則**（同 D54 精神）：K 由一部分資料擬合，另一部分資料當獨立檢驗，檢驗誤差 ≤ 20 K 才收錄；超過就不收錄並停下來回報。每個 K 附資料點、擬合方式、殘差、不確定度。
3. 苯氧樹脂 BT05 的基團貢獻值偏高 26–30 K（033 報告第五節）：DGEBA 類 Tg∞ 的 (a)(b) 兩個來源並列，報告寫出差異；**不得調整 Yg 現有值**。
4. **混合 Tg（Fox）**：只混 Solid 區成分，用質量分率；標記「揮發或分解」的成分、Liquid 區成分不混。Catalyst/Initiator（D26）成分同樣不混、列在輸出備註（不假設排除門檻，由使用者決定是否調整）。
5. 任一參與混合的 Solid 成分算不出 Tg（缺基團、缺 K、無 Tm）→ 回報「缺成分 Tg：成分名稱」，**不猜值、不略過**。同時輸出「去除該成分後的部分混合值」並明確標示非完整配方。
6. 聚合物成分的 Mn 依 D46、D47、D50（含端基）的現行算法取得，不得改動。
7. 結果依 D55 標來源等級與換算標記（「換算值，低可信度」「含校準基團」「外推」）；D09：分子量不顯示在網站畫面，本卡不做畫面。D02：不使用使用者實測值當輸入。

### D. 測試

1. 公式測試：Fox–Flory、Fox 混合、（若有）Gordon–Taylor 對手算值；邊界（單一成分＝成分 Tg；Mn → ∞ 時＝Tg∞）。
2. 資料表格式：新增資料表（Tg–Mn 資料點、K、類別）每列有來源等級、量測方法、頁碼，缺欄位報錯（D22）。
3. 缺成分 Tg 的回報測試；Catalyst、揮發成分排除測試；小分子 Tm 範圍測試。
4. 不要啟動背景伺服器。

### E. 驗證與輸出文件

1. **文獻驗證**：Pascault 等 1990 Table I 的未固化 Tg0（成分與組成看圖讀取）、Han 1997 圖 4 的 Tg0；用本卡方法算混合 Tg，與文獻值比較，列表附頁碼與誤差。成分的 Tg 必須由本卡方法得出，不得用論文中成分的實測 Tg 直接代入（若論文成分 Tg 無法由本卡方法算出，列為「無法驗證」，說明原因）。
2. **使用者目標（僅供比對，D02）**：使用者有兩組配方的未固化 DSC Tg 實測：4A 約 120 °C（中點）、4A＋SBI 約 105 °C。配方成分在 `docs/verification/` 或測試資料中找；找不到就停下來問我。這兩個數值**只能寫在驗證報告的比對欄**，不得寫進 `src/`、測試或資料表當輸入。

4. 原本的 `phase3`–`phase6-*` 輸出重新產生後逐字相同（除任務明確新增的檔案）。

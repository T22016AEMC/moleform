### A. 盤點缺基團

1. 列出化合物庫、配方測試資料與 BT01–BT06 中，在下列四種計算「缺基團」的所有結構：Yg（Tg）、Joback（Tb、Tf）、VW、莫耳體積／密度。
2. 對每個缺基團，標出缺的是哪個原子團（例如茀、螺雙茚滿、酚羥基、環氧環、醚 –O–、末端 CH3、2-萘基），以及哪些結構受影響。
3. 整理成表，放進報告。
4. **依 D53 另外盤點半導體常用材料的代表結構**。下列是範圍清單，SMILES 由你撰寫，並用 RDKit 檢查分子式與質量、列在報告中，一律標「待使用者審」，不得從記憶中補數值：
   - 封裝環氧：雙酚 A 型、鄰甲酚酚醛環氧（ECN）、聯苯型環氧、雙環戊二烯（DCPD）型環氧、萘型環氧
   - 硬化劑：苯酚酚醛、酚芳烷基型（Xylok 類）、聯苯芳烷基酚醛、DCPD 酚、酸酐（甲基六氫鄰苯二甲酸酐、甲基四氫鄰苯二甲酸酐）、胺類（DDS、雙氰胺）
   - 硬化促進劑：三苯基膦、咪唑類
   - 高耐熱絕緣聚合物：聚醯亞胺（PMDA–ODA、BPDA–PDA 單元）、聚苯并噁唑（PBO）、苯并環丁烯（BCB）
   - 光阻基底聚合物：聚羥基苯乙烯（PHS）、（甲基）丙烯酸酯共聚物單元
   對這些結構同樣做四種計算的缺基團盤點，並在報告分開列表（「使用者材料」與「半導體常用材料」）。清單若有遺漏的重要類別，列在報告「需要使用者決定的事」，不要自行擴張。

### B. 近似拆解候選方案（Yg、VW、莫耳體積各自）

1. 對 A 中每個缺的原子團，提出「只用現有資料表內基團」的拆解候選（每個原子團至少一種；有多種合理拆法時全部列出）。
2. 拆解規則必須寫明：用了哪些基團、哪個表、為何這樣拆、哪些地方是近似（例如稠環拆成兩個單環、環張力不計）。
3. **沒有任何現有基團可拆的原子團（預期包括酚羥基、環氧環的氫鍵或張力效應）直接標「無法拆解」，不要提候選。**

### C. 用書本身量化拆解誤差

1. 在 Table 6.1、6.3（Yg）、Table 4.2（VW）、Table 4.10（莫耳體積）中找出「書中有整個基團的值，同時能用同表較小基團相加得到」的案例（例如聯苯組合 vs 兩個伸苯基、稠環 vs 單環相加、芳香酯組合 vs 小基團、帶取代的伸苯基 vs 伸苯基加取代）。
2. 每個性質至少 8 個案例；找不到 8 個就列出找到的並說明。每個案例列：整個基團的書中值、拆解相加值、差值、相對誤差。數值一律看圖讀取，書中印刷錯誤依 KNOWN_ISSUES 處理。
3. 統計：平均差、最大差、每個「拆解類型」的差（稠環、聯苯型、酯組合等）。
4. 把 B 的每個候選方案對應到 C 中最相近的拆解類型，給出該方案的預期誤差範圍（用 C 的統計，不要憑感覺）。

### D. 幾何 VW 可行性

1. 讀 4.2.3 節與 Table 4.1，整理書中 VW 的計算定義：用哪套原子半徑、鍵長、是否算球體重疊、重疊公式。寫進報告（附書頁碼）。
2. 檢查任務 024 的 3D 流程能否輸出重複單元的原子座標；回報目前取得座標的函式與限制。
3. 寫一個**拋棄式驗證腳本**（放 `scripts/diagnosis/`，不進 `src/`，不進建置），以 D-1 的定義與 3D 座標算 VW，對下列結構與 Table 4.2／4.7 的值比較：聚乙烯單元、聚苯乙烯單元、PET 單元、雙酚 A 單元，以及其他 Table 4.7 中書中有 VW 的至少 4 個結構。報告列出差值。
4. 結論分三類：可行（差 ≤ 0.5 cm³/mol 或 ≤ 1%）／部分可行（說明限制）／不可行（說明原因）。並明確回答：對任務 028 留空的結構（含醚、環氧環、稠環），幾何 VW 能不能算、結果多可信。
5. 同時回答：不同構象（至少兩個構象）對 VW 的影響有多大。

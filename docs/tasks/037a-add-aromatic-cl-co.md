# 任務 037a：補收書的芳香 Cl 與芳香 >C=O（任務 037 的後續）

編號：037a
建立日期：2026-11-07
指派給：Claude Code

## 目標

任務 037 報告指出，van Krevelen Table 4.2 有 Cl（ar.）12.0 與 >C=O（ar.）11.7，但 `vw_groups.csv` 原本沒收。這是書的值（不是 Bondi 補充），使用者 2026-11-07 同意補收。

## 前置條件（先讀這些）

- `docs/reports/037-結果.md`、`docs/DECISIONS.md` 的 D22、D53、D59
- `src/data/vw_groups.csv` 與基團切分程式
- van Krevelen 4th ed. Table 4.2 的頁面（`docs/references/`）：**必須看圖讀取這兩列的數值、頁碼與適用條件**；看到的數值與 12.0、11.7 不符，或轉不出圖，就停下來問我。

## 要做的事

1. 在 `vw_groups.csv` 新增兩列：Cl（ar.）與 >C=O（ar.）。數值只取自看過的頁面，附出處、頁碼，稽核狀態「待使用者審」，缺欄位報錯。SMARTS 自行撰寫，每個基團至少一個正例與一個反例（正例：氯苯、二苯甲酮；反例：氯乙烷、丙酮）。
2. 配對順序：芳香 Cl 只配接在芳香碳上的 Cl，脂肪族 Cl 維持現有規則；芳香 >C=O 只配兩側皆為芳香碳的羰基，其餘羰基維持現有規則。要先確認書對「ar.」的定義：若書只指其中一側為芳香環，以書的定義為準並寫進報告。
3. 回歸：現有輸出中不含這兩個基團的結構，結果逐字相同。037 補充基團若已涵蓋同一原子，書的值優先，並在報告列出前後差異。
4. 原本因這兩個基團缺失而回報「缺基團」的結構，列出前後差異表（只列因本卡而變的列）。
5. `docs/DECISIONS.md` D59 加註「芳香 Cl 與芳香 >C=O 以書的值補收（任務 037a）」；更新檔頭日期。
6. 新增 `docs/reports/037a-結果.md`，commit、push，確認 CI 的 build 通過。

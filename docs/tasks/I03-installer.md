# 任務 I03：桌面版改為安裝版（NSIS，每使用者安裝）

編號：I03
建立日期：2026-11-16
指派給：Claude Code

## 目標

I02 完成後，可攜式 exe 每次啟動都要解壓約 3,200 個檔案、580 MB 到暫存資料夾，日常使用太慢。使用者 2026-11-16 決定：改為安裝版（NSIS，安裝在使用者自己的資料夾，不需要管理員權限，不做程式碼簽章）；不刪套件內的 `tests` 資料夾。依 D64：一次做完、驗證一次、報告半頁。

## 前置條件（先讀這些）

- `docs/reports/I02-結果.md`、`docs/reports/039-結果.md`（使用者資料位置）、`desktop/` 的打包設定
- 不要搜尋整個專案

## 要做的事

1. 把 Windows 打包目標從可攜式 exe 改為 NSIS 安裝檔：每使用者安裝（不要求管理員權限）、允許使用者選安裝資料夾、建立桌面與開始選單捷徑、不做程式碼簽章。`npm run desktop:build` 產出安裝檔；既有 `build`、`test` 指令行為不變。可攜式目標可保留為另一個獨立指令，但不再是預設。
2. **解除安裝不得刪除使用者資料**（039 查到的資料位置），並確認升級安裝（覆蓋安裝）後使用者資料仍在。
3. 引擎資源（內嵌 Python、`moleform_core`、資料表、授權聲明）必須完整包進安裝檔，路徑邏輯不變。
4. **一次性實測**：安裝後從安裝位置啟動，跑 I02 的 `--selftest=sample`，結果與 I02 記錄的數字逐位數相同（PMMA Tg、Vm、混合 Tg、混合密度）；記錄安裝檔大小、安裝時間、安裝後第二次啟動到引擎可用的時間（與可攜式第一次 304 秒比較）；解除安裝後確認程式資料夾已移除、使用者資料仍在；測試後不要留下背景程式。
5. 報告 `docs/reports/I03-結果.md`，限半頁。更新 `docs/PLAN.md` 6A 補註。
6. 本機只跑本卡需要的檢查、型別檢查、`npm run desktop:build` 與實測；全部 TypeScript 測試與建置交給 CI。大型安裝檔不得 commit。commit、push，只查一次 CI。

## 不可更動的檔案或規則

- 不修改 `src/`、引擎計算與資料表、既有 CI job；不新增套件除非打包設定必須
- 引擎仍只在 127.0.0.1，不對外；測試後不要留下背景程式
- 不使用記憶中的版本號；不更改已定案決定

## 完成標準（可檢查）

- [ ] `npm run desktop:build` 產出安裝檔；安裝後自測結果與 I02 逐位數相同
- [ ] 解除安裝保留使用者資料；覆蓋安裝後使用者資料仍在
- [ ] 安裝後二次啟動時間已記錄；已 commit 與 push，CI 通過

- 安裝版無法完整帶入內嵌引擎
- 任務與 `docs/DECISIONS.md` 衝突

# 任務 020：Random 共聚物（多種重複單元＋比例）（Phase 5.1、5.2、5.6）

編號：020
建立日期：2026-10-30
指派給：Codex／Claude Code

## 目標

聚合物可以由**兩種以上的重複單元**依比例組成（Random 共聚物，D04），比例可用 mol% 或 wt%；分子量沿用 Mw＋PDI（D47）。共聚物接上配方換算、交聯第 0、1 層與理論配比。測試體系中的 P 改為使用者提供的真實組成：**雙酚茀單元：萘基次甲基單元 = 2：1（莫耳）**。均聚物視為只有一種單元的共聚物，既有資料與結果不變。

## 要做的事

### A. 資料模型（`src/core/polymer/`，純 TypeScript）

1. 聚合物改為：`units: { repeatUnitSmiles, fraction }[]`（至少 1 種）、`fractionBasis: 'mol' | 'wt'`、分子量（Mw＋PDI，或 Mn／DP＋PDI，沿用 D47）。
2. 每種單元沿用任務 015 的連接點規則（恰好兩個 `*`）。
3. 比例：
   - 合計須為 100（容差 ±0.01，沿用任務 013 的規則），否則中文錯誤
   - `wt` 時以各單元的 M_unit 換算為莫耳分率
4. **平均重複單元**（以莫耳分率 x_i 加權）：
   - 平均單元質量 M̄_unit = Σ x_i·M_unit,i
   - 每個平均單元的官能基數 = Σ x_i·(單元 i 的官能基數)，每種官能基分開計
   - DP_n = Mn ÷ M̄_unit，DP_w = Mw ÷ M̄_unit；每分子官能度 = DP × 每平均單元官能基數
5. **組成分布近似**（寫進 `docs/MODELS.md`）：Random 共聚物每條鏈的組成視為等於平均組成，不考慮鏈與鏈之間的組成差異；分子量分布仍用任務 019 的兩成分等重量近似。結果附註：「共聚物以平均組成計算，未考慮鏈間組成分布」。
6. **舊資料相容**：均聚物（單一 `repeatUnitSmiles`）讀入時轉為 `units` 只有一種、比例 100 mol%；計算結果必須與任務 019 完全相同（加測試）。`schemaVersion` 若需變動，必須能讀舊檔。

### B. 畫面

7. 聚合物設定（分子工具、加入成分彈窗、成分詳細彈窗、化合物庫）：
   - 單元清單：每列一個重複單元（縮圖、SMILES、比例），可新增、刪除
   - 新增單元的方式：貼 SMILES（含兩個 `*`）、或用 Ketcher 畫（沿用彈窗內的 Ketcher）
   - 比例基準切換 mol%／wt%；合計不為 100 時顯示錯誤與實際合計
   - 分子量欄位沿用任務 019
   - 只有一種單元時，畫面與現在的均聚物設定相同（不出現多餘欄位）
8. 成分表縮圖：共聚物顯示第一種單元的縮圖，加「共聚物」標籤；成分詳細彈窗列出所有單元的縮圖與比例。
9. 依 D09，**網站不顯示** M_unit、M̄_unit、每單元官能基數；使用者輸入的比例、Mw、PDI 及其換算的 Mn、DP 可顯示在輸入欄旁。

### C. 接上計算（5.5、5.6）

10. **配方**：質量相關換算不變；聚合物 mol%（D46）以鏈計用 Mn、以重複單元計用 M̄_unit。
11. **交聯第 0 層**：每種單元分別辨識官能基（排除涉及 `*` 的匹配），依 A-4 加權得到每平均單元與每分子的官能基數；反應原子標記在每種單元的結構圖上分別顯示。
12. **交聯第 1 層與理論配比**：用 A-4 的官能度，其餘沿用任務 017、019。

### D. 測試體系更新（使用者 2026-10-29 提供，照抄）

13. `docs/verification/phase4-測試體系.md`：
    - 成分表 P 的「重複單元或結構」改為兩種單元：
      - 單元 A（雙酚茀）：`[*:1]c1ccc(C2(c3ccc([*:2])c(O)c3)c3ccccc3-c3ccccc32)cc1O`
      - 單元 B（萘基次甲基）：`[*:1]C([*:2])c1ccc2ccccc2c1`
      - 比例：A：B = 2：1（mol%：66.67、33.33）
    - 「類型」改為「Random 共聚物」
    - 「備註」中「P 的實際兩種單體比例不是 1:1，本階段先以 1:1 近似…」改為：「P 以使用者提供的組成 雙酚茀：萘基次甲基 = 2：1 建立 Random 共聚物（2026-10-29）。程式只依組成與分子量計算，不檢查縮合反應的連接規則；A 多於 B 的部分在結構上等同隱含 A–A 直接相連」

### E. 測試

14. `tests/polymer/`：
    - 比例 mol%／wt% 換算、合計檢查
    - 平均單元：P 的兩單元 2：1 → M̄_unit、每平均單元酚羥基數，與手算一致（在註解寫出：單元 A 去除 `*` 後 C₂₅H₁₆O₂ 約 348.40、單元 B C₁₁H₈ 約 140.18；M̄_unit = (2×348.40 + 140.18)/3；每平均單元 OH = 2×2/3）
    - 單一單元共聚物 = 原均聚物，結果完全相同（包括任務 019 的 4A、4B 輸出）
15. `tests/crosslink/`：P 改為 2：1 共聚物時，4A 的官能基比與手算一致（手算：酚羥基當量 = M̄_unit ÷ 每平均單元 OH；4A 約 1：2.72）。

### F. 驗證清單

16. 重新產生 `npm run verify:phase4`（以及 `verify:phase3`，若受影響）：
    - P 以 2：1 共聚物計算；報告附 4A、4B 新舊對照（官能基比、凝膠點、交聯密度、Mc、溶膠分率）
    - 驗證清單列出 P 每種單元的官能基數、M_unit、M̄_unit（僅文件，D09）

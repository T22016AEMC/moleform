## 目標

聚合物（均聚物與共聚物）可以分別設定兩端的端基：從常見端基清單選，或自訂 SMILES。端基計入分子量換算，端基上的官能基也參與交聯第 0、1 層。沒填端基時，結果與現在完全相同。

## 要點

- D50 寫入 `docs/DECISIONS.md`（文字照抄）。
- 新增 `src/data/end_groups.csv`（欄位 `id`、`名稱`、`SMILES`、`常見於`、`出處`；27 列，內容與順序照任務單，不可增刪修改）。
- 換算：DP_n = (Mn − M_ends) ÷ M̄_unit；輸入 DP 時 Mn = DP × M̄_unit + M_ends；Mn ≤ M_ends 時報錯。
- 每條鏈官能基數 f(M) = ((M − M_ends) ÷ M̄_unit) × 每平均單元官能基數 + 兩端端基官能基數；兩成分近似的每個虛擬成分用此式。
- 畫面：單元清單下方「端基 1」「端基 2」下拉選單（不填／27 項／自訂 SMILES），三處（分子工具、加入成分彈窗、成分詳細彈窗）。
- 沒填端基時，所有結果與任務 021 之前完全相同。

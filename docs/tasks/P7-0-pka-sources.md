編號：P7-0

指派給：Claude Code

## 目標

Phase 7 的 pKa 估算（7.3a，D38）用 Hammett／Taft 線性自由能法，需要「母體 pKa」與「取代基常數 σ」。使用者未提供書籍，D39 允許 AI 搜尋公開文獻或開放資料集取得。本卡**只做來源調查，不寫計算程式、不收錄資料列**，產出一份來源清單交使用者選擇。依 D64：一次做完、報告一頁。

## 前置條件（先讀這些）

- `docs/DECISIONS.md` 的 D17、D22、D38、D39、D65；`docs/PLAN.md` 的 Phase 7
- `docs/references/INDEX.md`（先看本機已有的書與論文有沒有現成的 σ 或 pKa 表，例如 Van Krevelen、Bicerano；有就列為候選來源之一，標明表號與頁碼）
- 不要搜尋整個專案

## 要做的事

1. 用 WebSearch／WebFetch 找可用的來源，涵蓋三類：
   - Hammett σ（meta、para、σ⁺、σ⁻）與 Taft（σ*、Es）取代基常數的公開表；
   - 母體 pKa（水溶液，25 °C）：酚、苯胺與脂肪胺（共軛酸）、羧酸（苯甲酸與脂肪酸）、醇、硫醇、咪唑等 Phase 7 反應位點會用到的可解離基團；
   - 各反應類別的 ρ（反應常數）來源，例如取代酚、取代苯甲酸、取代苯胺的解離常數 ρ。
2. 每個候選來源列出：名稱與版本或年份、作者／機構、網址、**授權**（可否再散布與放進本專案 public repo、是否需標示出處）、涵蓋的取代基或基團範圍、數值是否為水溶液 25 °C、是否能逐列取得出處（表號或資料集欄位）、取得方式（直接下載／需手動謄錄）。
3. 優先順序：開放授權的資料集或教科書級公開表優先；授權不明或僅限個人使用的來源要明講，不要列為建議。**不要收錄任何數值進專案**，也不要憑記憶寫數值；連結打不開或內容無法確認就寫「未能確認」。
4. 給一個建議組合（母體 pKa、σ、ρ 各用哪個來源）與理由，以及使用者需要決定的事。這是建議，由使用者選。
5. 報告 `docs/reports/P7-0-結果.md`，限一頁，用一張表列來源。不改任何程式、資料表、既有文件（除了報告）。commit、push；本卡不改程式，CI 不必另查。

# 任務 018：配方工作台（左右兩欄版面）與加入成分彈窗

編號：018
建立日期：2026-10-29
指派給：Codex／Claude Code

## 目標

把「配方」「交聯」兩個分頁合併成一個**配方工作台**：左欄輸入配方，右欄即時顯示所有結果，不必切換分頁或來回捲動。加入與檢視成分改用彈窗，在工作台內完成。**本任務只改版面與操作方式，不改任何計算、公式或資料表。**

## 前置條件（先讀這些）

- `AGENTS.md`
- `docs/DECISIONS.md`（特別是 D03、D09、D23、D34、D44）
- `docs/DESIGN.md`
- `docs/reports/014-結果.md`、`015-結果.md`、`016-結果.md`、`017-結果.md`

### B. 分頁

4. 分頁改為三個（樣式依 D34，與現在相同的按鈕組）：
   - **配方工作台**（預設開啟）：取代原本的「配方」與「交聯」
   - **分子工具**：原本的「結構」分頁（結構輸入、均聚物設定、3D），功能不變
   - **化合物庫**：原本的「我的化合物」，功能不變
5. 切換分頁時不清除各頁的內容（沿用目前的做法）。

### C. 工作台版面

6. **左欄（配方輸入，約 40% 寬）**，由上到下：
   - 配方名稱、「我的配方」選單（儲存、另存、載入等，功能同現在）
   - **目標 Solid Content**（放在配方名稱與配方選單下方）
   - Solid 區：單位選單、成分表、「＋加入成分」
   - Liquid 區：單位選單、成分表、「＋加入成分」
   - 錯誤與警告仍顯示在對應欄位旁（沿用任務 014 的做法）
7. **成分表每一列**：
   - 最左邊一張**小縮圖**（RDKit 產生的 2D 結構 SVG，高度約 48px；聚合物顯示重複單元）
   - 名稱、分類、用量（單位在輸入框內）；Solid 的「樹脂」「會揮發／分解」勾選
   - 聚合物加一個「聚合物」標籤
   - 「⋯」選單：上移、下移、刪除（畫面內確認，不用瀏覽器對話框）
   - **點縮圖或名稱 → 開啟「成分詳細」彈窗**（見 D 節）
8. **右欄（即時結果，約 60% 寬）**：
   - 右欄自己捲動，左欄捲動時右欄不跟著跑（固定在畫面上）
   - 由上到下分成可展開／收合的區塊，**預設全部展開**，展開狀態只存在畫面中：
     1. 組成（原配方結果：wt%、mol%、phr、質量、Solid Content、目標反推）
     2. 交聯第 0 層（判定、反應配對、不參與反應的成分、反應原子標記圖）
     3. 交聯第 1 層（官能基比、凝膠點、交聯密度、Mc 等，含轉化率輸入）
     4. 理論配比與比例掃描
   - 每個區塊的內容、文字、可信度標示、統一備註都**沿用現有元件**，不改計算與文字
   - 左欄任何輸入改變時，右欄全部即時更新（沿用約 0.3 秒的延遲）
9. **寬度不足**（小於約 1280px）時，改為上下排列：輸入在上、結果在下。
10. 版面相關的樣式值加進 `src/ui/theme.css`（例如欄寬比例、斷點），並更新 `docs/DESIGN.md`。

### D. 彈窗

11. **加入成分彈窗**（按「＋加入成分」開啟）：
    - 三種方式（分頁或切換）：**貼 SMILES**、**從化合物庫搜尋**、**用 Ketcher 畫**
    - 結構通過驗證後，下方顯示 2D 預覽與驗證訊息（沿用任務 010 的驗證）
    - 含連接點 `*` 時，在彈窗內直接顯示均聚物設定（Mn 或 DP，沿用任務 015）
    - 名稱欄（從化合物庫加入時帶入名稱；其他方式預設「成分 N」，可修改）、分類
    - 「同時存進化合物庫」勾選（預設不勾）
    - 「加入」「取消」
12. **成分詳細彈窗**（點縮圖或名稱開啟）：
    - 大的 2D 結構，標出反應原子（沿用任務 016 的標記，原子編號 1 起算）
    - 小分子：可在彈窗內產生與檢視 3D（沿用任務 011 的元件，含「標記反應原子」）；聚合物顯示「聚合物不提供 3D（D05）」
    - 聚合物：均聚物設定（Mn／DP）可在此修改
    - 「用 Ketcher 編輯結構」：在彈窗內打開 Ketcher，修改後套用回這個成分
    - 「存進化合物庫」按鈕
13. 彈窗規則：
    - 按 Esc 或彈窗外的暗色區域可關閉（Ketcher 編輯中有未套用的修改時，先在彈窗內提示確認，不用瀏覽器對話框）
    - 開啟時焦點移到彈窗內，關閉後回到原本的按鈕
    - Ketcher iframe 只在需要時載入；同一時間只保留一個 Ketcher 實例，避免重複初始化

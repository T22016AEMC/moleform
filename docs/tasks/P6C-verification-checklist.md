## 要做的事

**一、6.8 公式測試覆蓋**

1. 新增 `docs/verification/phase6-公式測試覆蓋.md`：每個計算模組一列——公式／方法、對應端點、測試位置（黃金比對檔、書的算例對照、單元測試）、案例數、有沒有缺口。
2. 有缺口（完全沒有測試的公式）時，補**最少的手算單元測試**（手算值寫在測試裡，附算式）；缺口超過 5 個就只列出、不補，在報告寫明，由使用者決定。

**二、6.9 使用者驗證清單**，新增 `docs/verification/phase6-使用者驗證清單.md`，含三部分：

3. **待審資料列總表**：掃描 `src/data/` 全部資料表，統計每張表稽核狀態為「待使用者審」的列數與總列數；另外**完整列出**所有標「詮釋」「補充」「校準」「使用者定義」的列（這些是判斷而非書值，最需要審）：表名、列識別、數值、出處、詮釋依據。不要把全部資料列貼進文件，只做統計與上述重點列表，其餘指向各 CSV。
4. **代表分子結果對照表**：沿用現有 `phase6-*.md` 已出現的分子與聚合物（不新增分子），用現在的 Python 引擎算出全部物性（VW、Tg、Vm／密度、CTE、自由體積、介電、極化率、Tb／Tf（小分子）、TPSA／LogP、Tm、Td、吸濕性），每個分子一張小表：物性、數值、單位、狀態、出處、缺基團／警告，最後一欄「使用者判定（對／錯／備註）」留空。分子數量以現有驗證文件為準，不超過 20 個。
5. **使用者實測比對模板**（D02：使用者的 DSC 實測值只作驗證目標，不作任何計算的輸入）：新增 `docs/verification/user-measured-template.csv`，欄位：配方或樣品名、結構（SMILES 或名稱）、實測 Tg（°C）、測量條件、**用途（校準／驗證）**、備註。並新增小腳本 `engine/scripts/compare_measured.py`：讀取使用者填好的 CSV，呼叫引擎算預測值，輸出每筆的預測、誤差，以及依材料家族分組的平均與最大誤差；**「用途＝校準」的列不得併入驗證誤差統計**（校準與驗證資料要分開，避免自己驗自己）。模板放幾列示範（明確標「示範，非實測」）。腳本不得把實測值傳進任何計算函式。
6. 驗證清單文件開頭寫一段使用說明（使用者要看哪些、怎麼填、填完怎麼跑腳本），簡短即可。

**三、收尾**

7. 報告 `docs/reports/P6C-結果.md`，限半頁：有沒有測試缺口、待審列總數、需要使用者決定的事。`docs/PLAN.md` 6.8、6.9 補註並依實際勾選（6.9 勾選條件：清單文件與模板完成；使用者實際審完屬後續）。
8. 本機只跑本卡新增的測試與引擎 pytest；全部 TypeScript 測試與建置交給 CI。新增測試字串一律用雙引號。commit、push，用 PowerShell 查一次 CI。

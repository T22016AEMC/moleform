## 目標

1. 把分子（小分子、聚合物重複單元、骨架範本單元）依 van Krevelen 的 Yg 基團切開。
2. 建立 Yg 基團參數表，每一列都有書中表號與頁碼出處。

6. D22 流程：SMARTS 由自行撰寫，每個基團至少一個正例分子與一個反例分子（放在測試中），稽核狀態先填「待使用者審」。

### D. 切分與計算（`src/core/properties/`，沒有該資料夾就新建）

1. **切分**：每個重原子恰好屬於一個基團（氫原子隨所屬重原子）。優先配對較大的基團，再配對較小的；順序固定、結果可重現。沒有任何基團可配的原子 → 這個分子 Tg 不計算，回傳「缺基團」與缺的原子位置，不拋例外、不猜值。
2. **連接點**：聚合物重複單元的 `*` 視為連到相鄰單元的鍵（van Krevelen 以重複單元計算）。小分子沒有連接點。
3. **共軛狀態**：Table 6.1 B 區段的 n／c／cc 規則照書中 6.2 節文字（先讀完再實作）。書中沒說清楚的情況（例如兩個芳香環之間隔多少原子才算共軛）→ 停下來回報，不要自行定義。
4. **計算**：Tg = ΣYgi ÷ M，M = ΣMi。單位 K，另外提供攝氏換算。M 必須等於分子（或重複單元）的莫耳質量，差大於 0.01 g/mol 回報。
5. 回傳內容：Tg、ΣYgi、M、每個基團的名稱與貢獻、使用到的出處、缺基團清單。
6. D09：分子量、當量**不顯示在網站畫面上**，本卡也不做任何畫面，只輸出到驗證文件。
7. D02：不使用任何實驗值當輸入；使用者的 Tg、Tx 只當驗證目標，本卡不比對。

### E. 測試（手算依據來自書中）

1. 從書中 Table 6.4（計算值與實驗值對照表）與書中範例各選至少 6 個聚合物（含聚乙烯類、PMMA、聚苯乙烯、含芳香環的縮聚物各至少一個），程式算出的 Tg 必須等於書中「計算值」欄（差 ≤ 1 K）。**書中計算值欄的每一個數字都要看圖讀取確認，不得使用記憶中的數值。**
2. 每個基團的正例、反例切分測試。
3. 切分完整性測試：任何分子切完後，各基團原子數加總 = 分子重原子數，沒有重複歸屬。
4. 缺基團測試：用一個 Table 6.1 沒有的結構，確認回傳「缺基團」而不是數字。
5. 測試時不要啟動背景伺服器。

編號：029
建立日期：2026-10-31
指派給：Claude Code

## 目標

1. 以 van Krevelen 第 4 章的基團增量計算聚合物（重複單元）在 298 K 的莫耳體積與密度：非晶（玻璃態／橡膠態）與結晶。

## 要做的事

### A. 先讀懂書中定義（寫進報告，不要自行詮釋）

1. Table 4.10 兩欄（標示 Va,i 與 Vc,i，但 Example 4.1 用 Vg(298) 與 Vc 兩欄）的實際意義，以及玻璃態、橡膠態各自使用哪一欄或哪個公式；
2. 如何判斷聚合物在 298 K 是玻璃態還是橡膠態（書中的規則，是否需要 Tg）；
3. Table 4.5 適用於哪類化合物、溫度條件；
4. 以上任何一點書中沒說清楚 → 停下來回報，不要自行定義。

### B. 資料表

1. `src/data/molar_volume_polymer_groups.csv`：欄位 `id`、`基團名稱`、`SMARTS`、`欄位一`、`欄位二`（欄名依 A-1 查到的實際意義命名）、`Mi`（若表中有）、`出處`、`稽核狀態`、`備註`。
2. `src/data/molar_volume_liquid_groups.csv`：欄位 `id`、`基團名稱`、`SMARTS`、`貢獻值`（cm³/mol）、`出處`、`稽核狀態`、`備註`。
3. `出處`寫「van Krevelen & te Nijenhuis, Properties of Polymers 4th ed. (2009), Table 4.x ＋ 書頁碼」。每列都要有，缺出處報錯（D22）。
4. 只收錄下列結構需要的基團：化合物庫與配方測試資料中的聚合物重複單元、環氧單元、小分子（含 SBI），骨架範本 BT01–BT06 單元，以及驗證用聚合物（見 D）。**表中找不到的基團，數值一律留空，不得以相近基團或記憶中的數值代替**，並在報告列出。
5. 括號內的值照數值收錄，備註寫「書中印於括號內，書中標為暫定」（與任務 028 一致）。組合基團（Table 4.10 中的芳香環組合）依任務 026 的作法優先配對，並在備註標示。
6. 每讀一列，若表中同時有基團質量，與實際基團質量核對；不符就先對照 KNOWN_ISSUES（M15、M18 等書中印刷錯誤），不同的再停下來回報。
7. D22 流程：SMARTS 自行撰寫，每個基團至少一個正例分子與一個反例分子（放在測試中），稽核狀態先填「待使用者審」。

### C. 計算（`src/core/properties/`）

1. 切分方式沿用任務 026／027／028：每個重原子恰好屬於一個基團，配對順序固定可重現，配不到的原子回報「缺基團」與位置，不計算、不猜值。
2. 聚合物：莫耳體積 = Σ增量（依 A 查到的規則選欄位與公式）；密度 = 單元質量 ÷ 莫耳體積。單元質量由結構計算。非晶與結晶各自輸出。298 K 的玻璃態／橡膠態判斷依 A-2；需要 Tg 時使用任務 026 的 Tg，Tg 算不出來（缺基團）就不判斷，**兩種狀態的結果都輸出並標明「狀態未定」**。
3. 小分子液體：莫耳體積 = Σ貢獻；密度 = 分子量 ÷ 莫耳體積，單位 g/cm³。
4. 含 `*` 的結構走聚合物函式；不含 `*` 的走小分子函式。聚合物重複單元不套用液體表，小分子不套用聚合物表。
5. 回傳：莫耳體積、密度、每個基團的貢獻、出處、缺基團清單、狀態判斷依據。
6. D09：分子量不顯示在網站畫面；本卡不做畫面。D02：不使用實驗值當輸入。

### D. 測試

1. Example 4.1（PET）：玻璃態 144.2 cm³/mol → 1.33 g/cm³；結晶 131.4 → 1.465 g/cm³。程式必須重現（差 ≤ 0.1 cm³/mol 與 0.005 g/cm³）。
2. 另外從 Table 4.6、4.7、4.8 中至少選 6 個結構（含脂肪鏈、芳香環、酯基、醯胺、含環各一），程式的莫耳體積或密度與書中**計算值欄**的差在書中印刷捨入範圍內（先看該表有沒有計算值欄；沒有就用 Table 4.10 手算，過程寫進報告）。書中數值一律看圖讀取。
3. 小分子液體：書中有範例或對照表就至少 3 個，否則用 Table 4.5 手算至少 3 個結構不同的小分子（含羥基、含酯或醚、含芳香環各一），手算過程寫進報告。
4. 每個基團的正反例切分測試；切分完整性測試；缺基團測試；狀態未定時兩種結果都輸出的測試。
5. 測試時不要啟動背景伺服器。

### E. 批次輸出文件（`docs/verification/phase6-Vm-密度-輸出.md`）

1. 對化合物庫與配方測試資料中的所有小分子、聚合物重複單元、環氧單元與 BT01–BT06 單元各輸出一列：名稱、SMILES、莫耳體積、密度（聚合物：玻璃態／橡膠態／結晶，狀態未定時標註），或「缺基團：…」。
2. 檔頭註明方法、出處與「基團加成估算，非實測」。

## 要做的事

**一、資料表（D22：每列書名、表號、頁碼；SMARTS 有正反例；`review_status` 一律 `pending`）**

1. `hammett_sigma.csv`：取代基（SMARTS、名稱）、σm、σp、σ\*（Taft）、必要時 σp⁺、σp⁻（取自 Hansch Table V）、以及 ortho 值（A.5，若書給）。**只收下列「可解離基團」的式子會用到的取代基**，不整張表照抄；括號、特殊註記照書標記。
2. `pka_equations.csv`：每個可解離基團類別一列：類別名稱、可解離基團的 SMARTS（含「連接取代基的位置定義」，例如酚環上 meta、para 位置如何判定）、型式（Hammett：`pKa = 截距 − ρ·Σσ`；Taft：`pKa = 截距 − ρ\*·Σσ\*`）、截距、ρ（或 ρ\*）、使用哪一組 σ（σ、σ⁺、σ⁻）、適用範圍與備註、Perrin 原文引用的文獻。**至少涵蓋反應位點會用到的類別**：酚、芳香胺（共軛酸）、苯甲酸與芳香羧酸、脂肪羧酸、脂肪胺（共軛酸）、醇、硫醇、咪唑。**開工時逐條核對 Perrin 的 A.2／A.3 是否真有這些類別的式子**（D66 待辦）：有的收；沒有的**不收、不補**，在報告列出缺哪幾類，該類回報 `missing`。
3. 數值必須與書圖像逐一核對；對不上圖像的列不收。

**二、pKa 估算（`POST /pka`，輸出 `value/unit/source/status`）**

4. 輸入：SMILES。流程：用 `pka_equations.csv` 的 SMARTS 找可解離基團；對芳香環上的基團，找出各取代基相對於該基團的位置（ortho、meta、para），用 `hammett_sigma.csv` 取 σ，加總後代入式子；脂肪基團用 Taft σ\* 的式子（σ\* 的加總方式與衰減規則**依 Perrin 原文**，先讀原文再寫）。
5. 狀態 `predicted`；備註「水溶液 25 °C 值，只用於比較相對強弱（D38），參考趨勢」；同時輸出每個 σ 的明細（取代基、位置、σ 值、出處）與所用式子。
6. 缺值：取代基不在表中、ortho 值書沒給、環系不在 Perrin 涵蓋（例如稠環、雜環取代基位置無法定義）→ `missing` 並列原因；**不估、不內插、不用其他來源補**。

**三、反應位點相對活性排序（7.3）**

7. 對交聯第 0 層命中的反應位點（`find_group_sites`），產生**兩個分開的排序，不合成單一分數**：
   - 電子效應排序：同一官能基類別（例如各酚羥基、各胺）依 7.3a 的 pKa 估算值排序；親核位點（酚、胺、醇、硫醇）pKa 愈高（共軛酸愈弱酸）依 Brønsted 關係傾向愈強的親核性，酸性位點的排序方向在報告與 MODELS.md 寫明。只在 pKa 都算得出時排序；有 `missing` 的位點列出但不排。
   - 空間位阻排序：以 3D 構型算**反應原子的相對可及表面積**（RDKit 的標準 SASA 方法，固定亂數種子、固定構型數與優化方式，使結果可重現；參數寫在 `docs/MODELS.md`）。**這是幾何描述量，不是文獻公式**，輸出與文件都要標明；聚合物成分沿用任務 024 的重複單元片段做法，做不到的成分回報 `missing`。
   - 兩個排序各自附「參考趨勢」，**不得自行訂權重合併**。
8. 介面：交聯頁成分詳細彈窗新增「位點活性」表：位點、基團類別、pKa 估算（附 σ 明細）、可及表面積、各自的排名；缺值顯示原因。分子工具若方便可顯示單一分子的 pKa；沒有就只放在交聯頁。沿用現有元件，不重做設計；橋接白名單加入新端點。
9. 文件：`docs/MODELS.md` 新增條目（公式、σ 加總規則、適用、限制、出處「待使用者審」、SASA 參數）；`docs/PLAN.md` 7.3、7.3a 勾選並補註（缺類別則依實際勾選）。

**四、驗證（全部完成後只做一次，用書自己的算例）**

10. 用 Perrin 書中**自己給的算例與對照表**（書中以 σ 預測 pKa 並對照實驗值的例子、Table 1.2／3.1／3.2 中可由式子算出的列）重現書的計算值；能算幾個算幾個，結果整理進 `docs/verification/phase7-pKa-輸出.md`（每個分子：書的預測值或實驗值、本卡值、差；「使用者判定」欄留空）。算不到書中數值（差超過書顯示的精度）→ 先檢查謄錄，仍不符就停下來回報，不調整數值去湊。**不把使用者自己的任何實測值當輸入**（D02）。
11. 最少的單元測試：端點可用、手算一個 Hammett 例子（附算式）、一個 Taft 例子、取代基不在表中回報 `missing`、不涵蓋的環系回報 `missing`、排序在有 `missing` 時不排序、SASA 固定種子重現同值。不做反向驗證與邊界探針。
12. 報告 `docs/reports/P7-5-結果.md`，限一頁：收了哪些類別、Perrin 沒有的類別（D66 核對結果）、書算例對照結論、SASA 參數、需要使用者決定的事。
13. 本機只跑本卡新增的測試、引擎 pytest、型別檢查；全部 TypeScript 測試與建置交給 CI。新增測試字串一律用雙引號。新增或修改 `src/data/` 後，先重產所有受影響的 golden 檔（`csv.json` 等，只允許多出新項目、舊值不得變）。commit、push，用 PowerShell 查 CI，逐一確認 build、engine、golden-fresh 三個 job 成功。

# 任務 037：用 Bondi (1964) 補 VW 的缺基團（Phase 6.4 補充）

編號：037
建立日期：2026-11-06
指派給：Claude Code

## 目標

van Krevelen Table 4.2 的 VW 基團表缺少使用者材料與半導體材料常見的基團（茀骨架、環氧基、碳酸酯、聚醯亞胺、PBO、金剛烷基酯、內酯等），這些材料的 VW、密度、介電、CTE 目前都回報「缺基團」。Bondi (1964) J. Phys. Chem. 68, 441 的 Table XV、XVI、XVII 是 VW 的原始來源（書的表由它而來），本卡用它補書裡沒有、但 Bondi 有明確基團增量與修正量的部分。**書的值優先；Bondi 只補書沒有的；Bondi 沒有明確值的基團維持「缺基團」，不得自行組合猜值。**

前提：任務 036c 已 push（CI 的 deploy 逾時不是程式問題，build 成功即可）。

## 要做的事

### A. 先盤點（寫進報告，數值只取自看過的頁面）

1. 列出 Bondi Table XV、XVI、XVII 的全部基團與修正量（含頁碼），與 `vw_groups.csv` 逐列對照：哪些與書相同、哪些書沒有、哪些數值不同（差異百分比）。
2. 針對下列結構，逐一判斷 Bondi 是否有「明確的基團增量加明確的修正量」可以算：茀骨架（9,9-二取代茀）、環氧基（三員環醚）、碳酸酯、醯亞胺環（PI）、苯并噁唑環（PBO）、金剛烷基與籠狀脂環、內酯（環內酯基）、酚 OH、其他書缺的基團（以現有輸出的「缺基團」清單為準）。每個結構寫出：能算／不能算、用哪幾個基團增量與哪一個修正量（Table XVII）、依據的頁碼。**Table XVII 沒有對應修正量的環系統（例如三員環、五員雜環、籠狀環），一律判「不能算」，維持缺基團。**
3. 「能算」的判斷若需要自行詮釋（例如把酯基在環內視為 C=O 加環內醚 O），寫出詮釋並停下來問我，不要直接採用。

### B. 資料表與計算（只做 A 判為「能算」且無需詮釋的項目）

1. 新增 `src/data/vw_groups_bondi.csv`（不得修改 `vw_groups.csv` 的任何數值）：欄位沿用 `vw_groups.csv`，另加 `來源等級`（Bondi 1964 原始論文）、`修正量`；每列有出處與頁碼、稽核狀態「待使用者審」，缺欄位報錯（D22）。SMARTS 自行撰寫，每個基團至少一個正例與一個反例。
2. 配對順序：先用書的基團（現行規則、M26 未決不得改動）；只有書配不到的原子才用 Bondi 補充；補充基團參與的結果必須標「含 Bondi 補充基團（非書值）」。
3. 修正量（Table XVII）：只在 A 判定可套用時才套用，輸出列出每一項修正的次數與數值。
4. 回傳與輸出：VW 與其下游（密度、介電、CTE 等沿用現有函式，不改公式）；缺基團清單縮減後的剩餘部分照舊回報。
5. 修正 `vw_groups.csv` 的 V25 備註（只改備註文字，不改數值）：Bondi 有 >CH–（6.78），備註更正為與 Bondi 一致的敘述；請先看圖確認。
6. `docs/DECISIONS.md` 新增 D59：「VW 缺基團以 Bondi (1964) 補充，書的值優先；補充結果標示非書值；Bondi 沒有明確基團與修正量者維持缺基團」，來源：使用者 2026-11-06 同意以 Bondi 補（Claude 提議）；更新檔頭日期。

### C. 測試

1. 回歸：用 Bondi 補充後，書已有的結構（苯、醚、酯等）VW 與現行輸出逐字相同（補充基團不得搶走書能配的原子）。
2. 與 Bondi 的比較：Bondi 論文中若有化合物 VW 例子，用補充後函式算同一化合物，與 Bondi 值比較（只作驗證，不當輸入）；無例子就用手算並寫出算式。
3. 每個新基團的正反例；缺基團測試（A 判為不能算的結構仍回報缺基團）；切分完整性測試。
4. 測試時不要啟動背景伺服器。

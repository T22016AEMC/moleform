# 任務 I01：介面接引擎（桌面版啟動引擎、橋接、最小物性面板）

編號：I01
建立日期：2026-11-16
指派給：Claude Code

## 目標

目前所有物性計算都在 Python 引擎（M00～M05、P6A），但介面沒有任何入口呼叫它們（039a U3）。本卡讓桌面版能實際用到：（1）桌面程式啟動時自動啟動引擎、結束時關閉；（2）介面透過受限橋接呼叫引擎；（3）一個最小的「物性」面板，顯示結果。**介面美化留到全部功能完成後（D45），本卡只求能用、不重做設計。** 依 D64：一次做完、驗證一次、報告一頁。

## 前置條件（先讀這些）

- `docs/reports/039-結果.md`（引擎啟動、握手、權杖、app:// 載入的做法）、`docs/reports/M05-結果.md`、`docs/reports/P6A-結果.md`、`docs/migration-known-issues.md` 的 D04（輸入契約）
- `desktop/`（Electron 主程式、preload）、`engine/` 的伺服器入口與端點清單
- 介面現況：只讀 `src/ui/` 中與「結果顯示」「配方工作台」「聚合物單元編輯」有關的檔案，以及 `src/worker/` 的請求格式；用目錄列表加 grep，不要搜尋整個專案
- `docs/DECISIONS.md` 的 D45、D62、D63、D64

## 要做的事

1. **引擎生命週期**：Electron 主程式在視窗開啟時啟動引擎（沿用 039 的隨機埠與一次性權杖，只監聽 127.0.0.1），程式結束時一併關閉並釋放埠。引擎 Python 沿用開發環境的 `engine/.venv`；**內嵌打包是之後另一張卡（D63），本卡不做**。引擎啟動失敗時，介面顯示明確訊息，其餘功能照常。
2. **受限橋接**：用 preload 暴露單一函式（例如 `window.moleformEngine.call(path, body)`），由主程式代為對引擎發 HTTP；主程式端只允許白名單內的路徑（`engine/` 現有端點），權杖不暴露給網頁內容。保持 `contextIsolation: true`、`nodeIntegration: false`、網路封鎖不變。
3. **最小物性面板**（沿用現有元件與樣式，不新增設計系統）：
   - 對象：單一聚合物單元／小分子、以及配方（混合）。
   - 單一對象顯示：VW、Tg、Vm／密度、CTE、自由體積、介電常數與極化率、Tb／Tf（小分子）、TPSA／LogP。每項顯示 `value`、`unit`、`source`、`status`；缺基團或算不出的項目顯示 `missing` 與原因（缺哪些基團），不得隱藏。
   - 配方（混合）顯示：成分 Tg 與混合 Tg、混合密度、混合介電常數。引擎需要的輸入（質量分率、Mn、每分子質量，D04）由介面端以現有 TypeScript 的 `formulation/compute` 換算後傳入。
   - 共聚比例掃描、相對 Tg、交聯第 0／1 層的新入口**不在本卡範圍**（交聯現有介面維持 TS）。
   - 非桌面環境（例如純網頁的 `npm run dev`）：面板顯示「需要桌面版與引擎」，不報錯。
4. **TypeScript 版物性計算**維持原狀，仍只作為黃金標準，介面不呼叫它們。
5. **測試**（最少）：橋接白名單的單元測試（允許路徑通過、非白名單與非 127.0.0.1 目標被拒）；面板輸入轉換（介面狀態→引擎請求）的單元測試。不做反向驗證、不加邊界探針。
6. **一次性實測**：以桌面版實際啟動，對一個聚合物單元算出 Tg 與 Vm，確認結果與引擎直接呼叫相同；關閉程式後確認引擎行程與埠已釋放。把這一步與結果寫進報告。
7. 報告 `docs/reports/I01-結果.md`，限一頁：做了什麼、實測結果、介面還缺什麼、需要使用者決定的事。更新 `docs/PLAN.md`（6A 補註：介面接引擎完成）。
8. 本機只跑本卡新增的測試、型別檢查、`npm run desktop:build` 與實測；全部 TypeScript 測試與建置交給 CI。commit、push，只查一次 CI。

## 不可更動的檔案或規則

- 不修改 `src/core/` 的計算與資料表、既有測試、既有 CI job；引擎的計算與端點行為不改（缺端點才加，並說明）
- 不重做介面設計；不引入新的 UI 套件
- 引擎只在 127.0.0.1 內部連線，不對外；不得放行任意 URL；測試後不要留下背景程式
- 不使用記憶中的數值與版本號；不更改已定案決定

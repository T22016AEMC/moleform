# 任務 033：以文獻錨點校準書中沒有的 Yg 基團（酚羥基、SBI 骨架、茀骨架）

編號：033
建立日期：2026-11-01
指派給：Claude Code

## 目標

van Krevelen 沒有酚羥基、螺雙茚滿（SBI）骨架、9,9-二芳基茀骨架的 Yg 值，所以酚醛、SBI、Cardo 類結構算不出 Tg。本卡用**文獻中的聚合物當錨點**反推這些基團的 Yg，再用**另一個獨立文獻聚合物檢驗**，通過才收錄。另外用苯氧樹脂直接檢驗現有方法對 BT05 型單元的準確度。

前提：任務 032 已完成（commit f78ecf0、7b66b95）。本卡只做 Yg（Tg）；環氧環、酚醛與環氧寡聚物的分子量依存、PGMA 縮水甘油基不在本卡（資料不足，見 `docs/references/INDEX.md` 第五節）。

### B. 錨點與檢驗資料（全部看圖讀取，寫進報告附頁碼）

1. 每個錨點與檢驗聚合物：結構（重複單元 SMILES）、Tg 數值、量測方法（DSC 中點等）、分子量（Mn 或 Mw）、論文作者／期刊／年份／表號或頁碼。
2. **分子量規則**：書中 Yg 對應高分子量的 Tg（Tg∞）。只用下列兩種數據：(a) 論文給出的 Tg 對 1/Mn 迴歸的截距（Tg∞）；(b) 論文明確是高分子量樣品（報告寫出 Mn 或 Mw 並說明為何視為高分子量）。**不得自行假設 Fox–Flory 的 K 值去修正低分子量數據。**
3. 同一論文內有「目標聚合物」與「雙酚 A 類比聚合物」對照時，優先用差值法（見 C-3），可抵消連接基團（例如碳酸酯）的不確定性。

### C. 校準方法

1. **酚羥基（芳香環上的 –OH）**：定義為 Table 6.20 型的「H 換成 –OH 的增量 ΔYg」（芳香環上）。錨點：Kratochvíl 等 (Eur. Polym. J. 2009) 式 (1) 的截距 Tg∞，ΔYg = Yg(PVPh 單元) − Yg(聚苯乙烯單元，書中值)。檢驗：Shin & Ryu (Polym. Chem. 2025) 的 PHS（若分子量不符合 B-2 就改用其他符合者，例如 Kuo 等 2003 圖 5 的 PVPh，並說明）。
2. **SBI 骨架**（3,3,3',3'-四甲基-1,1'-螺雙茚滿-6,6'-二基，兩個芳香連接點）：錨點用 Stueben (J. Polym. Sci. A 1965) Table IV。
3. **差值法**（SBI 與茀都優先用）：若同一論文同時給目標聚合物與雙酚 A 類比，Yg(新骨架) = Yg(雙酚 A 骨架，書中 Table 6.3 值) + [Tg(目標)·M(目標) − Tg(BPA 類比)·M(BPA 類比)] ÷ 1000（Tg 用 K，M 用結構單元 g/mol）。連接基團相同時自動抵消。報告寫出每一步。
4. **SBI 檢驗**：用 Stueben Table IV 另外的 SBI 聚合物（至少兩個，結構看圖讀取），以校準後的骨架 Yg 加上書中其他基團計算 Tg，與論文值比較。
5. **茀骨架**（9,9-雙(4-伸苯基)茀，兩個芳香連接點；與 BT06 的骨架相同）：從 INDEX 第二節的含茀論文中選一個錨點（優先：同論文有 BPA 類比可用差值法者；其次：單元其他基團全在書中表內者），另一篇論文的聚合物當檢驗（至少兩個）。選擇理由寫進報告。含羥乙氧基（BPEF）等間隔基者，間隔基須能由書中基團表示才可使用。
6. **苯氧樹脂直接檢驗（不校準）**：用現有方法計算 BT05 型苯氧樹脂單元的 Tg，與兩篇文獻（J. Anal. Appl. Pyrolysis 2011 的 DSC 值；Kuo 等 2003 圖 5 純苯氧樹脂）比較，報告差值與可能原因。**不要因此調整任何現有值**。
7. 每個校準值：錨點本身必須能反推回錨點 Tg（自洽測試）；檢驗誤差 ≤ 20 K 才收錄；任一檢驗超過 20 K → 不收錄，停下來回報。

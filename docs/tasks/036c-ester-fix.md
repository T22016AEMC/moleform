編號：036c
建立日期：2026-11-06
指派給：Claude Code

## 目標

036b 報告指出：使用者表的酯基 23 比書的 –COO–（15.2）大 51.3%，比 Bondi 參考和（>C=O 11.70 ＋ 烷基醚 3.7 ＝ 15.40）大 49.4%。使用者說明 xlsx 是逐原子拆開算的，23 是兩個 O（羰基 O ＋ 單鍵 O）的值，羰基碳另計為鏈 C；這個值沒有出處，兩個獨立來源都不支持。使用者 2026-11-06 授權：**哪個正確就用哪個。** 決定：酯基整組 –C(=O)–O– 改用書的 –COO– 值 15.2（有出處）。酮 10.8、醛 11.5 維持 036b 的整組處理（與 Bondi 11.70 同範圍）。

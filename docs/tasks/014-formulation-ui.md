# 任務 014：配方畫面、存檔與 Phase 3 驗證清單（Phase 3.1、3.4–3.7）

建立日期：2026-10-29
指派給：Codex／Claude Code

## 目標

網站新增「配方」頁：使用者可以建立 Solid／Liquid 兩區配方、從化合物庫或目前結構加入成分、選單位、填用量，即時看到 wt%、mol%、phr、總重與 Solid Content；錯誤以中文顯示在對應欄位旁；配方可以存在瀏覽器、匯出匯入。並產出 Phase 3 使用者驗證清單。

## 要做的事

### A. 任務 013 的修正（使用者 2026-10-29 決定）

1. **mol% 不輸出部分基準**：某區只要有任何成分無法換算 mol%（含 `*` 或缺分子量），**整區都不輸出 mol%**，所有成分的 mol% 為不適用，並附原因「{成分名稱} 無法換算 mol%（{原因}），本區不提供 mol% 以免數值不完整」。移除 `MOL_PARTIAL` 的部分基準行為；更新測試與 `docs/reports/013-結果.md` 第 3 節第 2 點（註明已依使用者決定修改）。
2. 任務 013 報告第 3 節的其他判斷，使用者都同意；在報告第 3 節開頭補一行「使用者 2026-10-29 確認：除第 2 點已修改外，其餘照現狀」。

### B. 版面

3. 頁首下方加兩個分頁：「結構」（現有的結構輸入、3D、我的化合物）與「配方」。分頁樣式沿用 CheMScutter 的按鈕組（D34）。切換分頁時不清除各頁的內容。

### C. 配方輸入（3.1）

4. 「配方」頁上方：配方名稱、Solid 區、Liquid 區，兩區各一張卡片。
5. 每區：
   - **區域單位**下拉選單（D36）：Solid 為 g、重量份、wt%、mol%、phr；Liquid 為 g、重量份、wt%、mol%、vol%（選 vol% 時顯示「vol% 需要溶劑密度，將於 Phase 8 提供」，不計算）
   - **成分表**，每列：名稱、結構（顯示 canonical SMILES，過長截斷）、分類下拉選單（Solid 七類含 Catalyst/Initiator，D26；Liquid 三類）、用量（單位標在輸入框內）；Solid 另有「樹脂」勾選（D37）與「會揮發／分解」勾選
   - 可新增、刪除、上下移動成分；刪除用畫面內確認，不用瀏覽器對話框
   - **加入成分**三種方式：從「我的化合物」選、使用「結構」分頁目前的結構、直接輸入 SMILES（經任務 010 的驗證，不合法就不能加入）
   - 選填「該區總重（g）」
6. 配方頁下方：選填「目標 Solid Content（%）」。

### D. 計算與結果（3.2–3.5）

7. 分子量由 RDKit Worker 計算後傳給 `computeFormulation`；**分子量不得出現在畫面上**（D09）。
8. 輸入改變時即時重算（可延遲約 0.3 秒避免頻繁計算）。
9. **結果區**：
   - 每區一張表：成分、質量（g，有時才顯示）、wt%、mol%、phr（Solid 有勾樹脂時）；不適用的格子顯示「—」，滑過顯示原因
   - 整體：Solid 質量、Liquid 質量、總重、Solid Content（全部）、Solid Content（扣除標記成分）、目標 Solid Content 反推的 Liquid 總量與各溶劑用量
   - 表格上方標示模型名稱「配方換算」與可信度「直接計算」，下方顯示統一備註（D03；沿用任務 008 的元件或樣式）
10. **錯誤與警告**（3.4）：顯示在對應的欄位或成分列旁（紅色為錯誤、橙色為警告，顏色取自 `theme.css`），結果區頂端另列一份總表；點總表的項目可捲動到對應欄位。

### E. 存檔與讀檔（3.6，D23）

11. 「我的配方」：仿照「我的化合物」，用 IndexedDB 儲存（另開一個 object store 或資料庫，**不要動到化合物庫的資料**），功能：儲存、另存、清單、搜尋、載入、改名、刪除、上次備份（JSON）。
12. 配方檔案內含每個成分的 canonical SMILES 與 Molfile（若有），**不依賴化合物庫**也能完整還原；用任務 013 的序列化函式。
13. 匯出 JSON（`moleform-formulations-YYYYMMDD.json`，可全部或單一配方）、匯入 JSON（合併規則比照化合物庫）。
14. 儲存失敗時的提示比照化合物庫。

### F. 測試

15. 依任務 A 修改 `tests/formulation/` 的 mol% 測試。
16. 新增 `tests/formulation-library/`：配方庫的儲存、合併、匯出匯入來回不變（用記憶體版儲存層）。
17. 畫面互動若可用無頭瀏覽器自動檢查，至少檢查：新增成分、改單位、合計不為 100 時出現錯誤、存檔後重新整理仍在；結果寫進報告（不能取代使用者確認）。

### G. Phase 3 使用者驗證清單（3.7）

18. 寫腳本 `scripts/verification/phase3.ts`（比照 Phase 2，`npm run verify:phase3`），對下列**示範配方**執行換算，輸出 `docs/verification/phase3-輸出.md`：
    - 配方 1（重量份，兩區）：Solid：BADGE `CC(C)(c1ccc(OCC2CO2)cc1)c1ccc(OCC2CO2)cc1` 100（勾樹脂）、雙酚 A `CC(C)(c1ccc(O)cc1)c1ccc(O)cc1` 60、三苯基膦 `c1ccc(P(c2ccccc2)c2ccccc2)cc1` 1（Catalyst/Initiator）；Liquid：甲基乙基酮 `CCC(C)=O` 40
    - 配方 2（Solid 用 wt%）：同上三種 Solid，wt% 為 62.11／37.27／0.62（即 100：60：1 換算，合計 100.00），填 Solid 總重 100 g；Liquid 用 g：甲基乙基酮 40
    - 配方 3（Solid 用 phr）：BADGE 100（樹脂）、雙酚 A 60、三苯基膦 1；無 Liquid
    - 配方 4（目標 Solid Content）：配方 1 的 Solid，目標 Solid Content 60%，Liquid 為甲基乙基酮與丙二醇甲醚醋酸酯 `COCC(C)OC(C)=O`，重量份 1：1
    - 配方 5（含揮發標記）：配方 1，把三苯基膦標記為會揮發／分解
    - 每個配方輸出：輸入內容、各成分的**分子量**（僅在此驗證文件中列出，供使用者手算 mol%；網站上不顯示，D09）、程式算出的全部結果、錯誤與警告
    - 檔案開頭照抄：「以下為程式輸出，未經化學判斷。請使用者以手算或其他工具核對（D17）。示範配方僅用於驗證換算，不代表建議配比。」
19. 使用者檢查結果之後寫在 `docs/verification/phase3-使用者檢查.md`（本任務先建立空檔，內含標題與「待使用者填寫」）。

- 網站上不得顯示分子量、官能基數量或當量（D09）；分子量只能出現在 `docs/verification/` 的驗證文件

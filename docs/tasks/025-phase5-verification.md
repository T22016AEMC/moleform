## 要做的事

### A. 範本卡片顯示條件（使用者 2026-10-30 同意）

分子工具中只有「範本選單」的聚合物設定卡片：結構空白，或結構含 `*` 時顯示；輸入一般小分子（不含 `*`）後隱藏。加入成分彈窗照同樣規則。`docs/DESIGN.md` 補上。

### B. 瀏覽器確認清單（`docs/verification/phase5-使用者檢查.md`）

1. 來源：任務 020、020 後續、021、021 後續、022、023、024、024 後續報告中所有「請使用者在瀏覽器確認」的項目。
2. 整理規則：
   - 已被後來任務改掉的行為，以**最新行為**為準，舊項目刪除或改寫（例如：任務 023 的「選範本一定先確認」已由 024 後續改為只在 D-2 情況才問；任務 021 後續的 K12 限制已由 024 後續處理）。
   - 重複項目合併。
   - 依畫面分組：分子工具／加入成分彈窗／成分詳細彈窗／配方工作台（目標固含量）／交聯結果／化合物庫與存檔／舊檔相容。
   - 加入本任務 A 的項目。
3. 格式：表格，欄位為「編號、操作、預期結果、來源任務、結果（使用者填）、備註（使用者填）」。結果與備註欄留空。
4. 清單開頭寫明：使用的測試成分與 SMILES 照 `phase4-測試體系.md`，不必另外準備。

### C. 計算值輸出（`scripts/verification/phase5.ts`，`npm run verify:phase5` → `docs/verification/phase5-輸出.md`）

格式比照 `phase4-輸出.md`，開頭註明「以下為程式輸出，未經化學判斷；官能基當量只列在本文件供核對，網站上不顯示（D09）」。

1. **測試成分**：P（2:1 共聚物，Mw 6000、PDI 1.8）、E（Mw 4500、PDI 預設 2）、S（小分子）。每個成分列出：
   - 每重複單元（共聚物為平均單元）的質量、反應官能基種類與數量
   - **官能基當量（g/eq）**：每重複單元基準 = M_unit ÷ 每單元官能基數；每鏈基準 = Mn ÷ 每鏈官能基數（含端基）。小分子 = 分子量 ÷ 官能基數
   - Mn、Mw、DP_n、DP_w
2. **骨架範本 BT01～BT06**：每個範本列出單元質量、端基質量合計、每單元與每端基的反應官能基數，以及下列分子量下的每鏈官能基數與當量：
   - n = 0 分子（只有端基）
   - Mn 500、Mw 1000（PDI 2）：是否啟用低分子量近似、兩成分的 M 與重量分率
   - Mn 3000、Mw 6000（PDI 2）
3. **手算核對**（寫在輸出中，程式值旁列手算值與差）：
   - P 酚羥基當量（每平均單元，精確 2:1）：M̄_unit ÷ (4/3) ≈ 279.00 ÷ 1.3333 ≈ 209.25 g/eq（以 66.67／33.33 輸入時差小於 0.05）
   - E 環氧當量（每單元）：GMA 單元 C₇H₁₀O₃ ≈ 142.15 g/eq
   - S 酚羥基當量：C₂₁H₂₄O₂ ≈ 308.42 ÷ 2 ≈ 154.21 g/eq
   - BT05 n = 0（DGEBA）環氧當量：≈ 340.41 ÷ 2 ≈ 170.2 g/eq
   - 差超過 0.1% 時停下來回報，不要調整程式
4. 第 1 層結果不重新列出（已在 `phase4-輸出.md`），只寫「見 phase4-輸出.md」。

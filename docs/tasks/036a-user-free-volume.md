# 任務 036a：使用者定義的經驗自由體積法（Vf = Vω × 經驗係數）

編號：036a
建立日期：2026-11-06
指派給：Claude Code

## 目標

van Krevelen 書中沒有「由結構算自由體積」的方法（任務 036 的報告已確認）。使用者依論文整理了一套經驗法，現在收進 MoleForm，作為**獨立的一項輸出**：

> 自由體積 Vf = 分子（聚合物為重複單元）的凡德瓦體積 Vω × 經驗係數

這是使用者定義的算法（使用者 2026-11-06 決定），不是書中的自由體積分率，也不用於 CTE 的計算。本卡只做這一項，不做其他物性。

前提：任務 036 已完成（CTE 等）。

### 使用者 2026-11-06 的規則

1. **一個單體（重複單元）只選一個係數**，整個單元的 Vω 乘上去（例如 PHS 單元整個乘 0.37）。
2. 預設優先順序（待使用者審）：SBI 螺環骨架 0.7 ＞ 橋環或籠狀脂環 0.8 ＞ 含任何芳香環 0.37 ＞ 其餘 1。
3. **共聚物以單體的莫耳比加權**：例如 a:b = 7:3，Vf = Vf(a)×0.7 ＋ Vf(b)×0.3；Vω 同樣按莫耳比加權。比例基準沿用任務 020 的無規共聚物組成（莫耳分率）。
4. 聚合物只算重複單元；小分子算整個分子（D56 只限制 Tg，不限制本項）。

### C. 計算（`src/core/properties/`）

1. 把單元的每個重原子（連同其氫）配到 19 個基團之一；芳香碳一律計為「芳香族 C」（8.11，含氫，不分有無取代）（配對規則固定、可重現；環氧環的碳依 xlsx 例子計為環脂肪族 CH／CH₂，環氧基 O 單獨計）；配不到回報「缺基團」。
2. 依規則選一個係數（SMARTS 辨識 SBI 螺環骨架、橋環或籠狀脂環、芳香環）；辨識結果寫進輸出，方便使用者檢查。
3. Vω ＝ Σ(基團數 × 基團 Vω)；Vf ＝ Vω × 係數。
4. 共聚物：沿用任務 020 的組成，Vf、Vω 按莫耳分率加權；單元缺基團則整體回報缺基團，不略過。
5. 回傳：Vf、Vω、係數與其類別、各基團貢獻、缺基團清單、出處；Vf／Va 比值另列（Va 取任務 029 的結果，標明「用書的 Va 計算，非使用者定義」），Va 缺就只標缺。

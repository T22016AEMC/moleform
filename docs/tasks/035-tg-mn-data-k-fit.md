# 任務 035：Tg–Mn 文獻資料入庫與 K 擬合（甲酚酚醛、BPA 環氧鏈、ECN 與 PGMA 登錄）

編號：035
建立日期：2026-11-06
指派給：Claude Code

## 目標

任務 034 的 K 只有「一般苯酚酚醛」一類（Mn 780–1535，低可信度），DGEBA 類缺 K。本卡把使用者 2026-11-06 提供並核對過原文的文獻 Tg–Mn 數據入庫，擬合甲酚酚醛（鄰位、對位兩種）的 Tg∞ 與 K，評估 BPA 環氧鏈類別，登錄 ECN 與 PGMA 數據（不擬合）。只做資料、擬合與類別比對，不改混合公式。

前提：任務 034 與 D56 修正已完成（CI #64 成功）。

## 要做的事

### A. 資料表

新增或擴充 Tg–Mn 資料表（沿用 034 的欄位格式）：每列有類別、Tg、Mn、Mn 的種類與方法、Tg 方法、端基、來源等級、出處、頁碼，缺欄位報錯（D22）。**Mn 方法（NMR、GPC-PS 等）不同的資料不得混在同一次擬合。**

### B. 甲酚酚醛的擬合（鄰、對各一類）

1. 對每種異構物以 Tg 對 1/Mn 做線性回歸，同時得 Tg∞ 與 K（4 點、2 參數），報告 Tg∞、K、標準誤差、R²、殘差。檢查是否線性（鄰位 Mn 1380→2250 只升 12 K，注意曲率）。
2. 獨立檢驗：用鄰位的擬合預測對位 4 點（以對位自己的 Mn），反之亦然；誤差 ≤ 20 K 才收錄。兩個異構物若各自擬合合理，再報告合併擬合是否可行（Tg∞、K 差異是否在不確定度內），由使用者決定要不要合併。
3. 適用範圍 Mn 490–2250，超出標「外推，未驗證」；K 與 Tg∞ 成對使用；端基（2,6-二甲基酚封端）寫入資料表，標明 K 不得當作所有酚醛的通用值。
4. 與 034 的苯酚酚醛結果並列比較（Tg∞、K、Mn 範圍），只寫差異，不調整任何現有值。
5. 類別辨識：用 SMARTS 辨識「甲酚酚醛重複單元」（鄰、對），依 D22 配正反例測試（含苯酚酚醛、茀／萘酚醛為反例），未辨識為此類的聚合物不得使用此 K。

### C. BPA 環氧鏈類別（候選，不一定收錄）

1. 資料點：EP3874001A1 雙酚 A 環氧（Mn 720，Tg 38 °C，GPC-PS）、苯氧樹脂兩點（Mn 1.5×10⁴、2.3×10⁴）。
2. 擬合 Tg∞ 與 K 並報告；**三點兩參數沒有獨立檢驗點，依任務卡規則不收錄 K**，只作參考表。若 Mn 方法不同（GPC-PS 對 GPC-THF），列出此差異。
3. 以參考擬合計算 EPON 1001F、1004F、1007F 的 Tg（Mn 由 McAninch Table 4.1 的平均 n 算），檢查順序是否為 1001F < 1004F < 1007F，並與 INDEX 的 AI 整理截圖順序比對；結果標「參考，未收錄」。
4. 與 BT05 的基團貢獻值（125.7 °C）比較，寫出差異，不調整任何現有值。

### D. ECN 與 PGMA

1. ECN：一個點，不擬合；報告它與同 Mn 範圍的鄰甲酚酚醛（Mn 930、Tg 76 °C）的差異，作為「環氧化降低 Tg」的觀察，不推導 K。
2. PGMA：登錄兩組數據，報告它們為何不符合 Fox–Flory（含鏈終止劑），**不擬合 PGMA 的 K**。

### E. 輸出與測試

1. 更新 `docs/verification/phase6-Tg-混合-輸出.md`：新增「甲酚酚醛」類別的成分 Tg 計算（用 Lin-Gibson 的 Mn 當輸入，與文獻 Tg 比對的是擬合殘差而非獨立驗證，需標明）。
2. 測試：回歸公式對手算、類別 SMARTS 正反例、Mn 範圍外標示、資料表格式檢查。
3. 不要啟動背景伺服器。

# 任務 036b：經驗自由體積法的羰基基團修正（任務 036a 的後續）

## 目標

任務 036a 把酮類 =O（10.8）、醛類 =O（11.5）、酯基 =O–O（23）解讀成「只算氧」，羰基碳另計為脂肪族 C（3.33）。Bondi (1964) Table XVI（p.450）的 >C=O 為 11.70，已經包含羰基碳；使用者表的 10.8、11.5 與它同一範圍。使用者 2026-11-06 授權：**若與論文敘述不同，改為論文的敘述。** 本卡把三個羰基類基團改為「整個官能基（含羰基碳），羰基碳不另計」。

- `docs/references/Bondi_1964_J._Phys._Chem._68_441_451.pdf`（p.450 Table XVI 的 >C=O 11.70，請看圖確認頁碼與數值）

## 要做的事

1. 酮、醛：基團值維持 10.8、11.5，改為「整個羰基（C=O）」；比對時羰基碳被該基團吃掉，不再另計為脂肪族 C。資料表基團名稱與備註改寫：「依 Bondi (1964) Table XVI，羰基增量含羰基碳；使用者 2026-11-06 授權改用論文敘述」。
2. 酯基：Bondi 沒有對應值，使用者表的 23 來源未註明。**使用者 2026-11-06 說明：酯基＝C=O ＋ 單鍵的 O（整組 –C(=O)–O–）。** 因此整組算 23：羰基碳、羰基 O、酯基單鍵的 O 都被吃掉，**單鍵的 O 不得再另計為醚類 O（3.7），羰基碳也不另計**；酯基另一側的碳（烷基或芳基碳）照原本的碳規則。另請拿 Bondi 的 >C=O（11.70）加醚 O（Table XVI 對應值，請看圖讀取）算一個參考和，與 23 比較並寫入報告（只報告，不修改 23）。請拿 `vw_groups.csv` 書中的 –COO– 值與 23 對照，列出差異百分比，並在報告標「來源待使用者確認」。不要修改 23。
3. 修改 SMARTS 與配對順序，使這三類基團把羰基碳一併吃掉；補每個基團的正反例測試（含酮、醛、酯、羧酸酯、醯胺不誤配）。
4. 更新 xlsx 回歸測試的期望：含酮、醛、酯的列，鏈 C 數會少 1；列出每列修正前後的基團數與 Vω、Vf；仍然不把疑點列當期望值。
5. 重新產生 `phase6-自由體積-經驗係數-輸出.md`，報告附前後差異表（只列因本卡而變的列）。
6. 環碳歸類規則（非芳香環上的碳用環值，其餘用鏈值）維持不變，不在本卡處理。
7. `docs/reports/036b-結果.md`：改了哪些檔案、前後差異、酯基對照結果、需要使用者決定的事。commit、push，確認 CI。

# 任務 036：自由體積分率與熱膨脹係數 CTE（Phase 6.4 的第三批）

編號：036
建立日期：2026-11-06
指派給：Claude Code

## 目標

1. 以 van Krevelen 第 4 章的方法，計算聚合物（重複單元）的**自由體積分率**。
2. 以書中的方法，計算**熱膨脹係數 CTE**（玻璃態與橡膠態各自的值，依書中定義）。
3. 做核心函式與批次輸出文件，不做畫面。

CTE 對半導體封裝（EMC、底填膠、介電層）的熱應力很重要（D53）；自由體積分率與 SBI、茀類骨架的自由體積問題直接相關。

前提：任務 035 已完成（CI #66）。本卡只做自由體積分率與 CTE。Tm、Td（任務 037）、彈性模數與吸濕性（6.5）、混合密度與混合介電常數（6.7 其餘部分）不在本卡。範圍以 `docs/PLAN.md` 的 6.4 為準，不得加做其他項目。

## 要做的事

### A. 先讀懂書中定義（寫進報告，不要自行詮釋）

1. 自由體積（或自由體積分率）在書中怎麼定義：用哪些體積量（Va、Vc、VW、佔有體積等）、乘數或係數、適用溫度（Tg 時的值、室溫的值，或隨溫度變化的式子）。
2. CTE 在書中怎麼估：用基團加成、由莫耳體積或 VW 推算、由 Tg 推算（Simha–Boyer 規則），或是直接給表。玻璃態與橡膠態的區別、線性與體積膨脹係數的關係與單位。
3. 計算需要哪些輸入（Tg、Va、Vc、VW、其他）、其中哪些我們已經有（任務 026、029、033），哪些需要實驗值。
4. **書中任何一點沒說清楚、或方法必須用實驗輸入（例如實測密度、實測 Tg、實測膨脹係數）→ 停下來回報，不要自行定義或用實驗值替代（D02）。**
5. 書頁 90、100 附近的 Simha–Boyer 規則（Δα·Tg ≈ 0.115 左右、散布約 37%）：書中有明文警告這類經驗規則不得互相代入推新式，請照書的限制使用。

### B. 資料表（只有書中需要新增的表才建）

1. 若 A 發現書中有 CTE 或自由體積的基團增量表，新增 `src/data/` 資料表，欄位格式沿用任務 029／032：`id`、`基團名稱`、`SMARTS`、數值欄（單位依書）、`出處`、`稽核狀態`、`備註`。
2. 出處寫「van Krevelen & te Nijenhuis, Properties of Polymers 4th ed. (2009), Table x.x ＋ 書頁碼」；每列有出處，缺出處報錯（D22）。
3. 表中找不到的基團，數值一律留空，不得以相近基團或記憶中的數值代替，並在報告列出。
4. 若書中方法完全由 Va、Vc、VW、Tg 推得（沒有新的基團表），就不新增資料表，只寫函式。
5. D22 流程：SMARTS 自行撰寫，每個基團至少一個正例與一個反例分子（放在測試中），稽核狀態先填「待使用者審」。

### C. 計算（`src/core/properties/`）

1. 沿用任務 026／029／031 的基團切分與配對規則（含 D54 校準基團標示）；配不到的原子回報「缺基團」，不計算、不猜值；重疊優先順序沿用現行規則（M26 未決，不得改動）。
2. 只對聚合物單元（含連接點）計算；小分子回傳「不適用（小分子，D56）」。
3. 輸入由前面任務的結果取得：Tg（書中基團，必要時含校準基團，輸出標「含校準基團」）、Va、Vc、VW。任一輸入缺（缺基團）→ 回報「缺 Tg」或「缺莫耳體積」，不猜。
4. 回傳：自由體積分率、CTE（玻璃態、橡膠態，若書中分開）、各輸入值與出處、書中式號、缺基團清單；若書中指出誤差範圍或適用條件，輸出附註。
5. D09：分子量不顯示在網站畫面；本卡不做畫面。D02：不使用實驗值當輸入。
6. 不得使用折射率 n（D07 已取消）。

### D. 測試

1. 書中有計算值的對照：自由體積分率與 CTE 的書中例子（表格或章節範例）至少各 6 個聚合物（含聚乙烯類、含芳香環、含酯基、含氮各一）；程式值與書中計算值差在書中印刷捨入範圍內。若書中只有觀測值，改用書中公式與表手算，手算過程寫進報告，並附觀測值對照（只作比較，不當輸入）。
2. 每個新基團的正反例切分測試（若有新表）；切分完整性測試；缺 Tg、缺莫耳體積、缺基團回報測試；小分子「不適用」測試。
3. 測試時不要啟動背景伺服器。

### E. 批次輸出文件（`docs/verification/phase6-自由體積-CTE-輸出.md`）

1. 對下列結構各輸出一列：名稱、SMILES、自由體積分率、CTE（玻璃態、橡膠態）、Tg、Va、Vc，或「缺基團／缺 Tg／缺莫耳體積：…」：使用者材料的聚合物單元與骨架範本 BT01–BT06、任務 030 的半導體代表結構中的聚合物單元（聚醯亞胺、PBO、PHS、丙烯酸酯類、酚芳烷基等）、驗證用書中聚合物。
2. 檔頭註明方法、出處與「基團加成估算，非實測；CTE 隨溫度與固化度變化」。
3. 在報告中另列一節：SBI、茀、酚醛等骨架算出的自由體積分率與一般聚合物的比較，及方法能否反映 SBI 的螺環自由體積（預期不能，如實寫出，不要自行修正）。

## 要做的事

### A. VW 基團表（`src/data/vw_groups.csv`）

1. 欄位：`id`、`基團名稱`、`SMARTS`、`VW`（cm³/mol）、`Mi`（g/mol）、`二價／非二價`、`出處`、`稽核狀態`。
2. `出處`寫「van Krevelen & te Nijenhuis, Properties of Polymers 4th ed. (2009), Table 4.2 ＋ 區段 ＋ 書頁碼」；若同一數值能與 Bondi 1964 對上，備註欄寫「與 Bondi 1964 相符」，對不上就在備註寫差異，**以書中 Table 4.2 為準**。每一列都要有出處，缺出處報錯（D22）。
3. 只收錄下列結構需要的基團：化合物庫與配方測試資料中的聚合物重複單元、環氧單元、小分子（含 SBI），骨架範本 BT01–BT06 單元。**Table 4.2 找不到的基團，VW 一律留空，不得以相近基團或記憶中的數值代替**，並在報告列出。
4. 每讀一列，用 Mi 與基團質量交叉檢查，不符就停下來回報（先對照書中印刷錯誤清單 KNOWN_ISSUES M15，不同的再回報）。
5. D22 流程：SMARTS 自行撰寫，每個基團至少一個正例分子與一個反例分子（放在測試中），稽核狀態先填「待使用者審」。

### B. VW 計算（`src/core/properties/`）

1. 切分方式沿用任務 026／027：每個重原子恰好屬於一個基團，配對順序固定可重現，配不到的原子回報「缺基團」與位置，不計算、不猜值。
2. VW = ΣVW,i；同時回傳 ΣMi 並檢查與分子（或重複單元）質量差；差值處理方式照任務 026 的作法。
3. 聚合物重複單元（含 `*`）與小分子都要能計算（van Krevelen 以結構單元計算）。
4. 回傳：VW、每個基團的貢獻、出處、缺基團清單。
5. D09：分子量不顯示在網站畫面；本卡不做畫面。

### C. TPSA 與 Crippen LogP

1. 使用專案已有的 RDKit（先確認專案目前的 RDKit 包裝提供哪些描述子；RDKit 的 TPSA 與 Crippen 實作即 Ertl 2000 與 Wildman–Crippen 1999 的方法）。若現有 RDKit 取不到這兩個描述子，**停下來回報**，不要自行寫一套近似。
2. **只對小分子計算**。含 `*` 的聚合物重複單元：回傳「不適用（聚合物單元）」，不要自行補封端原子。是否補封端、補什麼，列入報告「需要使用者決定的事」。
3. 輸出單位：TPSA 為 Å²，LogP 無單位。

### D. 測試

1. VW：書中第 4 章的計算範例與有 VW 數值的表（先看 Table 4.7、4.8 等是否附 VW 欄），選至少 6 個結構（含脂肪鏈、芳香環、含酯基、含環的各一），程式結果必須與書中數值差 ≤ 0.1 cm³/mol；**書中數值一律看圖讀取，不得用記憶中的數值**。若書中沒有足夠的範例，補用 Table 4.2 增量手算並把手算過程寫進報告。
2. VW：每個基團正反例切分測試；切分完整性測試（各基團原子數加總 = 重原子數）；缺基團測試。
3. TPSA 與 LogP：至少 3 個結構不同的小分子（含羥基、含酯或醚、含胺或醯胺的各一），以論文表中的貢獻值手算（貢獻值看圖讀取），與 RDKit 結果比對，差 ≤ 0.01。手算過程寫進報告。
4. 含 `*` 的結構回傳「不適用」測試。
5. 測試時不要啟動背景伺服器。

### E. 批次輸出文件（`docs/verification/phase6-VW-TPSA-LogP-輸出.md`）

1. 對下列結構各輸出一列：名稱、SMILES、VW（或缺基團）、TPSA、LogP（聚合物單元的 TPSA、LogP 寫「不適用」）：化合物庫與配方測試資料中的所有小分子、聚合物重複單元、環氧單元，以及 BT01–BT06 單元。
2. 檔頭註明方法與出處。

## 目標

聚合物（均聚物與共聚物）的每種重複單元可以看 3D：把連接點 `*` 換成甲基，當成小分子產生構象，沿用現有的 3D 顯示、反應原子標記與量測。畫面清楚標示這是單元片段，不是聚合物鏈。

2. 更新檔頭日期。

### B. 單元片段（`src/core/polymer/`，純 TypeScript）

1. 新增函式：輸入一個重複單元 SMILES，輸出封端後的片段。做法：**把每個 `*` 原子直接改成碳原子**（去除原子映射編號），再補氫。
   - 原子的順序與編號**不變**：原來的 `*` 原子變成甲基碳，留在原位置。這樣 3D 的原子編號與 2D 單元圖一致。
   - D48 的單元（兩個連接點在同一個原子）會得到同一個碳上的兩個甲基，這是正確結果。
2. 回傳每個原子是否為「封端甲基碳」（原本的 `*`），畫面要用。
3. 端基不畫 3D，也不接在片段上。

### C. 畫面

1. 成分詳細彈窗：聚合物原本顯示「聚合物不提供 3D」的地方，改成單元片段 3D。
   - 共聚物上方加「單元 N」選擇（依單元清單順序），一次只算目前選的那一種單元，不要一次把所有單元都算出來。
   - 均聚物只有一種單元，不顯示選擇。
2. 分子工具：輸入的是重複單元（含 `*`）時，同樣顯示單元片段 3D；目前「聚合物不提供 3D」的字樣移除。
3. 沿用小分子 3D 的全部功能：構象數量、MMFF94 最佳化、缺參數時的「未經力場最佳化」標示、三種顯示模式、原子編號、鍵長／鍵角／二面角量測、反應原子標記。
4. 封端甲基碳要和其他原子區分：例如原子編號旁加「（封端）」或改用不同的標示顏色，並在圖例說明「封端甲基：代替相鄰單元，不屬於本單元」。
5. 反應原子標記與 2D 單元圖的編號相同（因為 B-1 的原子順序不變）。
6. 3D 區域上方的說明文字改為：「重複單元片段的理論構型：連接處以甲基代替，依 MMFF94 力場估算，不代表聚合物鏈構象，非實測結構。」小分子維持原本的文字。
7. 單元片段的 3D **不存進化合物庫、不匯出**（聚合物在化合物庫中維持以單元與比例儲存）。

# 任務 015：均聚物輸入（重複單元＋Mn／DP）與 D40–D43

編號：015
建立日期：2026-10-29
指派給：Codex／Claude Code

## 目標

使用者可以輸入**均聚物**：畫出重複單元（用兩個連接點 `*` 標記）、填入 Mn 或 DP，程式算出重複單元分子量與兩者的換算；聚合物可以存進「我的化合物」、加入配方並參與質量相關的換算。這是 Phase 4 交聯計算的前提（D42）。同時把使用者 2026-10-29 確認的 D40–D43 寫進文件。**本任務不辨識官能基、不計算官能度與交聯**（任務 016、017）。

### C. 均聚物資料模型（`src/core/polymer/`，純 TypeScript）

7. 均聚物的欄位：`repeatUnitSmiles`（含兩個連接點）、`mnInput?`、`dpInput?`（兩者擇一填寫）、`name`。
8. 連接點規則（沿用 D31）：
   - 必須**恰好兩個**連接點；`[*:1]`、`[*:2]` 或兩個未編號的 `*`（後者依出現順序視為 1、2）
   - 少於或多於兩個、或連接點連在同一個原子上 → 錯誤，中文說明
9. 重複單元分子量 `M_unit`：由 RDKit 計算**不含連接點**的重複單元平均分子量（把 `*` 移除，不補氫）。在 `docs/DATA.md` 或報告中說明計算方式。
10. 換算：`DP = Mn / M_unit`、`Mn = DP × M_unit`；**端基忽略**（Phase 5 才處理），結果附註「未計入端基」。
11. 分子量相關數值（M_unit、Mn）依 D09 **不在結果區顯示**；但 **Mn 與 DP 是使用者的輸入**，可以顯示在輸入欄位中。換算出的另一個值（填 Mn 時的 DP，或填 DP 時的 Mn）顯示在輸入欄旁，作為輸入輔助（不是物性結果）。
12. 3D：聚合物不提供 3D（D05），沿用任務 011 的說明。

### D. 畫面與整合

13. 「結構」分頁：結構含兩個連接點時，顯示「均聚物設定」區：Mn 或 DP 擇一輸入。
14. 「我的化合物」：可以儲存聚合物（存重複單元、連接點、Mn 或 DP）；清單上標示「聚合物」；匯出入 JSON 包含這些欄位（`schemaVersion` 若需要變動，要能讀取舊版檔案，並加測試）。匯出 SDF 時，聚合物以重複單元的 Molfile 輸出，並附 `MoleForm_Type=polymer`、`MoleForm_Mn` 或 `MoleForm_DP` 欄位。
15. 「配方」：可以加入聚合物成分；質量相關換算（g、重量份、wt%、phr、Solid Content）照常；mol% 依任務 014 的規則，整區不輸出（U02 尚未決定）。配方存檔包含聚合物的設定。
16. 換算核心需要的分子量：聚合物成分以 Mn 作為「每分子質量」傳入核心，但核心不會用它算 mol%（U02），只供之後任務 017 計算官能度使用；在程式註解中寫明。

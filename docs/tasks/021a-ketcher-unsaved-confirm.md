# 任務 021 後續：Ketcher 未套用內容不得悄悄丟失

編號：021（後續）
建立日期：2026-10-30
指派給：Codex／Claude Code

## 目標

用 Ketcher 畫的內容，在還沒套用或驗證前，任何會把它清掉的操作都要先問使用者。沒有未套用的修改時，行為和現在一樣、不多問。

## 前置條件（先讀這些）

- `AGENTS.md`
- `docs/DECISIONS.md`（D28、D48）
- `docs/reports/021-結果.md`

## 要做的事

1. **離開「分子工具」分頁**（使用者 2026-10-30 決定，選 A）：
   - 單元繪圖中有未套用的修改 → 先跳確認（沿用現有的確認對話框），文字例如「單元 N 在 Ketcher 裡有尚未套用的修改，離開會放棄這些修改。確定要離開嗎？」。按取消就留在分子工具分頁。
   - 沒有未套用的修改 → 照現在的做法直接收掉單元繪圖、釋放 Ketcher，不詢問。
2. **借用 Ketcher 畫單元之前**：
   - 原本的結構繪圖畫布有尚未驗證的筆畫（和最近一次驗證過的結構不同）→ 先確認，文字例如「畫布上有尚未驗證的修改，改畫單元後會還原成最近一次驗證過的結構。確定要繼續嗎？」。
   - 沒有這種筆畫 → 直接借用，不詢問。
3. 三個地方（分子工具、加入成分彈窗、成分詳細彈窗）的判斷方式一致；彈窗內原有的「關閉前確認」不變。
4. `docs/DESIGN.md` 補上這兩條規則。

## 不可更動的檔案或規則

- 不得更動化學規則、資料表、模型公式
- 每處最多一個 Ketcher（任務 021 的做法不變）
- 沒有未套用修改時，不可多出任何確認

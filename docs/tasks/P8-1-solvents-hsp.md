**二、8.1 溶劑資料表**

1. 以上述清單，在 `src/data/solvents.csv` 填入：SMILES（有 RDKit 可驗證的規範寫法）、中英文名稱、分子量（由 SMILES 計算，標 `computed`）、25 °C 密度、HSP δD、δP、δH（單位 MPa^0.5）、25 °C 黏度、25 °C 表面張力、沸點（常壓）、摩爾體積（由分子量與密度算）。**每個數值一列出處欄位與溫度欄位**（沿用 `docs/DATA.md` schema 的 source／status 欄；現有欄位不足時擴充欄位，並同步 `docs/DATA.md`、資料表載入與驗證測試）。
2. 資料來源依 D72 與 D18：先查已有的本機文獻，再找開放授權資料集或成熟套件在 GitHub 的資料檔（此環境不能安裝套件，只能讀其公開資料檔並引用）。同一數值多個來源不一致時取**單一最清楚的來源**，其他來源的值寫進 notes。**找不到可引用的數值就留空並在 notes 說明；不得補值、內插、換算（密度的溫度修正除外且須標明）**。

**三、8.2 Liquid 區 vol% 換算**

4. Liquid 區的成分可從溶劑資料表選取（下拉），選取後帶入密度與分子量；仍可自行輸入（沿用 P7-4a 的密度欄位）。vol% 換算由 Python 端依成分質量與密度計算（先讀 018／019／021 報告，沿用既有 D49 的目標 Solid Content、扣除標記成分等規則，不改既有行為）。密度缺值（表中留空且使用者未輸入）→ vol% 回報 `missing` 與原因。

**四、8.3 HSP 與溶解性（Python，端點如 `POST /hsp`、`/solubility`，輸出 `value/unit/source/status`）**

5. **HSP 基團貢獻**：依書第 7 章的 Hoftyzer–Van Krevelen 式（δd＝ΣFdi／V、δp＝√ΣFpi²／V、δh＝√(ΣEhi／V)，**先讀原文確認式子與符號**），為聚合物重複單元與小分子算 δD、δP、δH。基團貢獻表（Fdi、Fpi、Ehi）取自書並依 D22 收進 `src/data/`（每列書名、表號、頁碼；SMARTS 有正反例；`pending`），切分方式沿用既有 `ecoh_groups.csv`、Tm／Td 基團表的做法；缺基團 → `missing` 並列出缺的基團。聚合物的 V 用既有 `vm.py`。
6. **混合溶劑 HSP**：各溶劑 HSP 依**體積分率加權平均**（體積分率由密度與分子量算；書或文獻有不同寫法則以文獻為準並說明）。
7. **Ra、RED**：聚合物與溶劑（或混合溶劑）的 Ra（Hansen 距離式，書中係數 4 的寫法依原文）與 RED＝Ra／R0；R0（相互作用半徑）只用書 Table 7.8 這類**有出處的聚合物值**，沒有 R0 的聚合物，RED 回報 `missing` 並說明（Ra 照常輸出）。**不自行訂 R0**。
8. **Flory–Huggins χ**：依書的式（先讀原文，含式中常數）由溶解度參數差與溶劑莫耳體積算 χ；輸出 `參考趨勢`。
9. **溶解性判斷**：依 RED 與 χ 給定性判斷（例如 RED＜1 傾向溶解；χ 與 0.5 的關係，**門檻照書或文獻原文，不自訂**），明確標示「參考趨勢，非定量保證；HSP 對聚合物分子量、結晶度、溫度未做修正」。
10. 介面：在配方或聚合物成分的結果區新增「溶解性」卡片：選一個聚合物成分與（混合）溶劑，顯示 HSP 三分量（聚合物、溶劑、混合）、Ra、RED、χ、判斷、各缺值原因。沿用現有元件；橋接白名單加入新端點。

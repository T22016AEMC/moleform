# 任務 001：測試 RDKit.js 的 3D 能力

編號：001（2026-10-28 改寫：依 DECISIONS D19 刪除原部分 A「盤點第三方 3D 程式碼」）
建立日期：2026-10-28
指派給：Codex／Claude Code

## 目標

提供使用者決定架構（DECISIONS P01）所需的事實：官方 RDKit.js（`@rdkit/rdkit`）能不能完成 MoleForm 單體與小分子的 3D 需求。規則表已決定不需保密（D21），所以若 RDKit.js 全部支援，就可以採用純前端架構。**本任務只產出測試腳本與報告，不建立正式專案骨架。**

## 前置條件（先讀這些）

- `AGENTS.md`
- `docs/DECISIONS.md`（特別是 P01、D19、D20、D21）
- `docs/KNOWN_ISSUES.md`（K01）
- `docs/reports/002-結果.md`（請先確認任務 002 已完成）

## 要做的事

1. 建立暫時測試資料夾 `experiments/rdkit-3d/`，使用 **npm**（D20）在該資料夾內安裝官方 `@rdkit/rdkit`。不要在專案根目錄建立 `package.json`。
2. 寫一個 Node 腳本，對下列分子執行測試並記錄結果：
   - 乙醇 `CCO`
   - 環氧丙烷 `CC1CO1`
3. 逐項檢查：
   1. 能否產生 3D 座標（ETKDG 或等價功能）
   2. 能否做 MMFF94 最佳化；MMFF94 參數缺漏時能否退到 UFF
   3. 能否產生多個構象並取得每個構象的能量（用來算相對能量）
   4. 能否輸出含 3D 座標的 MOL 與 SDF
   5. 能否取得鍵長、鍵角、二面角，或確認需要自行由座標計算
   6. 每項記錄：**支援／不支援／部分支援**、使用的 API 名稱；不支援就說明缺什麼
4. 另外記錄以下事實，供日後判斷純前端是否可行：
   - `@rdkit/rdkit` 版本與授權（從套件的 `package.json` 或 LICENSE 讀取）
   - WASM 檔案大小
   - 初始化時間，以及每個分子產生 3D 的耗時（大約值即可）
5. 在 `experiments/rdkit-3d/README.md` 寫明如何執行腳本（一行指令）。

## 不可更動的檔案或規則

- 不得更動基團貢獻參數表、反應規則表與模型公式
- 不得重新加入 `AGENTS.md` 列出的已取消項目（例如聚合物 3D）
- 測試腳本只放在 `experiments/rdkit-3d/`，不要接入正式程式碼，不要建立 Vite／React 專案骨架
- 除 `@rdkit/rdkit` 外不安裝其他 3D 或化學套件；若認為需要，先在報告中說明並問使用者
- 不參考 YIHAN-HSU/TiN-Al2O3-SiO2-HMDS-P1-S5 專案（D19）
- 不得自行決定架構；報告只提出建議

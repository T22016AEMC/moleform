## 目標

P6B 的 `/modulus` 只回報缺什麼。使用者 2026-11-17 決定補完。書（`docs/references/vanKrevelen-teNijenhuis-2009-Properties-of-Polymers-4ed.pdf`，以下稱「書」）第 13.2.4–13.2.6 節與 Example 13.1、13.2 給出由結構算出模數的路徑，不是只有 K：

- 式 (13.21)/(13.30)：K = ρ·(U_R/V)^6；式 (13.22)：G = ρ·(U_H/V)^6；U_R、U_H 是加成函數，基團值在 **Table 14.4**（第 14 章，書頁約 515；U_H 書中標明「tentative／暫定」）。
- 泊松比 ν 與楊氏模數 E：依 Table 13.2 的式 (13.8)–(13.11)（Example 13.2 示範：ν = (1 − (2/3)G/K) / (2(1 + G/K))，E = 3G / (1 + (1/3)G/K)）。**先讀 Table 13.2，照書的式寫**。
- 方法三（式 13.32）K ≈ 8.04·(E_coh + x_c·ΔH_m)/V，需要內聚能（第 7 章 Table 7.1 基團值）與熔融熱（第 5 章 ΔH_m 的基團值；Example 13.1 說明出處）。方法二（式 13.31）需要熱膨脹與 Cp/Cv（圖 5.4，是圖），**本卡不做方法二**。

依 D62 寫在 Python；D22 資料表流程；依 D64：相關功能一次做完、只驗證一次、報告一頁。

## 要做的事

**一、資料表（D22：每列有書名、表號、頁碼、SMARTS 正反例、稽核狀態「待使用者審」）**

1. `Rao／Hartmann` 基團表（Table 14.4：U_R、U_H 兩欄；U_H 欄標「書中暫定值」；書中缺 U_H 的基團，U_H 欄留空並使 G 回報 missing，不得自行補）。分子中的基團切分沿用 Tm／Td 既有切分方式與優先順序（大基團優先於小基團，避免重複計算）。
2. 若 Table 7.1（E_coh）與第 5 章 ΔH_m 基團表都存在且基團定義可與本專案切分對應：收錄兩張表，啟用方法三。**任一張缺、或基團無法對應，方法三不做**，在報告寫明原因，不要找外部資料。

**二、計算（`POST /modulus`，輸出沿用 `value/unit/source/status`）**

3. 方法一：K、G（若 U_H 齊全）。V 用現有 `vm.py` 的莫耳體積（輸入若帶密度則用輸入密度並標示）；單位換算依書（K 以 GPa 輸出，換算寫在程式註解，例如 Example 13.2 的 dyn/cm² → N/m²）。
4. ν 與 E：K、G 都有才輸出，用 Table 13.2 的式；只有 K 時只輸出 K。
5. 方法三（僅在第 2 步啟用時）：輸入可帶結晶度 x_c（沒有就視為 0 並標示）；K₃ 由式 (13.32)。兩個以上方法可算時，同時列出各方法值與平均（書的建議）；只有一個方法時不取平均，標「單一方法」。
6. 狀態 `predicted`，備註「參考趨勢；書稱各方法一致性約 20%；U_H 為書中暫定值」。缺基團 → `missing` 並列出缺的基團。
7. 介面：I01 物性面板的彈性模數區顯示 K、G、ν、E 與各方法值，缺值顯示 `missing` 與原因，沿用現有元件；橋接白名單不需新增端點（沿用 `/modulus`）。`docs/MODELS.md` 更新彈性模數條目；`docs/PLAN.md` 6.5 勾選並補註實際做到的範圍。

**三、驗證（全部完成後只做一次，用書自己的算例）**

8. 重現：Example 13.1（聚乙烯：U_R = 2×880、V = 29.5、K ≈ 4.3 GPa；方法三 E_coh 8380 J/mol、ΔH_m 8000 J/mol，K ≈ 3.8 GPa，僅在方法三啟用時）；Example 13.2（雙酚 A 聚碳酸酯：U_R 12,575、U_H 9,900、V = 212 → K ≈ 5.23、G ≈ 1.24 GPa、ν ≈ 0.39、E ≈ 3.52 GPa）；Table 13.6 方法一欄中本專案基團能算出的列（能算幾列算幾列）；Table 14.5 的 U_R、U_H 計算欄（能算幾列算幾列）。算不到書中數值（差超過書自己顯示的精度）→ 先檢查謄錄，仍不符就**停下來回報**，不要調整數值去湊。結果整理進 `docs/verification/phase6-Tm-Td-吸濕-彈性模數-輸出.md`（新增「彈性模數」一節，每個聚合物：書值、本卡值）。
9. 最少的單元測試：端點可用、缺基團回報、U_H 缺時 G／E 回報 missing 但 K 仍輸出。不做反向驗證、不加邊界探針。
10. 報告 `docs/reports/P6E-結果.md`，限一頁：做到哪些方法、對照幾列相符與不符的是哪些、方法二與（若有）方法三為何不做、需要使用者決定的事。

# 任務 P6D：實測比對腳本擴充（混合配方 Tg、相對 Tg）

編號：P6D
建立日期：2026-11-17
指派給：Claude Code

## 目標

P6C 的比對腳本只比對單一重複單元的 Tg。使用者的 DSC 實測值是**配方（混合物）固化前的 Tg**（D02：只作驗證目標，不作計算輸入），並有以 Cardo 酚醛樹脂為基準的相對 Tg 算例（D61），所以腳本需要三種模式。依 D64：一次做完、報告半頁、不做額外驗證。**只改比對腳本、模板與說明，不改任何計算。**

## 前置條件（先讀這些）

- `docs/reports/P6C-結果.md`、`engine/scripts/compare_measured.py`、`docs/verification/user-measured-template.csv`、`docs/verification/phase6-使用者驗證清單.md`
- `docs/DECISIONS.md` 的 D02、D04、D61；引擎 `/tg/mixing`、`/relative-tg` 的輸入契約（讀 `engine/` 對應處理函式，不要猜）
- 不要搜尋整個專案

## 要做的事

1. **三種比對模式**，以模板的「模式」欄區分：
   - `unit`：單一重複單元 Tg（現有行為，不變）。
   - `mixture`：混合配方 Tg。每個樣品有多個成分，成分資訊（名稱或 SMILES、質量百分比、Mn、每分子質量等）依 `/tg/mixing` 的輸入契約；腳本呼叫 `/tg/mixing` 取得預測值。模板用「成分表」的方式表達，例如一個樣品多列、以樣品名分組，或另開一個成分 CSV，由你選最容易填寫的格式，並在說明寫清楚。
   - `relative`：相對 Tg（D61）。輸入基準材料 A（結構與其 Tg 錨點）、目標材料 B（結構或組成變化）與比例；腳本呼叫 `/relative-tg` 取得預測值；A 的 Tg 錨點是輸入（D61 已定的例外），實測的 B 值只拿來比對。
2. **共通規則（沿用 P6C）**：用途欄分「校準／驗證」，校準列不進驗證誤差統計；依材料家族分組統計平均與最大誤差；實測值不得傳進任何計算函式；缺基團或引擎回報 `missing` 的樣品要列出原因，不算誤差。
3. 模板與說明：更新 `user-measured-template.csv`（或新增對應的成分／相對模板）與驗證清單中的使用說明，各模式放 1–2 列示範並標「示範，非實測」，不得放看起來像真實實驗的數字。
4. 最少的測試：三種模式各一個、校準列不進統計各一個、`missing` 樣品不算誤差一個；實測值不進計算沿用既有測試。不做反向驗證與邊界探針。
5. 報告 `docs/reports/P6D-結果.md`，限半頁。本機只跑本卡新增測試與引擎 pytest；全部 TypeScript 測試與建置交給 CI。新增測試字串用雙引號。commit、push，用 PowerShell 查一次 CI。

- 實測值不得成為任何計算的輸入（D02）；校準與驗證分開；不新增或編造任何實驗數字

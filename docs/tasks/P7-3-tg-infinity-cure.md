# 任務 P7-3：Tg∞、固化後 Tg、完全固化最低溫度、Tg∞ 高於 Td 警示（PLAN 7.4、7.5、7.7）

編號：P7-3
建立日期：2026-11-18
指派給：Claude Code

## 目標

交聯模組的 Phase 7 計算。三項互相相關，一次建完（D64），**直接寫在 Python（D62）**，介面沿用 I05 之後的做法（交聯頁走引擎）。只對第 1 層「支援」的體系計算；第 1 層回報「尚未支援」的體系，這三項也回報「尚未支援」與同一原因，不硬算。

- 7.4 Tg∞：完全固化時的 Tg。方法來源（本機書，使用者 2026-11-18 以全文定位）：`docs/references/vanKrevelen-teNijenhuis-2009-Properties-of-Polymers-4ed.pdf` 第 6.2.4.4 節（約書頁 148–149），式 (6.13)：`Tg,crl − Tg,0 = K_crl / M_crl`；本節同時給兩個 K_crl 值（Nielsen 的 3.9×10⁴ K·mol/g；本書以苯乙烯–二乙烯苯資料擬合的 5.2×10⁴ K·mol/g），並說明 K 值依體系而異；環氧以二胺或酸酐硬化的資料顯示 ΔTg 在高交聯度趨近定值（本書寫約 80 K）。式 (6.14)（DiBenedetto 的未發表式）：`Tg,crl − Tg,0 = 1.2·Tg,0 · x_crl / (1 − x_crl)`，x_crl＝交聯數／主鏈原子數。**照書抄，兩個 K 值都要用到原文確認（先讀原文，數值以原文為準）**。
- 7.5 固化後 Tg（DiBenedetto 型式，λ 依 S02：λ ≈ Tg,0 / Tg∞，標示為近似）、完全固化最低溫度、指定溫度下最大轉化率（玻璃化限制：硬化溫度 T 下 Tg(x) 到達 T 時，轉化率不再上升）。
- 7.7 Tg∞ 高於 Td 警示（S04）。

## 要做的事

1. **Tg,0（未交聯狀態）**：使用既有的混合 Tg（Fox，P6A／`tg_mixing`）對配方各成分算得的值，不新增模型。結果標「未交聯 Tg 估計」。
2. **Tg∞（7.4）**：
   - 取第 1 層在「限量官能基轉化率 = 1」時的 M_crl（第 1 層已有 Mc／網目鏈資料，D44；本專案 Mc 定義見 `docs/MODELS.md`，與書的 M_crl 若有定義差異，要在 MODELS 與報告寫明差在哪）。
   - 用式 (6.13) 兩個 K 值各算一次，**輸出為一個範圍（下限、上限）並各標來源**，狀態 `predicted`，備註「參考趨勢；K_crl 依體系而異；環氧體系高交聯度時 ΔTg 趨近定值」。**不得選其中一個當單一值**，也不得自行調整 K。
   - 以式 (6.14) 另算一個對照值（需要 x_crl，由第 1 層交聯點資料與主鏈原子數取得；取不到就回報「無法取得 x_crl」並說明缺什麼，不要估）。(6.13) 與 (6.14) 差很多時，兩個都列出，不選。
   - 輸入為 Tg,0 缺值（成分缺基團）時，Tg∞ 回報 `missing` 與原因。
3. **固化後 Tg（7.5）**：DiBenedetto 型式方程式（Tg(x) 對轉化率 x）**必須取自本機文獻**；先查 `docs/references/`。若本機沒有該方程式的出處，**停止 7.5 的這一部分並回報**（不要憑記憶寫式子，也不要用別的式子替代）；其餘（7.4、7.7）照做並提交。有出處時：λ = Tg,0 / Tg∞（S02，標近似；Tg∞ 用 K 範圍的下限與上限各算一次，結果同樣為範圍）；輸出：指定轉化率（輸入，預設可填 0.5、0.8、0.9、1.0 作為列表）的 Tg；完全固化最低溫度（T ≥ Tg∞ 才可能 100% 轉化，這是推論，標明）；指定硬化溫度 T 下的最大轉化率（解 Tg(x) = T 得 x_max；T ≥ Tg∞ 時為 1）。
4. **Td 警示（7.7，S04）**：用 `/td` 對配方各成分算 Td,1/2（`td.py` 既有），警示條件：Tg∞（上限）高於**配方中最低的成分 Td,1/2**時，顯示警示「估算 Tg∞ 高於成分 Td,1/2，完全固化前可能分解」。理由：固化未完成時材料仍由未反應成分構成，最弱成分的分解溫度才是限制；寫進 MODELS.md，並說明 Td,1/2 是書定義的半分解溫度，不是 5% 失重溫度。成分缺 Td 時，缺的不比較並列出。
5. **介面**：交聯頁新增「固化預測」卡片：Tg,0、Tg∞（範圍）、固化後 Tg 表、完全固化最低溫度、最大轉化率、警示；缺值與「尚未支援」顯示原因。沿用現有卡片元件，不重做設計。橋接白名單加入新端點。
6. **文件**：`docs/MODELS.md` 新增條目（公式、式號、適用、限制、出處「待使用者審」）；`docs/PLAN.md` 7.4、7.5（若有出處）、7.7 勾選並補註；7.5 若停在缺出處則不勾並寫明。

## 測試結果（全部通過）

- Solid A 8 g＋B 2 g（B 勾揮發）、目標 4%：「全部」→ Liquid 240 g、Solid Content（全部）4%、（扣除標記）3.2%；「扣除標記成分」→ Liquid 190 g、（扣除標記）4%、（全部）5%。
- 目標 85% → 錯誤「扣除標記成分後，Solid Content 最高只能到 80%（目標 85%）」；目標 80% → Liquid 0 g、沒有錯誤。
- wt%（每 100 份固體）、B 佔 20% 勾揮發、扣除標記成分、4% → Liquid 1900 份。
- `targetSolidContentBasis` 存檔、讀檔保留；舊檔讀成 all。
- 用 Ketcher 套用的單元與貼同一個 SMILES 的分析結果相同（連接點、官能基數、M_unit、莫耳分率）；畫出不合法單元（只有一個 `*`、沒有 `*`、空白畫布、三個 `*`）時錯誤訊息指出第幾個單元；次甲基單元可套用（D48）。
- 端基選 EG10 出現提示，選其他端基、自訂或不填不出現；選 EG10 的計算結果與直接填 `[*]O` 相同（只是提示，不改計算）。
- 畫面狀態：有揮發標記且選扣除標記才寫入基準；無標記時固定為全部。

## 遇到的問題與設計說明

- **Ketcher 的「借用」方式**：每個地方只有一個 Ketcher。畫單元時暫時卸下原本的結構繪圖，畫完再以最近一次驗證過的結構還原——分子工具靠 `StructureInput` 既有的 `active` 機制（釋放後重新載入目前結構）；加入成分彈窗與成分詳細彈窗是把主結構的 Ketcher 卸下，之後以最近一次的結構重新載入。因此在主畫布上尚未被驗證（匯出）的最新筆畫，會以最近一次已驗證的結構還原。
- 離開「分子工具」分頁時會收掉單元繪圖（避免和配方工作台的彈窗同時有兩個 Ketcher），尚未套用的修改在這種情況不會跳確認。
- 載入填有目標的舊配方一律進入自動計算模式（D49），Liquid 欄位的舊用量會被當作溶劑間的比例或被忽略。
- 達不到目標的錯誤只在使用自動計算（`liquidFromTarget`）時出現；舊配方沒有旗標、畫面載入後會因目標欄非空而進入自動計算模式。

## 需要使用者決定的事

- 其他官能基（胺基、羧酸、乙烯基等）延到 Phase 7.1，依 P05 處理（K11 已記）。

## 任務 021 後續：Ketcher 未套用內容不得悄悄丟失

完成日期：2026-10-30

### 做了什麼

1. 離開「分子工具」分頁：單元繪圖有未套用的修改 → 先確認（「單元 N 在 Ketcher 裡有尚未套用的修改，離開會放棄這些修改。確定要離開嗎？」，按取消留在分子工具、修改還在）；沒有修改 → 直接收掉單元繪圖，不詢問。
2. 借用 Ketcher 畫單元之前：原本的結構畫布有尚未驗證的筆畫 → 先確認（「畫布上有尚未驗證的修改，改畫單元後會還原成最近一次驗證過的結構。確定要繼續嗎？」）；沒有 → 直接借用，不詢問。
3. 三個地方（分子工具、加入成分彈窗、成分詳細彈窗）判斷方式一致；彈窗原有的「關閉前確認」不變；單元之間切換、取消的確認不變。

### 偵測「未驗證的筆畫」

Ketcher 有變更事件（`changed`），所以可以偵測，不需要回報替代做法。`KetcherPane` 與 `StructureInput` 在收到使用者修改時回報「有未驗證的筆畫」，直到匯出並經 RDKit 驗證完成（且之後沒有新的筆畫）才回報沒有；畫布卸下時也回報沒有。

### 改了哪些檔案

- `src/ui/workbench/KetcherPane.tsx`、`src/ui/structure/StructureInput.tsx`：`onUnverifiedChange`（`KetcherPane` 另有 `onExported`，回報最近一次匯出的 Molfile）。
- 新增 `src/ui/polymer/drawingState.ts`（單元繪圖與分頁切換的狀態轉移，純函式）；`useUnitDrawing.ts` 改為接上它，並接受 `mainUnverified`；`model.ts` 的 `decideDrawRequest`、`tabLeaveNeedsConfirm`；`UnitDrawPanel.tsx` 加借用確認。
- `src/ui/App.tsx`（分頁切換確認）、`PolymerSettings.tsx`、`AddComponentDialog.tsx`、`ComponentDetailDialog.tsx`：接上；兩個彈窗還原主結構時改用畫布最近一次匯出的 Molfile（即使驗證沒通過）。
- `docs/DESIGN.md`（兩條規則）、`docs/KNOWN_ISSUES.md`（K12）。

### 測試結果

型別檢查、測試（25 檔、490 項）、建置通過；`phase3-輸出.md`、`phase4-輸出.md` 重新產生後與提交版本逐字相同；測試時沒有啟動背景伺服器。
- 有未套用的單元修改時離開分子工具 → 需要確認；取消後仍在原分頁、單元繪圖與修改都還在；確認後切換並收掉單元繪圖。

### 遇到的問題

- 「分子工具」的 `StructureInput` 在借用後只還原「已驗證且合法」的結構，已驗證但不合法的畫布內容（畫到一半的結構）不會還原，也不算「尚未驗證」所以不詢問；兩個彈窗則以畫布最近一次匯出的 Molfile 還原，不受影響。已記為 K12。

### 請使用者在瀏覽器確認

1. 分子工具：在單元 Ketcher 畫了東西但沒有套用，按別的分頁 → 出現確認；按取消 → 仍在分子工具、畫的內容還在；按「放棄並離開」→ 切過去。

4. 借用前沒有任何筆畫（或主結構是用 SMILES、化合物庫輸入）→ 直接借用，不詢問；畫完後主結構還原。

## 建議組合（由你選）

1. **σ、ρ、母體 pKa：以 #1／#9（Perrin 1981 Table A.1、A.2、A.3）為主。** 理由：（a）本機已有，符合鐵則 3(a)；（b）每條 Hammett／Taft 式的截距（母體 pKa）、ρ 與 σ 組是同一書擬合的，混用不同來源的 σ 會讓 ρ 與截距失準；（c）資料表每列可標書名、表號、頁碼與書內再引的原始文獻，`review_status` 設 `pending`（D39）。
2. **σ⁺、σ⁻ 與交叉檢查：#2（Hansch 1991 Table I、V）。** 只在 Perrin 沒有的取代基或需要 σ⁺／σ⁻ 時用，資料表標明 σ 來源，不與 Perrin 的 ρ 混用，除非該 ρ 原文就用該 σ 組。
3. **IUPAC Digitized pKa Dataset（#6）只當查表與核對工具**，不把其資料列轉入專案資料表（NC 條款），除非你接受非商業限制。
4. #3 Shorter 1994 待授權確認後，可作為 σm、σp 的第二來源比對。
5. #4、#5、#7、#8、#10 不採用。

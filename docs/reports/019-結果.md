## 兩成分近似的推導與測試

M₁ + M₂ = 2·Mw、M₁·M₂ = Mn·Mw → M₁,₂ = Mw ∓ √(Mw² − Mn·Mw)。重量分率各 0.5，分子數 = 0.5·質量 ÷ M，官能度 = (M ÷ M_unit) × 每重複單元官能基數。PDI = 1 退化為單一成分。

- 手算：Mw 6000、PDI 1.8 → M₁ = 2000、M₂ = 10000（M_unit 200、每單元 2 基 → f₁ = 20、f₂ = 100、f_w = 60）。
- 凝膠點：兩成分近似 = 單一成分取重量平均官能度（f = 60），數值一致到 1e-10（測試通過）。原因：凝膠條件只含 Σ a_i(f_i − 1)，兩成分的 a_i 各 0.5，得 f_w − 1。
- 官能度為非整數時，相鄰整數混合（B-8）使「固定 Mw、改變 PDI」的凝膠點有小於 1e-4 的差異（不是 0）；整數官能度時完全一致。
- PDI = 1 時結果與任務 017 的單一成分完全相同（`toEqual`）。
- 官能基比、過量、理論最大成鍵數、殘留百分比：不同 PDI 下不變（測試）。

## –O– 的查證結果（M19）

高解析度重看 Table 4.2 書頁 74 的 –O– 一列：印兩個值「{(5.5) (5.0)}」，都在括號內，**沒有任何條件標示**；本頁與 4.2.3 節文字也沒有說明。Bondi 1964：

- p.450 Table XVI：–O–（c.e.，雜環脂族醚）5.20、（a.e.，烷基醚）3.7、（ph.e.，苯基醚）3.2。
- p.445：單鍵 O 的 r_w 上限 1.52 Å 對應 V_w = 5.5 cm³/mol，「只有環氧乙烷的醚 O 暴露得夠多才取這個值」；烷基醚 3.7、聚苯醚 3.2。

書的 5.5 與 5.0 都不是 Bondi 的任一個條件值，無法從書或 Bondi 對應出各自的適用條件。依使用者指示，`vw_groups.csv` 的 V10（–O–）VW 留空，含醚結構回報缺基團，請使用者決定（例如指定條件，或改採 Bondi Table XVI 的 5.20／3.7／3.2——後者偏離 Table 4.2，需要同意）。

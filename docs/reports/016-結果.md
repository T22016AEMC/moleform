## 2. 官能基 SMARTS（來源原文照抄，只加原子映射）

| id | 來源與讀取方式 | 原文 | 加映射後 |
|---|---|---|---|
| `hydroxyl.phenolic` | Daylight〈SMARTS Examples〉，Functional Groups by Element → O → hydroxyl (includes alcohol, phenol) → Phenol；以 WebFetch 讀取 `https://daylight.com/dayhtml_tutorials/languages/smarts/smarts_examples.html` | `[OX2H][cX3]:[c]` | `[OX2H:1][cX3]:[c]`（映射 1 = O） |
| `ether.epoxide` | RDKit `Data/FragmentDescriptors.csv`，標籤 `Release_2026_09_1`，`fr_epoxide` 列的 SMARTS 欄（以 curl 讀取 raw.githubusercontent.com） | `O1CC1` | `[O:1]1[C:2][C:3]1`（映射 1–3 = 環上 O、C、C） |

注意：Daylight 頁面的章節名稱實際為「O → hydroxyl (includes alcohol, phenol)」，任務單寫「hydroxyl → Phenol」，已照頁面實際標題記錄。計數去重：以映射原子的集合去重（酚羥基以 O、環氧以三原子集合）；測試確認苯酚計 1、雙酚 A 計 2。

## 3. 反應 SMARTS（自行撰寫）

```
[OX2H:1][cX3:4]:[c:5].[O:2]1[C:3][C:6]1>>[c:5]:[c:4][O:1][C:3][C:6][O:2]
```

酚羥基 O（1）與環上碳（3）成鍵，C3–O2 鍵斷開，O2 成為羥基。反應物端沿用兩個官能基的匹配條件，產物端需帶出映射 4、5（否則 RDKit 會刪除未出現在產物的映射原子）。開環位置未區分。正反例（環氧丙烷＋苯酚、BADGE＋雙酚 A 應反應；環氧丙烷＋乙醇、PGMEA＋苯酚不應反應）全部通過資料表檢查。

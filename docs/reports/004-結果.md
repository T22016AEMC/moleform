## 5. Ketcher 整合

- 套件：`ketcher-core`、`ketcher-react`、`ketcher-standalone` 皆 **3.18.0**，另有 `events 3.3.0`；子專案內 `react 18.3.1`、`react-dom 18.3.1`（與主程式的 React 19 不同）。
- 架構：Ketcher 放在**獨立子專案** `packages/ketcher-frame/`（自己的 `package.json`、`package-lock.json`、`vite.config.mjs`），建置到 `dist/ketcher/`，主程式用 `<iframe src={BASE_URL + 'ketcher/'}>` 嵌入（`src/ui/AnalysisPanel.tsx` 第 232 行附近；CSS 在 `src/ui/analysis.css` 的 `.ketcher-container`，iframe 最小寬 760px、高 600px）。
- 元件／初始化：`packages/ketcher-frame/src/main.tsx` 以 `<Editor staticResourcesUrl structServiceProvider={new StandaloneStructServiceProvider()} disableMacromoleculesEditor onInit buttons={{miew,analyse,recognize 皆 hidden}} />`；初始化時 `ketcher.setSettings({'ignore-stereochemistry-errors': false})`、`ketcher.indigo.info()` 確認 WASM 可用，之後送出 `ready`。
- 與主程式的通訊：`src/shared/ketcherProtocol.ts` 定義 `postMessage` 協定（頻道 `chemscutter-ketcher-v1`；請求 `load`／`export`；回應 `ready`／`changed`／`loaded`／`structure`／`error`），並驗證來源 origin 與 window。需替換的專屬字串：頻道名稱。
- 與 RDKit.js 的互動：Ketcher 內部用 Indigo（`indigo.check` 檢查價數、立體、query、rgroups、pseudoatoms）。匯出時取得 Molfile V3000、SMILES、KET，傳給主程式，主程式再把 Molfile 交給 Web Worker 內的 RDKit 解析。RDKit 與 Ketcher 不直接共用物件。
- 特殊設定：
  - `define: { global: 'globalThis' }` 與 `resolve.alias` 把 `events` 指向 `events/`。
  - Ketcher 的 WASM 由 `StandaloneStructServiceProvider` 隨子專案建置輸出到 `dist/ketcher/`，不需手動放置 WASM。
  - 子專案 `index.html` 設 CSP：`connect-src 'self' blob: data:; img-src 'self' blob: data:; font-src 'self' data:; form-action 'none'; base-uri 'self'`。
  - Ketcher 的 `runAsyncAction` 會吞掉匯入例外，所以程式監聽 `FAILURE` 事件判斷匯入失敗。
  - 建置後 `notices.mjs` 產生 `dist/ketcher/THIRD-PARTY-NOTICES.txt`；`public/` 內有 Ketcher 的 LICENSE 與 NOTICE。
  - 專屬邏輯（需處理）：`unsupportedDrawing`、`unsupportedCheck`（`src/shared/structureChecks.ts`）是 CheMScutter 的輸入限制，含反應式即拒絕；錯誤分類與中文訊息在 `src/shared/inputErrors.ts`。

## 6. RDKit.js 使用方式

- 套件：`@rdkit/rdkit` 2026.9.1（`RDKit_minimal.wasm`）。
- 載入：`src/engine/rdkit/loader.ts` 的 `getRDKit()` 為單例，Promise 只初始化一次，可傳 `locateFile`；型別在 `src/engine/rdkit/types.ts`。
- WASM 位置：`src/worker/analysis.worker.ts` 以 `import wasmUrl from '@rdkit/rdkit/RDKit_minimal.wasm?url'` 取得含部署 `base` 的網址，再用 `locateFile` 指定；`src/worker/depiction.worker.ts` 同理。Node／Vitest 不需要 `locateFile`。
- 在 Web Worker 中執行：`src/worker/analysis.worker.ts`、`client.ts`（`new Worker(new URL(..., import.meta.url), {type: 'module'})`）、`protocol.ts`、`structureSession.ts`。
- 實際用到的功能（grep 次數）：`mol.is_valid`、`get_json`、`get_smiles`、`get_substruct_match(es)`、`get_descriptors`、`get_svg`、`get_num_atoms`、`rdkit.get_mol`、`set_log_capture`、`version`。
- **沒有用到**：3D 座標、ETKDG、MMFF／UFF、`get_molblock` 的 3D 輸出（與 KNOWN_ISSUES K01 一致，這部分不能由 CheMScutter 驗證）。

# 任務 I02 結果：內嵌 Python 引擎打包（D63）

日期：2026-11-16。CI 結果見文末。

## 做了什麼

- **內嵌 Python**：`engine/.venv` 為 3.12.7，python.org 有同版 `python-3.12.7-embed-amd64.zip`；sha256 取自實際下載檔，固定在 `scripts/embed-python.lock.json`（python.org 頁面沒有列 sha256，只能以自己下載的檔案為準）。套件用 `pip install --target`（`--require-hashes --no-deps --only-binary`）裝進內嵌環境的 `Lib/site-packages`，沒有複製 venv；`python312._pth` 加入 site-packages 與引擎資料夾。
- **requirements 加 hash**：`engine/requirements.txt` 的 numpy 2.5.4、pillow 13.0.0、rdkit 2026.9.1、scipy 1.18.1 各帶兩個 sha256（Windows win_amd64 wheel，供打包；manylinux x86_64 wheel，供 CI 的 ubuntu）。hash 皆取自 `pip download` 實際下載的檔案。pip 只要有一項帶 hash 就要求全部帶 hash，所以 `requirements-dev.txt` 的 6 個套件也補了 hash（CI job 本身未改）。
- **隨附內容與路徑**：`moleform_core`、`moleform_engine.py` 與引擎讀取的 15 張 CSV（從 `src/data` 複製，不手改）放進資源 `engine/`。主程式在打包版（資源內有 `python/python.exe` 與 `data/`）用內嵌 Python 並設 `MOLEFORM_DATA_DIR` 指向複本；開發環境維持 `engine/.venv` 與 `src/data`。引擎仍只聽 127.0.0.1、隨機埠、一次性權杖（未改）。
- **建置**：`scripts/assemble-engine.mjs`（輸出到已忽略的 `desktop/engine-runtime/`，每次從頭組）接進 `npm run desktop:build`（經 `desktop` 的 `dist`）。連跑兩次整個資料夾的雜湊相同（移除了 pip 產生、內含本機路徑的 `bin/*.exe` 與 `RECORD`）。`.gitignore` 補 `desktop/engine-runtime/`、`desktop/engine-runtime-cache/`。
- **授權聲明**：`THIRD-PARTY-LICENSES-ENGINE.txt`，由腳本從隨附套件自己的授權檔組成（Python、numpy、scipy、rdkit、pillow）；在 exe 內的 `resources/engine/`。
- **新增**：`tests/desktop/engineRuntime.test.ts`（3 項，雙引號）、`scripts/engine-sample.py`、`selftest.cjs` 新增 `--selftest=sample` 模式（送固定 5 個請求並存檔）。

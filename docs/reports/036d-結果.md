## 二、Bondi 看圖結果與定義原文（p.449 Table XV、p.450 Table XVII）

Table XV 的「Aromatic」區（Vw，cm³/mole）：

| 表中標籤原文 | Vw |
|---|---|
| `>C— (condensation)` | 4.74 |
| `>C— (alkyl)` | 5.54 |
| `>C–H` | 8.06 |
| Benzene | 48.36 |

**Bondi 對這三類沒有任何文字定義，只有上面的標籤。** 腳註 a：「See corrections for crowding and vicinal effects on Table XVII.」所以「取代」的原文只有 **alkyl**，沒有說接雜原子（–OH、–O–、–F、羰基）或稠合飽和環的芳香碳算不算。任務卡的「連接環外任何原子或飽和環」比 alkyl 寬，因此依卡的要求停下來問，使用者選「照任務卡」，本卡照此實作。

Table XVII（Decrements …due to Intramolecular Crowding and Related Effects）全部項目：

| 項目原文 | δVw（cm³/mole） | 本任務 |
|---|---|---|
| Decrement per cyclohexyl and per cyclopentyl ring, free and in transcondensed cyclic naphthenes | 1.14 | **不套用**（任務卡規定，使用者環值可能已含） |
| Decrement per ring in cis-condensed cyclic naphthenes（腳註 a：異構物混合時的正確修正） | 2.50 | **不實作**：SMILES 沒有立體資訊，判斷不了 |
| Decrement per methylene ring condensed to benzene（腳註 b：Or other aromatic ring system; examples: tetralin and indane） | 1.66 | 實作（FX01–FX03） |
| Decrement per dioxane ring | 1.70 | 實作（FX04），只限 1,4-二氧六環 |
| Decrement per single bond between conjugated double bonds | 0.25 | **不實作**：見下 |
| Decrement per single bond adjacent to carboxyl or amide group | 0.22 | 實作於酯基（FX05、FX06） |

Table XVI 腳註 d（>C=O）：「Corrections to carboxylates and amides in Table XVII.」——這是把酯基（羧酸酯）納入 0.22 修正的依據。

## 三、規則（固定、可重現）

**芳香 C 三類**（寫在 `freeVolume.ts` 檔頭註解與資料表備註）：

1. 芳香碳同時有三個芳香鄰居（以芳香鍵 `:` 相連，即兩個芳香環共用，萘、蒽、芘）→ 縮合 4.74（FV21）。
2. 否則有氫 → C–H 8.11（FV01，備註「Bondi C–H 為 8.06，差 0.6%，保留使用者值」）。
3. 否則（無氫）→ 取代 5.54（FV20）。
4. 茚滿與茀的稠合碳（屬一個芳香環與一個飽和環或五員環；茀的兩個苯環之間是單鍵不是芳香鍵）歸取代，標「詮釋，待使用者審」。

SMARTS：FV01 `[#6;a;H1]`、FV20 `[#6;a;H0;!$([#6](:a)(:a):a)]`、FV21 `[#6;a;H0;$([#6](:a)(:a):a)]`。三類互斥，三類個數相加 = 芳香碳總數（測試對全部 xlsx 結構與案例檢查）。

正反例（測試）：苯（6／0／0）、甲苯（5／1／0）、苯酚（5／1／0）、萘（8／0／2）、聯苯（10／2／0）、茚滿（4／2／0）、茀（8／4／0）、二苯醚（10／2／0）、蒽（10／0／4）、芘（10／0／6）；FV01、FV20、FV21 各有正例與反例。

**Table XVII 修正的計數方式**（每項在輸出列出適用次數與數值）：

| 項目 | 計數 |
|---|---|
| FX01、FX02 亞甲基環（1.66） | 五員環（兩個芳香碳＋三個飽和碳，茚滿型）、六員環（兩個芳香碳＋四個飽和碳，四氫萘型）各算 1 環；以環原子集合去重；SBI 兩個茚滿環共 2 次 |
| FX03 茀五員環（1.66） | 一個飽和碳＋兩個苯環各兩個芳香碳，算 **1 個環、減 1 次**（使用者指定，詮釋，待審） |
| FX04 二氧六環（1.70） | 只限 1,4-二氧六環（論文只寫 dioxane，沒指明異構物，詮釋）；1,3-二氧六環不套用（測試固定） |
| FX05、FX06 酯基旁單鍵（0.22） | 每個酯基 2 個：羰基碳接外側碳（或連接點 `*`）的單鍵 1 個＋單鍵 O 接外側碳（或連接點）的單鍵 1 個，即每個酯基減 0.44。與 D59 對羧酸、碳酸酯的計數方式一致（詮釋，待審）；酮、醚、羧酸、醯胺不適用（羧酸、醯胺在本方法是缺基團） |

**不實作（論文敘述不清楚，不猜）**：

- **共軛雙鍵間的單鍵 0.25**：論文沒說芳香環、羰基算不算「雙鍵」；本方法的基團表沒有烯烴（烯烴回報缺基團），所以可以判斷的情況本來就不存在。
- **cis-稠合環 2.50**：需要立體資訊，SMILES 沒有。萘烷等不扣。
- **環己基與環戊基 1.14**：任務卡規定不套用。

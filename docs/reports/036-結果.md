### A2 CTE 在書中怎麼估

- 定義（書頁 89，4.4.1 節，式 4.9）：莫耳膨脹率 E = ∂V/∂T（cm³/mol/K）；比膨脹率 e = E/M = ∂v/∂T（cm³/g/K）；體膨脹係數 α = (1/v)·∂v/∂T = E/V（K⁻¹）；線膨脹係數 β = (1/L)·∂L/∂T，**α = 3β**。
- 玻璃態與橡膠態（書頁 89，式 4.10）：α_g ≈ α_c；以兩條直線表示，轉折點在 Tg；書中報導 e_g（轉變前）與 e_l（轉變後）。
- 估算法（書頁 91–95）：由 Table 4.12 的 E 對 VW 作圖（圖 4.3，書頁 96），平均直線
  - E_l（= E_r）= 1.00×10⁻³·VW（式 4.17）
  - E_g（= E_c）= 0.45×10⁻³·VW（式 4.18）
  - Table 4.12 比較：平均偏差 E_l 8%、E_g 12%，實驗數據本身約 ±5%（書頁 94）。
- 體膨脹係數（書頁 99，推導式 4.11a）：α_l(298) = E_l/V_r(298) = 1.0×10⁻³·VW / (1.60·VW) = 6.25×10⁻⁴ K⁻¹；α_g(298) = E_g/V_g(298)，V_g ≈ 1.6·VW，得 2.81×10⁻⁴ K⁻¹。
- 玻璃態的 V_g(298)（書頁 95–96，式 4.27–4.28）：V_g(298) = [1.43 + 0.55×10⁻³·Tg]·VW；書頁 96 說明式 4.8b（1.6·VW）「偏低」，PMMA 與 PS 以式 4.27 得 1.643、1.635。
- Example 4.2（書頁 101）：PET 的熔體 CTE，用 E_g、E_l（式 4.17、4.18）與 Tg = 343 K 算 V(550 K)。

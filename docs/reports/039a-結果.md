## 2. 依賴關係與核心鏈

```
atomicWeights ─┬─────────────────────────────┐
molGraph(J) ───┼─ vanDerWaalsVolume ◀ vwGroups, vwGroupsBondi
               ├─ tgGroupContribution ◀ ygGroups, ygCalibratedGroups
               │        │
               ├─ molarVolumeDensity ◀ VW, Tg, molarVolumeGroups
               │        │
               │   cte ◀ VW, Tg
               │        │
               ├─ freeVolume ◀ VW, Vm, polymer/copolymer, freeVolumeTables
               │        │
               └─ relativeTg ◀ VW, Vm, freeVolume, cte, tgMixing.foxMix, packingCoefficientK

tgMixing ◀ tgGroupContribution, jobackTbTf, novolacUnits, tgMnData,
           formulation/compute, formulation/molecularWeight, polymer/convert, polymer/copolymer
polymer/copolymer ◀ repeatUnit, endGroups      dielectricRefraction ◀ VW, Vm, 兩個資料表
```

**核心鏈搬遷順序**：共用層（atomicWeights、molGraph、CSV 讀取）→ VW → Tg（Yg）→ Vm／密度（Va）→ CTE → 自由體積 → 相對 Tg。
注意：Vm 依賴 Tg（判斷玻璃態／橡膠態），所以 Tg 必須在 Vm 之前；自由體積依賴 `polymer/copolymer`（→ repeatUnit、endGroups），需先搬聚合物基礎；相對 Tg 只用 tgMixing 的 `foxMix`（純數值），不必等整個 tgMixing。

## 3. RDKit 風險清單

| # | 依賴的行為 | 使用處 | 現有測試例 | 差異可能性 |
|---|---|---|---|---|
| R0 | 版本不一致：RDKit.js 2026.09.1 vs Python 2026.09.2 | 全部 | rdkit-smoke | **必須先處理** |

## 4. 黃金資料方案（只提方案）

- 匯出：新增 `scripts/golden/export-<module>.ts`（用 vite-node／vitest 執行現有 TS 函式），輸出 `tests/golden/<module>.json`：
  `{ module, commit, rdkitjs: "2026.09.1", cases: [{ id, input, output }], tolerance }`。
  `output` 為函式回傳物件原樣（含缺基團原子位置、警告、備註），鍵排序後 `JSON.stringify`。
- 比對：Python 端 `engine/tests/test_golden_<module>.py` 讀同一檔。
  - 字串、整數、陣列（原子索引、基團 id、缺基團清單）：逐字相同。
  - 浮點：預設也逐字相同（JS 與 Python 的浮點最短字串表示同為 round-trip，相同值會輸出相同文字）；若因 `pow`／`log` 末位差異無法逐字，記錄案例後由使用者決定是否給 `rel 1e-12`（見不確定 U6）。
- 重產時機：TS 版有任何改動就重產；Python 版通過後 TS 版進入「過渡期開關，預設 TS」（PLAN 6A.3）。

## 6. 即時回饋類小計算

觸發點（實際查 `src/ui/`、`src/worker/` 的匯入與 worker 請求類型）：

| 計算 | 觸發 | 建議 | 依據 |
|---|---|---|---|
| structure/validate（驗證、canonical）、molfileChecks、sdf、drawingChecks | 每次輸入結構（worker `validate`） | **留 TS** | 輸入當下回饋；不含化學模型公式；與 Ketcher 綁在一起 |
| crosslink/draw（SVG） | 顯示結構圖（worker `draw`） | **留 TS** | 繪圖，不是計算 |
| formulation/molecularWeight | 加入成分（worker `weight`） | **留 TS** | 每次輸入觸發；單一描述子 |
| polymer/repeatUnit、unitFragment | 編輯聚合物單元（worker `repeatUnit`、`unitFragment`） | **留 TS**（6A.4-03 另做 Python 版供物性用） | 輸入時檢查連接點；Python 物性也需要，兩邊以黃金檔保持一致 |
| formulation/compute | 工作台每次改數量（Workbench 主執行緒） | **留 TS** | 單位換算、無化學模型；039 實測引擎啟動 0.6–0.9 秒、import rdkit 約 2 秒，不適合每次按鍵 |
| polymer/convert | PolymerFields 輸入 Mw／PDI | **留 TS** | 同上 |
| 交聯第 0 層、第 1 層卡片 | 交聯頁（worker `crosslink`；Layer1Cards 主執行緒） | **搬**（13、12 卡，低優先） | 含模型判斷（D41、D42），非逐鍵輸入 |
| properties/* 全部 | 目前未接介面 | **搬** | 核心鏈 |

建議：tgMixing 搬到 Python 時**不搬 formulation/compute**，改由 TS 傳入已算好的質量分率，避免兩份換算實作。

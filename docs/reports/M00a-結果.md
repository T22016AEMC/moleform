## 2. 新增的 CI job

- **engine**（ubuntu、Python 3.12）：`pip install -r engine/requirements-dev.txt` → `python -m pytest engine/tests -q`。
- **golden-fresh**（ubuntu、Node 24、`npm ci`）：重跑 `scripts/golden/export-*.ts`，再以內嵌 Python 把工作目錄的 `tests/golden/*.json` 與 `git show HEAD:` 的已提交版本比對；失敗時印出「TS 計算或資料表改了，請重產黃金檔」與過期檔名。
  - 排除 `commit` 欄位（每次提交都會變）。
  - 只對以實際資料檔為輸入的案例（`parseCsv/data:*`、`readTable/*/real`，共 9 例）把 CRLF 視為 LF，其餘案例逐字比對。原因：`csv.json` 內嵌 `src/data/*.csv` 原文，Windows 本機（autocrlf）有 6 個檔檢出為 CRLF、CI 為 LF。第一次推送（33ff86a）因此誤報，已修正（3745ab2）。輸出（output）本身兩邊本來就相同。

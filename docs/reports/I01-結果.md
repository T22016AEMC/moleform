# 任務 I01 結果：介面接引擎（桌面版啟動引擎、橋接、最小物性面板）

日期：2026-11-16。CI 結果見文末。

## 做了什麼

- **引擎生命週期**：桌面主程式在開窗時（與載入頁面同時）啟動 `engine/.venv` 的 Python 引擎（沿用 039：隨機埠、一次性權杖、只 127.0.0.1），結束時關閉。啟動失敗時面板顯示原因，其餘功能照常。
- **受限橋接**：`desktop/preload.cjs` 只暴露 `window.moleformEngine.call(path, body)` 與 `.status()`；主程式（`desktop/bridge.cjs`）代發 HTTP，只允許 11 個白名單路徑（`/vw /tg /vm /cte /free-volume /dielectric /joback /tpsa-logp /tg/mixing /mixture-density /mixture-dielectric`）、`engine.host` 必須是 127.0.0.1、本文須為 ≤60 KB 的 JSON 物件；只接受主框架（不含 Ketcher iframe）的呼叫；回應不含權杖與埠。`contextIsolation`、`nodeIntegration: false`、sandbox、網路封鎖未改。橋接一次只送一個請求（引擎的連線佇列只有 5，同時 8 個請求會 ECONNREFUSED，實測發現）。
- **物性面板**：工作台右欄新增一個 `ResultBlock`「物性（Python 引擎）」（`src/ui/engine/`）。對象下拉：各成分（聚合物單元／小分子）或「配方（混合）」。每列顯示 value／unit／source／status，缺值顯示 `missing` 與原因（缺基團清單、不適用說明等）。純網頁顯示「需要桌面版與引擎」。
  - 單一對象：VW、Tg、Vm、密度、CTE α×3、自由體積、ε 與極化率 α′／α、Tb／Tf、TPSA／LogP。小分子不呼叫 `/tg`，直接顯示 missing（D56）。
  - 配方：成分 Tg、混合 Tg（含部分混合值）、混合密度、混合介電（Lichtenecker／Wiener 上下界）。質量分率、Mn、每分子質量由 `computeFormulation` 的結果換算後傳入；混合只混 Solid 區、扣除 Catalyst 與揮發／分解成分並重新正規化；共聚物成分不傳 SMILES（不以第一種單元代表）。
- 既有檔案只動 `Workbench.tsx`（換算 memo 多回傳 `mnById`、加一行面板），`src/core/`、引擎計算與端點均未改。

## 測試與實測

- 新增測試 13 項（`tests/desktop/bridge.test.ts`：白名單、非白名單／任意網址／非 127.0.0.1 被拒、本文限制、回應不含權杖；`tests/engine-ui/propertyRequests.test.ts`：輸入轉換）。`npm run typecheck`、新增測試、`npm run build`、`npm run desktop:build`（exe 119,124,539 bytes）本機通過。
- **一次性實測**（`npm run selftest:engine --prefix desktop`，桌面版實際啟動，加入 PMMA 單元＋乙醇）：
  - 引擎 ready（`127.0.0.1:56089`，啟動 1049 ms）。面板：聚合物單元 **Tg 377.622 K、Vm 91.07 cm³/mol、密度 1.09934 g/cm³**；經橋接取得的 `/tg`、`/vm` 回應與直接呼叫引擎處理函式的 JSON **完全相同**，面板數字與直接值一致。
  - 缺值顯示：乙醇的 Vm／密度／ε／CTE 顯示 `missing` 與引擎原因；聚合物的 Tb／Tf 顯示不適用；PMMA 的混合 Tg 顯示 `missing`（缺 K 表類別）。
  - 橋接拒絕 `/handshake` 與 `http://example.com/tg`；`window` 上只多了 `moleformEngine`（keys: call、status）。
  - 關閉後：埠已釋放（連線被拒）、啟動器行程（含 2 個子行程）已不存在，`Get-Process` 無殘留 python／electron。

## 介面還缺什麼

- 共聚比例掃描、相對 Tg、交聯新入口（本卡範圍外）。
- 「分子工具」分頁尚無物性入口（目前只能從配方成分看）。
- 配方混合密度／介電在含小分子時必為 missing（小分子液體密度 Fedors 未收錄）；PMMA 等不在 K 表的樹脂混合 Tg 為 missing。
- source 欄顯示完整模型文字，列很長；排版留待 D45 美化。

## 需要使用者決定

1. **打包版（exe）目前算不出物性**：exe 只帶 `moleform_engine.py`，沒有 `moleform_core` 與 venv，面板會顯示引擎回報的 503（引擎無法載入模組）。依指示內嵌 Python 留給另一張卡（D63）；是否需要先讓 exe 帶 `moleform_core`（仍缺 RDKit）？
2. 配方混合是否也要納入 Liquid 區成分（目前不混，與 Tg 混合一致）？

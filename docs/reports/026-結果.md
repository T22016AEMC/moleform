### 二、我們的規則或讀值可能有誤（2 筆，證據偏弱，需要你查書決定）

兩筆都含碳酸酯，都用「Table 6.3 組合 ＋ Table 6.1 碳酸酯 20」，而且**同方向、同量級偏高**：ΣYgi 差 −2.23 與 −1.76，換成 Tg 約高 8 K。共同點只有「碳酸酯 –O–C(=O)–O– 與其相鄰芳香環」，所以懷疑的是我們對這個相鄰關係的處理，不是 Table 6.3 組合本身：

- 書中值若解讀為「組合值 ＋ 碳酸酯 x」，x ＝ 17.77（±0.13）與 18.24（±0.11），都接近 18，而不是 20。但 Table 6.1 的 C-hetero 三列（碳酸酯、胺基甲酸酯、脲）圖上確實都印 20，聚脲（Table 6.4 書頁 144）用 20 重現（+0.02 K），所以不能直接說 20 讀錯。
- BPA 聚碳酸酯若不用 Table 6.3 組合、拆開成兩個「c」態對位苯環（35×2）＋ –C(CH3)2– 受阻 15 ＋ 碳酸酯 20 ＝ 105 → 412.9 K，與書中 412 差 0.9 K（只在 1 K 內）。但同樣的拆法套到亞甲基二伸苯碳酸酯（2×35 ＋ 2.7 ＋ 20 ＝ 92.7 → 410 K）與書中 368 差 42 K，且碳酸酯在 Table 6.1 屬 A「非共軛基團」，苯環與它之間隔著 O，依書頁 140 的定義苯環不算共軛。所以 BPA 這一筆的吻合很可能是巧合，不能當證據。

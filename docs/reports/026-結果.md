## 共軛狀態規則的實作依據

- 書中只有兩處文字：Table 6.1 B 表尾註（書頁 134：n = 脂肪鏈中孤立；c = 一側與芳香環共軛；cc = 兩側夾在兩個芳香環之間）與 6.2.2.4 文字（書頁 140：苯環「與另一個雙鍵基團」在一側共軛為 35、兩側為 41；–C(CH3)2– 夾在兩個芳香環之間為 15.0）。
- 依你的回答，**先配 Table 6.3 組合基團，配不到再拆回 Table 6.1**（組合基團沒有共軛狀態，直接用書中值）。
- 拆回後的判定（程式實作，待你審）：
  - 雙鍵基團（C=O、CONH）：基團向外的鍵中，對面是芳香原子的有幾邊 → 0 邊 n、1 邊 c、2 邊 cc。
  - 苯環：向外的鍵中，對面原子屬於「B 雙鍵系統」基團的有幾邊 → n／c／cc。醚 O、C(CH3)2、苯環直接相連都不算共軛。
  - 聚合物單元的兩個連接點視為首尾相接（跨單元判定）。
- 書中沒定義、我自行採用的兩項規則（請審）：①「氫鍵鏈」＝單元內有 CONH、胺基甲酸酯或脲基（依 Fig. 6.3 說明與書頁 139 註腳指聚醯胺、聚胺基甲酸酯、聚脲）；②–C(CH3)2– 兩側相鄰原子都是芳香原子才算受阻（15），其餘取自由（8.5）。
- 書中 Table 6.1 B 另有表 D（共軛加成值，書頁 136，標為暫定）與括號數值的用法，**沒有實作**，因為上面的 n／c／cc 取值已涵蓋；表 D 與 B 表的 C=O（n 11.5、c 15.5、cc 19 相差 4、7.5）數值看起來不是同一套，書中沒說明。

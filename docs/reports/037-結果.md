## 6. C：驗證與手算

- Bondi 論文沒有茀、茚滿、四氫萘、碳酸酯、羧酸、NH2、P 化合物的 VW 值（只有 Table XIII／XIX 的甲烷、乙烷、乙烯、乙炔、苯，補充沒有介入這些），所以補充基團**無法用 Bondi 化合物值驗證**，以手算驗證程式照規則加總（算式也寫在測試裡，數值取自測試內獨立抄錄的 Bondi 表）：
  - 三苯基膦：3×45.85 + 10.44 = 147.99
  - L-丙胺酸：13.67 + 6.8 + 8.0 + 11.70 + 10.54 − 0.22 = 50.49
  - DDS：2×43.3 + 20.3 + 2×10.54 = 127.98
  - 雙酚 A 聚碳酸酯：11.70 + 2×3.2 + 2×43.3 + 30.7 − 2×0.22 = 134.96（書 Table 4.7 為 136.2，−0.92%；若 O 都用 3.7，不含修正為 136.4，與書相近）
  - 雙酚茀單元：2×8.0 + 14×8.05 + 6×5.55 + (3.33 + 4×5.54) − 1.66 = 185.83
  - SBI 雙酚：4×13.67 + 2×8.0 + 6×8.05 + 2×5.55 + 4×5.54 + 2×3.33 + 2×10.23 + 3.33 − 2×1.66 = 179.37
  - 茚滿：2×5.54 + 3×10.23 + 4×8.05 − 1.66 = 72.31；四氫萘：2×5.54 + 4×10.23 + 4×8.05 − 1.66 = 82.54
- 回歸：書的基團能配完的結構，補充前後的結果 JSON 全等（含 groups、vw、sources、model）。
- 每個新基團與修正至少一個正例、一個反例；Bondi 判為不能算的 14 個結構仍回報缺基團；切分完整性（每個重原子恰好一個基團）。

## 7. 詮釋與邊界（全部待使用者審）

1. **連接點 `*` 上的碳酸酯 O（BG12、BG13）**：你指定「依所接的碳」，但重複單元的 `*` 不是碳。我用「頭尾相接」判斷：單元恰有兩個連接點，另一端的連接點接芳香原子 → 芳香醚 3.2；接非芳香碳 → 烷基醚 3.7；連接點數不是兩個就不配對（維持缺基團）。這是我的詮釋，請確認。
2. **羧基／碳酸酯旁單鍵的計數**：羧酸 1 次（羰基碳接的那個 C–C）、碳酸酯 2 次（兩側 O–C 或 O–*）。羧酸的 –OH 先由書的 V17（8.0）配走，不用 Bondi 8.04。
3. **稠合碳取 5.54**：茀與茚滿型的稠合碳都用「烷基取代芳香碳」5.54，不用縮合 4.74。限制：茚滿／四氫萘型要求苯環只與一個全碳飽和環（5 或 6 員）稠合，稠合碳不屬於其他環；茀限 9,9-二取代、兩個苯環不再與其他環稠合。9H-茀、苯并茀、噻咯等維持缺基團。
4. **–NH2** 只收接在碳上、且該碳沒有羰基或其他雜原子取代者；醯胺 NH2、脲、胍維持缺基團。**>P** 只收三個鍵都接碳者。
5. 修正量只在命中的原子至少有一個屬於補充基團時套用，書的基團不套用（書值不動）。

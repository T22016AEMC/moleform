## B. 桌面封裝原型

### B-1 主程式

- `nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`、`webSecurity: true`、`webviewTag: false`，沒有 preload。
- 禁止導向本程式以外的網址（`will-navigate`、`will-redirect`、`will-frame-navigate`），開新視窗一律拒絕，拒絕所有權限要求。

### B-6 Python 引擎原型

- 啟動：Electron 主程式以 `python -I -u engine/moleform_engine.py` 啟動；權杖（32 bytes 隨機）從 stdin 第一行交付，不放命令列或環境變數。引擎綁定 `127.0.0.1:0`（作業系統給隨機埠），回報埠號後主程式才連線。
- 防護：權杖錯誤 401；帶 `Origin`（瀏覽器發出）或 `Host` 不是 `127.0.0.1:埠` 一律 403；請求上限 64 KB；不寫存取紀錄；引擎本身不對外連線。
- 關閉：主程式結束時關閉 stdin，引擎自行結束；3 秒內沒結束就 `taskkill /T /F`（venv 的 `python.exe` 會再開一個子程序）。父程式異常結束時 stdin 也會關閉，引擎同樣結束。
- 握手回報（實際讀取已安裝套件的版本資訊，與 pip 相同來源）：

| Python | 環境 | NumPy | SciPy | RDKit |
| --- | --- | --- | --- | --- |
| 3.12.7 | `engine/.venv`（開發） | 2.5.4 | 1.18.1 | 2026.9.2 |
| 3.12.7 | PATH 上的 python（exe 實測） | null（未安裝） | null | null |

- JSON 格式示範（`POST /demo/quantity`，只檢查格式、原樣回傳，不計算）：

```json
請求  {"quantity": {"value": 1.05, "unit": "g/cm3", "source": "格式示範（非真實數值）", "status": "assumed"}}
回應  {"ok": true, "quantity": {…同上…}, "note": "格式示範：引擎未計算任何數值"}
錯誤  status 為 "guessed" → 400 {"ok": false, "errors": ["status 必須是 measured / literature / fitted / predicted / assumed / missing 之一"]}
```

另有規則：`status = missing` 時 `value` 必須是 null；`value` 為 null 時 `status` 必須是 missing。

- 實測時間：引擎啟動到回報埠號 643–755 ms（venv）／672–900 ms（PATH 上的 python）；握手 20–33 ms；`import numpy, scipy, scipy.optimize, rdkit.Chem` 約 1.9–2.4 秒（空的 Python 約 0.6 秒）。

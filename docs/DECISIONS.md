## 二、建議（待確認）

| 編號 | 建議 | 原因 |
|---|---|---|
| S01 | 基本版凝膠點與交聯密度用 **Miller–Macosko**，不用 Flory–Stockmayer | Flory–Stockmayer 假設無環化、同類官能基等活性，與規格要求考慮競爭反應互相矛盾 |
| S02 | DiBenedetto 的 λ 用近似 λ ≈ Tg0 / Tg∞（兩者皆由基團貢獻估算），並標示為近似 | 不輸入實驗值的前提下需要一個替代 |
| S03 | 交聯起始溫度顯示**規則表記錄的文獻典型溫度範圍**；不從結構、自由體積或位阻計算 | 反應起始溫度主要由活化能與催化劑決定，無法只靠結構算出 |
| S04 | 「估算 Tg∞ 高於 Td」時顯示警示 | 提示配方可能在完全固化前分解 |
| S05 | 固化收縮用**規則表中每種反應的文獻單位鍵體積變化值**計算，不用反應前後基團貢獻體積相減 | 後者是兩個大數相減，誤差大 |
| S06 | 反應規則表每條規則記錄：反應類型、SMARTS、所需催化劑、典型溫度範圍、官能度、副產物（縮合型）、單位鍵體積變化、出處 | 同一官能基組合在不同條件下結果不同 |
| S08 | 小分子的 Tg、Tm 另用 Joback 法估沸點與熔點作為補充 | Van Krevelen 參數主要建立在聚合物上 |

# Phase 6 介電常數與極化率輸出

**基團加成估算，非實測；含極性基團的 ε 受頻率與溫度影響（Table 11.2 觀測值屬 10²–10⁹ Hz 低頻範圍）。**

以下為程式輸出，未經化學判斷（D17）；分子量與單元質量只用於式 (11.8) 的計算，網站上不顯示（D09）。

- 結構處理：RDKit 2026.09.1
- **ε 的方法**：van Krevelen & te Nijenhuis, Properties of Polymers 4th ed. (2009), 11.2.3 節：式 (11.7) P_LL = (ε − 1)/(ε + 2)·V（V ＝ Va，任務 029）與式 (11.8) P_V = ε^½·M；基團增量見 Table 11.1（書頁 321）。基團表 `src/data/polarization_groups.csv`（20 列，稽核狀態皆為「待使用者審」）。可信度：理論估算（基團貢獻法）。
  - **式 (11.7)**：ε = (1 + 2x)/(1 − x)，x = ΣP_LL / V；V 使用任務 029 的非晶態莫耳體積 Va。書中式 (11.7) 與 Example 11.1 只寫「V(298)」，沒說 Va 或 Vc；依 PE 試算選擇 Va（使用者 2026-11-01 決定，驗證見第 4 節）。
  - **式 (11.8)**：ε = (ΣP_V / M)²，不需要莫耳體積；M 為結構單元質量。沒有莫耳體積的結構仍輸出此版本，註明「缺莫耳體積，僅 P_V 估計」。
  - **頻率**：書中未註明 P 的適用頻率；Table 11.2 的觀測值屬 10²–10⁹ Hz 低頻範圍（書頁 320）。含極性基團的 ε 受頻率與溫度影響。
  - **暫定值**：Table 11.1 中印於括號內或「~」的 P_LL、P_V 照數值收錄，書中標為暫定；用到時在結構旁標「†」（P_LL 暫定）或「‡」（P_V 暫定）。
- **ΣR 與 α 的方法**：van Krevelen & te Nijenhuis, Properties of Polymers 4th ed. (2009), 10.2 節 Table 10.4（R_LL，λ = 589 nm，書頁 293–294）；α 由式 (11.10)、(11.11)（書頁 321–322）換算。基團表 `src/data/molar_refraction_groups.csv`（47 列，稽核狀態皆為「待使用者審」）。ΣR 單位 10⁻⁶ m³/mol ＝ cm³/mol；α′ ＝ 3ΣR/(4π·N_A)（Å³／單元），由式 (11.10)、(11.11) 換算。**不輸出折射率 n 與 n²（D07）。**
- **缺基團**：切分規則與 Tg、VW、莫耳體積相同（原子數由大到小配對；每個重原子恰好屬於一個基團；重疊優先順序為現行的最大組合優先，M26 未決，未更動）；配不到的原子回報「缺基團」，不用相近基團或記憶中的數值代用。鄰位與間位伸苯基 Table 11.1 沒有，不配對（使用者 2026-11-01 決定不放寬）。
- **小分子**：Table 11.1、Table 10.4 是聚合物重複單元的基團增量，不含連接點（*）的小分子標「不適用（小分子）」。
- 本數值為依理論模型估算之參考值，非實測值。實際結果受原料純度、製程條件與反應動力學影響，請以實驗結果為準。
- 重新產生：`npm run verify:phase6-dielectric`。

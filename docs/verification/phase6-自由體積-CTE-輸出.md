# Phase 6 熱膨脹係數 CTE 輸出

**基團加成估算，非實測；CTE 隨溫度與固化度變化。書中平均偏差：E_l 8%、E_g 12%（Table 4.12，書頁 94）；實驗數據本身約 ±5%。**

以下為程式輸出，未經化學判斷（D17）；單元質量只用於比膨脹率 e，網站上不顯示（D09）。本輸出不使用實驗值當輸入（D02）；書中實驗值只在第 3 節當比較。

- 結構處理：RDKit 2026.09.1
- **方法**：van Krevelen & te Nijenhuis, Properties of Polymers 4th ed. (2009), 4.4 節 MTE 模型：E_l = 1.00×10⁻³·VW（式 4.17，書頁 91）、E_g = 0.45×10⁻³·VW（式 4.18）；α = E/V（式 4.9，書頁 89）；V_r(298) = 1.60·VW（式 4.24）、V_g(298) = [1.43 + 0.55×10⁻³·Tg]·VW（式 4.27，書頁 95）；β = α/3（式 4.9）。
  - 莫耳膨脹率：E_l（橡膠態／液態）= 0.001 × VW（式 4.17）；E_g（玻璃態）= 0.00045 × VW（式 4.18）；單位 cm³/mol/K。比膨脹率 e = E/M（cm³/g/K）。
  - 體膨脹係數 α = E/V（式 4.9）：α_l 用 V_r(298) = 1.6·VW（式 4.24），α_l = 6.25×10⁻⁴ K⁻¹，與結構無關；α_g 有兩種算法並列（書頁 96 說明式 4.8b「偏低」，不替使用者選）：(a) V_g(298) ≈ 1.6·VW（式 4.8b，書頁 99 的用法，不需 Tg，α_g = 2.81×10⁻⁴ K⁻¹，同樣與結構無關）；(b) V_g(298) = [1.43 + 0.55×10⁻³·Tg]·VW（式 4.27，需 Tg）。
  - 線膨脹係數 β = α/3（式 4.9 的 α = 3β，等向性假設）。ppm/K ＝ α × 10⁶。
  - **只依 VW（式 4.17、4.18）的 E 隨 VW 成正比；α 因分母也是 VW 的倍數，在模型中是常數**（6.25×10⁻⁴ 與 2.81×10⁻⁴）。要區分不同聚合物的 α，只有式 4.27 的 Tg 項（變化很小，Tg 300–500 K 時 V_g/VW 為 1.595–1.705）。這是書中方法的性質，不是程式問題。
  - **適用條件**：書中的 Table 4.12 比較：平均偏差 E_l 8%、E_g 12%，實驗數據本身約 ±5%（書頁 94）。CTE 隨溫度與固化度變化；本方法是未交聯聚合物重複單元的估算，交聯網路的 CTE（例如 EMC、底填膠含填料）不在本方法範圍。
  - **不使用的規則**：Table 4.11 的經驗規則（Simha–Boyer、Boyer–Spencer、Bondi、Tobolsky–Bueche）書中明文不得互相代入推新式（書頁 90），本程式不使用。
  - **自由體積分率**：書中沒有由結構計算的方法；本輸出不含（見報告 036 第一節）。
- **缺基團**：VW 用任務 028／031 的切分（Table 4.2），Tg 用任務 026／033（Table 6.1，必要時含校準基團，標「含校準基團」）；重疊優先順序為現行規則（M26 未決，未更動）。配不到的原子回報缺基團，不用相近基團或記憶中的數值代用。缺 VW → 不算任何 CTE；缺 Tg → 只缺式 4.27 的 α_g(b)，其餘照算。
- **小分子**：不含連接點（*）的結構標「不適用（小分子，D56）」。
- Va、Vc 欄來自任務 029（Table 4.10 基團），只供參考，不參與 CTE 計算。
- 本數值為依理論模型估算之參考值，非實測值。實際結果受原料純度、製程條件與反應動力學影響，請以實驗結果為準。
- 重新產生：`npm run verify:phase6-cte`。

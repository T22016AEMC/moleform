# Phase 6 聚合物莫耳體積與密度輸出

**莫耳體積與密度為基團加成估算，非實測；以 cm³/mol 與 g/cm³（結構單元）表示。**

以下為程式輸出，未經化學判斷（D17）；單元質量只列在本文件供核對，網站上不顯示（D09）。

- 結構處理：RDKit 2026.09.1
- **方法**：van Krevelen & te Nijenhuis, Properties of Polymers 4th ed. (2009), 4.3.7 節：Vm = ΣVi(298)（基團增量見 Table 4.10，書頁 88）；密度 = 結構單元質量 ÷ Vm。基團表 `src/data/molar_volume_polymer_groups.csv`（27 列，稽核狀態皆為「待使用者審」）。可信度：理論估算（基團貢獻法）。
- **Va、Vc**：Table 4.10 的 Va,i(298) 是非晶態增量，Vc,i(298) 是結晶態增量。依書中式 (4.8a)、(4.8b)，玻璃態與橡膠態的莫耳體積相同（都用 Va），所以兩種狀態的數值相同，只差標籤；Example 4.1 中標「Vg(298)」的欄就是 Va。
- **298 K 的狀態**：Tg（任務 026）低於 25 °C 為橡膠態，高於 25 °C 為玻璃態（書頁 79、80）；Tg 算不出來（缺基團）就不判斷，標「狀態未定」，玻璃態與橡膠態兩種結果都輸出。
- **括號值**：Table 4.10 中印於括號內的數值（–O– al./ar.、–CONH–）照數值收錄，書中標為暫定；用到時標「括號值」。
- **缺基團**：切分規則與 VW 相同（原子數由大到小配對；每個重原子恰好屬於一個基團）；配不到的原子回報「缺基團」，不用相近基團或記憶中的數值代用。
- **小分子**：液體莫耳體積（Table 4.5 沒有推薦欄）改用 Fedors 1974，由使用者決定另開任務（與 8.3 溶解度參數合併），本任務未實作，標「液體法未實作」。
- 本數值為依理論模型估算之參考值，非實測值。實際結果受原料純度、製程條件與反應動力學影響，請以實驗結果為準。
- 重新產生：`npm run verify:phase6-vm`。

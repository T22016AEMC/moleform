# Phase 2 輸出（結構驗證與 3D）

以下為程式輸出，未經化學判斷。請使用者依文獻或經驗檢查是否合理（D17）。

- 3D 設定：OpenChemLib 9.25.2（ConformerGenerator，種子 42，要求 5 個構象）；MMFF94 最佳化；結構驗證：RDKit 2026.09.1
- 鍵長、鍵角取自構象 1（有 MMFF94 能量時即最低能量構象；未最佳化時為產生的第一個構象），由 x、y、z 座標計算（`src/core/geometry.ts`），含氫原子。

- 重新產生：`npm run verify:phase2`（說明見 `docs/verification/README.md`）。

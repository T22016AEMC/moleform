## 備註

- P 以使用者提供的組成 雙酚茀：萘基次甲基 = 2：1 建立 Random 共聚物（2026-10-29）。程式只依組成與分子量計算，不檢查縮合反應的連接規則；A 多於 B 的部分在結構上等同隱含 A–A 直接相連

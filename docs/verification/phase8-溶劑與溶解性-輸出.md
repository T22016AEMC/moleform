## 2. 書算例對照

### 2.1 Example 7.3（書頁 216）：雙丙酮醇，V = 123.8 cm³/mol（Hoftyzer–Van Krevelen，式 7.22–7.24）

| 分量 | 書值 | 本程式 | 差 |

| δp | 7.4 | 7.4160 | 0.0160（書印 1 位小數，四捨五入後相同：是） |
| δh | 13.3 | 13.3306 | 0.0306（書印 1 位小數，四捨五入後相同：是） |
| δ（式 7.14） | 21.9 | 21.9853 | 書用已四捨五入的 15.8、7.4、13.3 算：√(15.8²+7.4²+13.3²) = 21.938 → 21.9（本程式用未四捨五入的分量，得 21.985） |

**結論**：三個分量都與書相同（書印位數）。總 δ 的差只來自書先把分量四捨五入。

### 2.2 Example 7.5（書頁 219）：聚醋酸乙烯酯 Hoftyzer–Van Krevelen 欄（δd 16.0、δp 6.8、δh 8.5、δ 19.4）

- 本程式（V 取 Vm 模組 68.77 cm³/mol）：δd 16.87、δp 7.13、δh 10.09、δ 20.91。基團：–COO–（酯基）、–CH3、–CH2–、>CH–
- ΣFdi = 1160、√ΣFpi² = 490、ΣEhi = 7000。書印的 δd 16.0 與 δp 6.8 對應 V ≈ 72.5（72.1）cm³/mol，但用同一個 V，ΣEhi = 7000 給出 δh = 9.83，與書印的 8.5 不同。
- **不一致且無法由書內資料解釋**：書在 Example 7.5 沒有寫 HVK 欄的算式與 V（該段的算式只展開 Hoy 法），HVK 欄的 δh 8.5 無法由 Table 7.10 的值（–COO– Ehi = 7000）重現；δd、δp 在 V ≈ 72 cm³/mol 時與書相符。本程式不調整任何數值（見報告，需使用者決定）。

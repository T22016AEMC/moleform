# Phase 5 使用者檢查清單（Phase 5.7，瀏覽器確認）

把任務 020～024（含各「後續」）累積的瀏覽器確認項目整理在這裡，一次點完。已被後來任務取代的舊行為，已改成最新行為或刪除；重複的項目已合併。

- **測試成分與 SMILES**：照 `docs/verification/phase4-測試體系.md`（P、E、S、L 與配方 4A、4B），不必另外準備。骨架範本 BT01～BT06 從畫面的範本選單直接選。
- 計算值（官能基當量等）在 `docs/verification/phase5-輸出.md`，網站上不顯示（D09）。第 0、1 層的數字見 `phase4-輸出.md`。
- 「結果」「備註」兩欄由使用者填寫，請勿由程式覆蓋。標「三處」的項目請在分子工具、加入成分彈窗、成分詳細彈窗各試一次。

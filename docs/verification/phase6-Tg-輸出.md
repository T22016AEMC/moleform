# Phase 6 Tg 輸出（van Krevelen 基團加成）

**僅為基團加成估算，未含交聯與端基效應；使用者的固化前 Tg 為驗證目標，尚未比對。**

以下為程式輸出，未經化學判斷；分子量、ΣMi 只列在本文件供核對，網站上不顯示（D09）。

- 結構處理：RDKit 2026.09.1；基團表 `src/data/yg_groups.csv`（56 列，稽核狀態皆為「待使用者審」）
- 模型：van Krevelen & te Nijenhuis, Properties of Polymers 4th ed. (2009), 式 6.4–6.5：Tg = 1000·ΣYgi ÷ M（Ygi：K·kg/mol；M：g/mol）。可信度：理論估算（基團貢獻法）。
- 本數值為依理論模型估算之參考值，非實測值。實際結果受原料純度、製程條件與反應動力學影響，請以實驗結果為準。
- 切分規則：Table 6.3 組合基團與 Table 6.1 基團依「基團原子數由大到小」配對，同大小依資料表順序；每個重原子恰好屬於一個基團；配不到的原子回報「缺基團」，不用相近基團代用。
- M = ΣMi（書中 Mi 印到小數一位）；「ΔM」= ΣMi − 分子（重複單元）的精確質量，容許 0.01，超過者標「超出」。
- 重新產生：`npm run verify:phase6-tg`。

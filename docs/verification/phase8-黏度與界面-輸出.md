## 2. 書的算例

### Example 8.1（書頁 236）：聚甲基丙烯酸甲酯（PMMA）

- 書：Ps = 39.0（–CH2–）＋ 4.8（>C<）＋ 2×(39.0＋17.1)（–CH3）＋ (4.8＋60)（–COO–）＝ 220.8；V = 86.5（書 Table 4.6：M 100.1、ρ 1.17）；γ = (220.8/86.5)^4 = 42.5 mN/m。
- 本程式：Ps（Sugden）= 220.8（與書相符）；V = 91.07（Vm 模組，非晶；書用 86.5）；γ = 34.55。
- 以書的 V = 86.5 代入本程式的 Ps：γ = (220.8/86.5)^4 = 42.46（與書 42.5 相符）。差異來自 V：本程式的 V 取 Vm 模組（Table 4.10 的 Va），書的 V 由 Table 4.6 的密度算得。
- 接觸角（書用式 8.10，不是本卡的式 8.23）：本卡未實作式 8.10，這個算例的 θ = 34° 不比對。

### Example 8.3（書頁 241）：式 8.23 的代入

書以兩個接觸角（水 87°、碘甲烷 36°）反解 PVC 的 γSd = 40.1、γSp = 1.5；本程式沒有實作反解（卡片只要求由已知分量算 cosθ），這裡把書的結果代回式 8.23 檢查：

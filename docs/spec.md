# 化學配方物性與交聯預測引擎：修訂版規劃

Oct 27, 2026 · @Leo He

## 定位與基本原則

本程式是**實驗前的參考工具**：只依化學結構與配方比例，以理論模型估算物性與交聯結果。

- **不需任何實驗輸入**：使用者不輸入 DSC、黏度等實測數據。
- **內建文獻資料可使用**：基團貢獻參數表、常見溶劑物性、反應類型的文獻典型值，每個數值標示出處。
- **結果一律給數值**，並顯示模型名稱；是否拿來比較由使用者自行判斷。
- **統一備註文字**：「本數值為依理論模型估算之參考值，非實測值。實際結果受原料純度、製程條件與反應動力學影響，請以實驗結果為準。」
- **可信度分三級標示**：直接計算、理論估算、參考趨勢。
- 不使用量子計算（DFT）與分子動力學（MD）。

## 平台架構與技術選型

架構為**純前端**的桌面網頁（DECISIONS D33）：所有計算在使用者的瀏覽器中執行，部署為公開靜態網站，資料只存使用者自己的電腦（D23、D24）。

| 元件 | 用途 | 授權 |
| --- | --- | --- |
| Ketcher（iframe 獨立子專案） | 2D 結構繪圖 | Apache 2.0 |
| RDKit.js（`@rdkit/rdkit`） | SMILES 解析與驗證、SMARTS 官能基辨識、描述子、2D 座標 | BSD-3-Clause |
| OpenChemLib JS（`openchemlib`） | 3D 構象產生、MMFF94 最佳化與能量（Web Worker 執行） | BSD-3-Clause |
| 3D 顯示函式庫 | 3D 顯示與反應原子標記 | Phase 2 選定並查證授權 |
| write-excel-file | Excel 匯出 | MIT |

成熟 Python 套件（例如 thermo／chemicals）的內建數值（溶劑物性、Joback 參數等）只能轉錄成資料表使用，並標出套件名稱、版本與原始文獻（D18），不在執行時呼叫 Python。

需自行實作：Van Krevelen／Bicerano 基團貢獻法、HSP 基團貢獻法、反應規則表、Miller–Macosko 網路計算。避免 GPL 元件（如 Open Babel），保留未來商業化的彈性。

## 結構輸入、聚合物與 3D

### 化學結構輸入

- 2D 繪圖、SMILES 輸入，兩者雙向轉換
- 原子與鍵編輯；支援芳香環、多環芳香結構、手性中心、E/Z
- 結構驗證：原子價數、鍵結、SMILES 合法性
- 匯入匯出：SMILES、MOL、SDF；建立個人化合物資料庫
- 分子量、官能基種類與當量由程式在背景計算（換算與基團貢獻需要），不列入物性輸出

### 聚合物與共聚物

- 重複單元以 2D 繪圖或 SMILES 輸入，用 `[*:1]`、`[*:2]` 標記連接位置
- 均聚物與共聚物，重複單元數量不限
- **鏈組成固定為 Random**，可設定 mol% 或 wt% 比例
- 可設定 Mn、Mw、PDI、DP 與端基
- 酚醛、Epoxy、Cardo、SBI 等特殊骨架可自訂重複單元與連接位置

### 3D 模型

- **僅顯示單體與小分子**，不建立聚合物鏈
- OpenChemLib JS 構象生成與 MMFF94 最佳化，多構象與相對能量（能量單位確認前不顯示相對能量）；MMFF 缺參數時顯示未最佳化的初始構象並標示
- 旋轉、縮放、平移；Ball-and-Stick、Stick、Space-Filling
- 顯示原子編號，量測鍵長、鍵角、二面角
- 標記官能基與可能的反應原子；匯出 MOL、SDF
- 標示為理論構型

## Solid／Liquid 配方輸入

兩個獨立區域，成分數量不限，每項皆可繪圖或輸入 SMILES。

| 區域 | 成分分類 | 可用單位 |
| --- | --- | --- |
| Solid（非揮發性） | Resin、Crosslinker、Catalyst/Initiator、Small Molecule、Surfactant、Additive、Other | g、重量份、wt%、mol%、phr |
| Liquid | Solvent、Co-solvent、Other Liquid | g、重量份、wt%、mol%、vol% |

自動計算項目：總重、Solid Content、wt%、mol%（聚合物可選以重複單元或以鏈為基準）、phr，以及單位一致性檢查。Solid 成分可標記是否在指定條件下揮發或分解。Liquid 區域依所選計算項目決定是否需要填寫。

## 交聯模組

交聯模組採用三層結構，全部只靠結構與配方計算、全部顯示。需要實驗數據的反應動力學層已排除。各層的化學知識來自內建的**反應規則表**（每種反應一列 SMARTS，含反應類型、新鍵、官能度、副產物、催化劑需求、文獻典型溫度、單位鍵的體積變化）。

### 第 0 層：只有結構

- 可能反應的原子與編號，在 2D／3D 標記
- 反應類型（加成、縮合、開環…）
- 自反應可能性；配方中所有成分的反應配對（A–A、A–B…）
- 鏈延長、接枝或網路的判定
- 反應起始溫度參考範圍（規則表文獻值）
- 反應位點相對活性排序（電子效應 + 3D 空間位阻）

### 第 1 層：加上配方比例

- 化學計量比、過量官能基
- 理論最大成鍵數
- 凝膠點轉化率（Miller–Macosko）
- 交聯密度、平均網目分子量 Mc、溶膠分率（依指定轉化率）
- 殘留官能基（依指定轉化率）

### 第 2 層：加上網路 Tg 估算

| 輸出 | 計算方式 | 注意 |
| --- | --- | --- |
| Tg∞ | 基團貢獻 + 交聯密度修正（Nielsen／Fox–Loshaek） | 高交聯網路誤差較大 |
| 固化後 Tg | DiBenedetto，λ ≈ Tg0 / Tg∞ | Tg0（小分子混合物）為最大誤差來源 |
| 完全固化最低溫度 | ≈ Tg∞ | 估算 Tg∞ 高於 Td 時顯示警示 |
| 指定溫度下最大轉化率 | DiBenedetto 反推 | 未考慮玻璃化後的緩慢反應 |
| 固化收縮 | 單位鍵體積變化（規則表文獻值）× 成鍵數 ÷ 總體積 | 僅化學收縮，區分開環與縮合 |

第 2 層全部直接給數值，附統一備註與模型名稱。第 2 層依賴第 1 層的交聯密度與成鍵數。

## 已取消項目

| 項目 | 原因 |
| --- | --- |
| BigSMILES | 工具成熟度不足，改用自訂重複單元格式 |
| Alternating、Block、Graft、Gradient、Branched 共聚 | 鏈組成固定為 Random |
| 聚合物與共聚物 3D、3D 交聯網路 | 3D 僅顯示單體與小分子 |
| DFT／TD-DFT、分子動力學 | 運算成本高，不符即時參考用途 |
| HOMO/LUMO、UV-Vis、偶極矩 | 需量子計算 |
| 折射率 n、消光係數 k、混合折射率 | 使用者決定取消 |
| 分子量、官能基種類與數量、官能基當量（物性輸出） | 改為背景計算，不顯示 |
| 固化動力學（轉化率對時間）、Arrhenius 速率 | 需實驗數據 |
| 任何使用者實驗輸入 | 本程式為實驗前參考工具 |

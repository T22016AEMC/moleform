## 交聯第 1 層：Miller–Macosko（D41）

### 假設（[M76] 第 206 頁開頭，Flory 的理想網路假設）

1. 同類官能基等活性
2. 各官能基獨立反應
3. 有限分子內不發生分子內反應（無環化）

另外：無副反應。這些假設與實際的落差見 KNOWN_ISSUES M06。

### 符號

| 符號 | 意義 |
|---|---|
| A_fi、B_gj | A 側、B 側的成分，官能度 f_i、g_j（A＝規則的 `group_a`，B＝`group_b`） |
| a_fi、b_gj | 以**官能基莫耳分率**加權的成分比例（[M76] 式 17–21 後的說明，引自其前篇 ref 2a 式 26） |
| p_A、p_B | A、B 官能基轉化率；p_B = r·p_A，r = (A 基團數)／(B 基團數)（[M76] 式 11–13 前後） |
| P(F_A^out)、P(F_B^out) | 由 A、B 基團向外看，通往有限鏈（而非無限網路）的機率 |
| w_Afi、w_Bgj | 各成分的質量分率 |
| [A_fi]₀ | 成分的初始濃度；本專案以「每克固體的莫耳數」代入 |

### 本專案的推導定義（非論文原式）

- **Mc**：論文未以「每單位質量」定義 Mc（式 56 一帶以體積濃度表示，需要密度）。本專案以式 49、51 的濃度改用「每克固體」計算（初始濃度 [A_fi]₀ 以每克固體的莫耳數代入），**Mc ≡ 1 ÷（每克固體的有效網目鏈莫耳數 ν_c）**，單位 g/mol。**依 Miller 1976 式 51 推導的質量基準定義，非論文原式。** 體積基準等 Phase 6 有密度後再加；結果附註「以質量為基準，未換算體積」。「固體」為 Solid 區所有成分（含不參與反應者）；溶膠分率則以參與反應的成分為基準。
- **非整數官能度**（任務 017 B-8）：聚合物每分子平均官能度 = DP × 每重複單元官能基數，常為非整數（例如 24.56）。以相鄰兩個整數官能度的兩種「虛擬成分」混合近似：24.56 = 24（分子數 44%）＋ 25（分子數 56%），兩者沿用同一個每分子質量，使數量平均官能度與總分子數、總質量都不變；再直接套用式 17–21、39、45 的多成分形式。f 為整數時與直接計算完全相同（有測試）。結果附註「官能度以相鄰整數混合近似」。
- **分子量分布的兩成分等重量近似**（任務 019，D47，取代 D42 只用 Mn 的近似）。**本專案推導，非論文原式**；公式仍只取自 Miller 1976 式 17–21、39、45、49、51 的多成分形式。每個聚合物成分以兩種虛擬成分表示，**重量分率各 0.5**，分子量 M₁、M₂ 使 Mn、Mw 與輸入相同：
  - M₁ + M₂ = 2·Mw，M₁·M₂ = Mn·Mw，所以 M₁,₂ = Mw ∓ √(Mw² − Mn·Mw)；PDI = 1 時兩者相等，退化為單一成分（結果與任務 017 完全相同）。
  - 例：Mw 6000、PDI 1.8 → Mn 3333、M₁ = 2000、M₂ = 10000。
  - 每個虛擬成分的分子數 = 0.5 × 質量 ÷ M；官能度 = (M ÷ M_unit) × 每重複單元官能基數；非整數時沿用上一項的相鄰整數混合。
  - **凝膠點只取決於 Mw**：由式 21 推得的凝膠條件只含 Σ a_i(f_i − 1)（a_i 為官能基莫耳分率），也就是重量平均官能度 − 1（式 27 的一般形式）。兩成分近似的官能基總量與 Mw 和輸入相同，所以凝膠點與完整分布相同（測試以整數官能度的手算範例核對：兩成分近似 = 單一成分取重量平均官能度，數值一致；官能度為非整數時，相鄰整數混合造成小於 1e-4 的差異）。
  - 溶膠分率（式 39）、交聯密度與 Mc（式 49、51）依分布形狀而定，兩成分近似只是近似。結果附註：「分子量分布以兩成分（等重量）近似；凝膠點只取決於 Mw，溶膠分率與交聯密度為近似值」。
  - 第 0 層的網路判定、官能基比、過量、理論最大成鍵數、殘留百分比只取決於質量與組成，不受分布影響。
- **共聚物**（任務 020，D04；本專案的處理，非論文公式）：Random 共聚物由 k 種重複單元與比例組成。wt% 先以各單元 M_unit,i 換成莫耳分率 x_i ∝ w_i ÷ M_unit,i；mol% 則 x_i = 比例 ÷ 100。
  - 平均單元質量 M̄_unit = Σ x_i·M_unit,i；每個平均單元的官能基數 = Σ x_i·(單元 i 的該官能基數)，每種官能基分開計。
  - DP_n = Mn ÷ M̄_unit，DP_w = Mw ÷ M̄_unit；每分子官能度 = DP_n × 每平均單元官能基數。之後沿用上面的兩成分等重量分布近似與 Miller 1976 公式（M_unit 以 M̄_unit 取代）。
  - **組成分布近似**：每條鏈的組成視為等於平均組成，不考慮鏈與鏈之間的組成差異；結果附註「共聚物以平均組成計算，未考慮鏈間組成分布」。
  - 只有一種單元的共聚物 x_1 = 1，M̄_unit = M_unit，結果與均聚物完全相同（測試）。程式只依組成與分子量計算，不檢查縮合反應的連接規則。
  - 聚合物 mol%（D46）以重複單元計時用 M̄_unit。
- **端基**（任務 022，D50；本專案的處理，非論文公式）：聚合物兩端可各填一個端基（SMILES 含一個 `*`），M_end = 去除 `*` 後片段的分子量（算法同 M_unit）；M_ends = 已填端基的 M_end 合計。
  - 換算：DP_n = (Mn − M_ends) ÷ M̄_unit；DP_w = (Mw − M_ends) ÷ M̄_unit（顯示用）；輸入 DP 時 Mn = DP × M̄_unit + M_ends。Mn ≤ M_ends 為錯誤。沒有端基時 M_ends = 0，與先前完全相同。
  - 每條鏈的官能基數（每種官能基分開計）：f(M) = ((M − M_ends) ÷ M̄_unit) × 每平均單元官能基數 + 兩端端基官能基數。端基的官能基用與重複單元相同的 SMARTS、相同的 `*` 處理辨識。
  - 兩成分等重量近似：每個虛擬成分（M₁、M₂）的官能度用上式；非整數時沿用相鄰整數混合。M 小於 M_ends 時鏈長以 0 計（邊界保護）。
  - **凝膠點仍只取決於 Mw**：f 是 M 的一次式，Σ w_i f(M_i) = f(Mw)（兩成分等重量近似的 Mn、Mw 與輸入相同，所以重量平均官能度與完整分布相同）。測試以手算範例核對（M_unit 200、每單元 2 個官能基、M_ends 200、端基 2 個官能基、Mw 6000、PDI 1.8：M₁ = 2000、M₂ = 10000，f₁ = 20、f₂ = 100，f(Mw) = 60；兩成分近似的凝膠點 = 單一成分 f = 60，差小於 1e-10）。
  - 官能基量、官能基比、過量、理論最大成鍵數、殘留百分比都使用含端基的每分子官能基數。聚合物 mol%（D46）以鏈計用含端基的 Mn，以重複單元計仍用 M̄_unit。
  - 附註：兩端都填 → 無；都不填 → 「未計入端基」；只填一端 → 「端基 N 未填，未計入」。
  - **低分子量修正**（任務 023，D51；本專案的處理，非論文公式）：兩成分近似的 M₁ = Mw − √(Mw² − Mn·Mw) 若小於 M_ends（分子量很低、端基很重），輕成分比兩端端基合計還輕，不合理。**只有 M₁ < M_ends 時**改用兩成分：成分 a 是 n = 0 的分子（M_a = M_ends，重量分率 w），成分 b 是較重成分（M_b，重量分率 1 − w），Mn、Mw 與輸入相同：
    - w·M_a + (1 − w)·M_b = Mw、w ÷ M_a + (1 − w) ÷ M_b = 1 ÷ Mn。
    - 消去 M_b 得 (1 − w)² = (Mw − w·M_a)(1 ÷ Mn − w ÷ M_a)。展開後 w² 項兩邊相消，化為一次式：w = (Mw ÷ Mn − 1) ÷ (Mw ÷ M_a + M_a ÷ Mn − 2)，M_b = (Mw − w·M_a) ÷ (1 − w)。因 Mn > M_ends（Mn ≤ M_ends 已是輸入錯誤），且 Mn < Mw，恆有 0 < w < 1 與 M_b > M_ends，恰有一個根。
    - 官能度仍用同一個 f(M) = ((M − M_ends) ÷ M̄_unit) × 每平均單元官能基數 + 端基官能基數；成分 a 的 f 只剩端基的官能基。非整數時沿用相鄰整數混合。原本對 M − M_ends 的 `Math.max(…, 0)` 截斷已移除，M < M_ends 時拋出內部錯誤（不應再發生）。
    - **凝膠點仍正確**：f 是 M 的一次式，Mn、Mw 不變則重量平均官能度 Σ w_i f(M_i) = f(Mw) 不變。
    - M₁ ≥ M_ends（含沒有端基）時，M₁、M₂ 各 0.5，完全不變。使用新作法時，結果附註在分布附註後加「低分子量：以 n = 0 分子與較重成分兩成分近似」。
    - 測試（`tests/crosslink/layer1/lowMw.test.ts`）：雙酚 A 環氧（BT05）Mn 500、Mw 1000：M_ends ≈ 340.41，原式 M₁ ≈ 292.9 < M_ends；w ≈ 0.6179、M_b ≈ 2066.5；回算 Mn、Mw 差小於 1e-9；每條鏈環氧基 2，凝膠點與單一成分 f = 2 相同。
- **分子量輸入換算**（D47）：Mn = Mw ÷ PDI；DP_n = Mn ÷ M_unit；DP_w = Mw ÷ M_unit；PDI 必須 ≥ 1，沒有 PDI 時為 2。舊資料（只有 Mn 或 DP）視為 PDI 未填（預設 2）。
- **聚合物 mol%**（D46）：預設以整條鏈計（莫耳數 = 質量 ÷ Mn），可切換為以重複單元計（莫耳數 = 質量 ÷ M_unit）；只影響 mol% 的顯示（區域單位選 mol% 時，也決定把 mol% 換成質量的方式）。
- **官能基量**：成分的官能基莫耳數 = 質量 ÷ 每分子質量 × 每分子官能基數（聚合物：Mn、DP × 每重複單元官能基數；與第 0 層的 f 相同）。限量官能基轉化率 q → `p_A = q·min(N_A,N_B)/N_A`、`p_B = q·min(N_A,N_B)/N_B`（反應掉的鍵數相同，與 p_B = r·p_A 一致）。
- **理論最大成鍵數**：限量官能基完全反應的鍵數，單位 mol／kg 固體（與「已形成的鍵」、交聯密度同一基準；使用者 2026-10-29 決定，原為 mol／100 g）。
- **殘留官能基**：`(1 − p)×100%`；掃描的「兩類合計」為 `1 − (p_A·N_A + p_B·N_B)/(N_A + N_B)`。

### 與 [T24] 的差異

[T24] 式 19 的 `m/2`（`ν = Σ (m/2)[A_f]₀P(X_m,f)`）是**網目鏈總數**，與 [M76] 式 51 的 (m−2)/2（含 Duiser–Staverman／Graessley 的有效性加權）定義不同。本專案的「交聯密度」與 Mc 以 **[M76] 式 51** 為準；[T24] 僅用於核對式 39（其式 2）與式 45（其式 21），兩者與 [M76] 一致。

## 第 1 層不支援的體系（任務 P7-1A，D65）

Miller–Macosko 只適用「兩類官能基、單一步驟、等活性」的逐步加成。反應規則 A 批中下列規則的體系不符合，第 1 層（Python `layer1.py` 的 `UNSUPPORTED_RULES`；任務 I05 起 TypeScript `prepare.ts` 的同一份清單已退役）回報「此體系的凝膠點與當量計算尚未支援：原因」，不套用公式：`epoxy+anhydride`（多步）、`epoxy+cyanate`（多路徑）、`cyanate.trimerization`（三聚自反應）、`novolac+hmta`（HMTA 須先分解、等效位點未定）、`resol.methylol+phenol_ring`／`resol.methylol-ether`／`resol.methylol-methylene`（同分子兩類官能基、自縮合）、`epoxy+pag.cationic`／`oxetane+pag.cationic`（陽離子鏈增長）。`epoxy+amine.*` 四條照現有公式計算（一級胺 N 的 functionality = 2、二級胺 = 1；一級與二級胺氫的活性差異不計，" 等活性 " 假設）；配方同時含一級與二級胺（如二乙三胺）時有兩條規則，回報「目前只支援單一反應規則」。反應規則的 `functionality` 為「每個官能基形成的鍵數」，對催化劑類配對（PAG）無化學計量意義。

### C 批（自由基體系，任務 P7-1C，D65）

- **鏈增長聚合不適用逐步聚合的 Miller–Macosko 凝膠點**：`acrylate`／`methacrylate`／`acrylamide`／`styrene` 各與熱起始劑（`initiator.thermal`，偶氮、過氧化物）或光起始劑（`initiator.photo`，α-羥基烷基苯酮）共 8 條規則，第 1 層回報「此體系的凝膠點與當量計算尚未支援」，不給數值。起始劑與光酸產生劑同一種表示法：官能基列入 `crosslink.py` 的 `CATALYST_GROUPS`，配對顯示「催化劑配對（不計當量）」，起始劑的 f 無化學計量意義；每個單體 C=C 的 functionality 取 2（打開 π 鍵、與前後單元各形成一鍵，自行判斷）。反應 SMARTS 表示一步增長（碳自由基＋單體），資料表測試組合因此是「單體＋碳自由基」。
- **硫醇–烯**：`thiol`（RDKit `fr_SH`）與烯丙基（`alkene.allyl`）、乙烯基醚（`vinyl.ether`）、降冰片烯（`norbornene`）各一條規則，視為 1:1 等活性的逐步加成（每個 –SH 與每個 C=C 各反應一次，這類 ene 不自聚；判斷無本機文獻，待使用者確認），第 1 層照現有公式計算，適用條件見各規則 notes；`thiol+acrylate` 因丙烯酸酯可同時均聚、官能度不固定，列入不支援清單。同一配方含多種 ene 時有多條規則，回報「目前只支援單一反應規則」。含環氧的丙烯酸酯（GMA）同時命中 `ether.epoxide` 與 `methacrylate`，只做官能基命中，沒有跨體系規則。

## 理論配比與比例掃描（D40）

- **化學計量配比**：`group_a` 側成分用量不變，`group_b` 側所有成分乘同一個係數 N_A／N_B，使兩類官能基等量。可信度「直接計算」。
- **比例掃描**：當量比 R = N_B／N_A，預設範圍**自動包含目前配方的當量比**：下限 0.5，上限 max(1.5, 目前當量比 × 1.2)，41 點，使用者可調整（最佳點落在範圍邊界時提示）；每個 R 把 `group_b` 側乘 R·N_A／N_B（固體總量隨之改變，所有「每克固體」的量以新總量計），轉化率使用使用者的限量官能基轉化率。目標物性（預設為交聯密度 ν_c 最大；下拉選單旁附白話說明，如「Mc（最小）：網最密」）：交聯密度 ν_c、連入網路的分子數 [X]（未凝膠兩者視為 0）、Mc（最小／最大）、凝膠轉化率（最小／最大）、殘留官能基（A 側、B 側、兩類合計；皆取最小）。可信度「參考趨勢」，標示「未考慮副反應與反應不完全，實際最佳配比以實驗為準」。

## 交聯第 1 層：Miller–Macosko（D41）

### 假設（[M76] 第 206 頁開頭，Flory 的理想網路假設）

1. 同類官能基等活性
2. 各官能基獨立反應
3. 有限分子內不發生分子內反應（無環化）

另外：無副反應。這些假設與實際的落差見 KNOWN_ISSUES M06。

### 符號

| 符號 | 意義 |
|---|---|
| A_fi、B_gj | A 側、B 側的成分，官能度 f_i、g_j（A＝規則的 `group_a`，B＝`group_b`） |
| a_fi、b_gj | 以**官能基莫耳分率**加權的成分比例（[M76] 式 17–21 後的說明，引自其前篇 ref 2a 式 26） |
| p_A、p_B | A、B 官能基轉化率；p_B = r·p_A，r = (A 基團數)／(B 基團數)（[M76] 式 11–13 前後） |
| P(F_A^out)、P(F_B^out) | 由 A、B 基團向外看，通往有限鏈（而非無限網路）的機率 |
| w_Afi、w_Bgj | 各成分的質量分率 |
| [A_fi]₀ | 成分的初始濃度；本專案以「每克固體的莫耳數」代入 |

### 本專案的推導定義（非論文原式）

- **Mc**：論文未以「每單位質量」定義 Mc（式 56 一帶以體積濃度表示，需要密度）。本專案以式 49、51 的濃度改用「每克固體」計算（初始濃度 [A_fi]₀ 以每克固體的莫耳數代入），**Mc ≡ 1 ÷（每克固體的有效網目鏈莫耳數 ν_c）**，單位 g/mol。**依 Miller 1976 式 51 推導的質量基準定義，非論文原式。** 體積基準等 Phase 6 有密度後再加；結果附註「以質量為基準，未換算體積」。「固體」為 Solid 區所有成分（含不參與反應者）；溶膠分率則以參與反應的成分為基準。
- **非整數官能度**（任務 017 B-8）：聚合物每分子平均官能度 = DP × 每重複單元官能基數，常為非整數（例如 24.56）。以相鄰兩個整數官能度的兩種「虛擬成分」混合近似：24.56 = 24（分子數 44%）＋ 25（分子數 56%），兩者沿用同一個每分子質量，使數量平均官能度與總分子數、總質量都不變；再直接套用式 17–21、39、45 的多成分形式。f 為整數時與直接計算完全相同（有測試）。結果附註「官能度以相鄰整數混合近似」。
- **只有 Mn 的近似**（D42）：每種成分視為單一官能度（重量平均官能度 = 數量平均官能度）。分子量分布越寬，實際凝膠點越早；結果附註此限制。
- **官能基量**：成分的官能基莫耳數 = 質量 ÷ 每分子質量 × 每分子官能基數（聚合物：Mn、DP × 每重複單元官能基數；與第 0 層的 f 相同）。限量官能基轉化率 q → `p_A = q·min(N_A,N_B)/N_A`、`p_B = q·min(N_A,N_B)/N_B`（反應掉的鍵數相同，與 p_B = r·p_A 一致）。
- **殘留官能基**：`(1 − p)×100%`；掃描的「兩類合計」為 `1 − (p_A·N_A + p_B·N_B)/(N_A + N_B)`。

### 與 [T24] 的差異

[T24] 式 19 的 `m/2`（`ν = Σ (m/2)[A_f]₀P(X_m,f)`）是**網目鏈總數**，與 [M76] 式 51 的 (m−2)/2（含 Duiser–Staverman／Graessley 的有效性加權）定義不同。本專案的「交聯密度」與 Mc 以 **[M76] 式 51** 為準；[T24] 僅用於核對式 39（其式 2）與式 45（其式 21），兩者與 [M76] 一致。

## 理論配比與比例掃描（D40）

- **化學計量配比**：`group_a` 側成分用量不變，`group_b` 側所有成分乘同一個係數 N_A／N_B，使兩類官能基等量。可信度「直接計算」。
- **比例掃描**：當量比 R = N_B／N_A，預設範圍**自動包含目前配方的當量比**：下限 0.5，上限 max(1.5, 目前當量比 × 1.2)，41 點，使用者可調整（最佳點落在範圍邊界時提示）；每個 R 把 `group_b` 側乘 R·N_A／N_B（固體總量隨之改變，所有「每克固體」的量以新總量計），轉化率使用使用者的限量官能基轉化率。目標物性（預設為交聯密度 ν_c 最大）：交聯密度 ν_c、連入網路的分子數 [X]（未凝膠兩者視為 0）、Mc（最小／最大）、凝膠轉化率（最小／最大）、殘留官能基（A 側、B 側、兩類合計；皆取最小）。可信度「參考趨勢」，標示「未考慮副反應與反應不完全，實際最佳配比以實驗為準」。
